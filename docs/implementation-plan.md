# 实现计划

## 1. 项目目标

本项目同时服务于两个目标：

1. 以可测试的方式复现论文的核心算法：Wang 边约束、Coons 坐标变形、逆映射采样和
   环面连续生成器。
2. 将算法发展为具有实时交互、稳定导出和良好视觉表现的生成艺术工具。

“看起来接近”不等于算法复现成功。接缝误差、映射可逆性、CPU/GPU 一致性和导出
一致性都必须能够定量验证。

## 2. 技术基线

- 语言：C++20。
- 构建：CMake。
- 窗口与输入：GLFW。
- 图形 API：OpenGL，算法 Shader 使用独立 GLSL 文件。
- UI：Dear ImGui。
- 测试：轻量 C++ 单元测试目标；具体测试框架在搭建构建系统时确定。
- 图像导出：从权威渲染结果读取并编码 PNG；不建立另一套离线几何定义。

依赖版本与获取方式在构建系统阶段确定并锁定。项目不得依赖开发机上的隐式全局
状态才能构建。

## 3. 权威数据流

```text
ProjectParameters
  -> EdgePalette
  -> WangGrid
  -> CoonsWarp
  -> InverseWarp
  -> TorusGenerator
  -> ColorPipeline
  -> Renderer
  -> Viewport / Debug Views / Export
```

预览、主视图、接缝调试和导出必须消费同一组参数、边定义和变换语义。允许 CPU 与
GPU 使用不同执行后端，但两者必须由同一数学规范约束，并通过固定样本测试证明等价。

## 4. 模块所有权

| 模块 | 唯一职责 | 不负责 |
| --- | --- | --- |
| model | 项目参数、边颜色、铺砌拓扑、随机种子 | GPU 资源和窗口事件 |
| math | 边函数、Coons 映射、Jacobian、逆映射 | 调色板和 OpenGL 生命周期 |
| generators | 环面连续标量场及其参数 | Wang 邻接规则 |
| color | 标量场到最终颜色的连续映射 | 几何与逆映射求解 |
| renderer | Shader、GPU 资源、绘制调度、调试合成 | 修改模型参数 |
| ui | 草稿参数、用户意图和提交操作 | 复制实现算法 |
| export | 选择权威渲染路径并编码输出 | 维护另一套渲染模型 |

复杂参数使用不可变快照或 revision 传入渲染器。昂贵重建只在输入提交或相关 revision
变化时发生，不因窗口重绘、悬停或普通布局变化重复执行。

## 5. 目标目录

目录随实现逐步建立，不预先创建空层级：

```text
docs/                 设计、数学规范和验证方案
src/model/            参数模型与 Wang 网格
src/math/             CPU 参考数学实现
src/generators/       生成器参数与 CPU 参考实现
src/render/           OpenGL 渲染后端
src/ui/               应用界面与交互状态
shaders/              独立 GLSL 源码
tests/                数学、铺砌和一致性测试
assets/presets/       可复现的艺术预设
```

## 6. 分阶段实施

当前进度：阶段 A、B、C、D 已完成并通过 CPU/GPU 分阶段对照、draft/committed 事务
测试、三套展示预设及高低缩放视觉检查；阶段 E 为下一步。

### 阶段 A：可验证的 CPU 数学核心

- 实现边函数、导数、Coons 映射与 Jacobian。
- 生成经过安全条件验证的边函数调色板。
- 实现带残差、步长保护和失败状态的双精度逆映射。
- 实现共享边、角点、正逆映射和随机种子确定性测试。
- 生成最小的数值结果，不追求 UI 或最终视觉效果。

完成条件：所有数学测试通过，非法参数能够被明确拒绝，而不是产生未定义图像。

### 阶段 B：CPU 基准图与接缝证明

- 实现周期 Fourier/QRP 和周期噪声的参考采样。
- 生成单瓦片、2 x 2 邻接和 10 x 10 铺砌基准图。
- 输出接缝误差数值和热图。
- 固定一组回归种子与参数快照。

完成条件：共享边的独立求值在规定容差内一致，且输出可由相同参数复现。

### 阶段 C：GPU 实时渲染

- 将逆 Coons 求解和生成器移入 GLSL。
- 与 CPU 固定样本逐点对照。
- 实现平移、缩放、不同窗口比例和调试覆盖层。
- 参数变化时更新必要资源；普通绘制不得触发不相关重建。

完成条件：代表性设备上交互流畅，无失败像素，CPU/GPU 误差满足验证规范。

### 阶段 D：交互与视觉系统

- 加入边函数、种子、生成器、混合和调色板编辑。
- 区分 draft 与 committed 状态；高成本操作在 Apply 或稳定节点执行。
- 加入连续色带、感知颜色插值、抗锯齿轮廓和边界安全的材质效果。
- 制作至少三套风格明显、参数可复现的展示预设。

完成条件：图案既无接缝，也没有明显的方格感、过度重复或不可控闪烁。

### 阶段 E：导出与发布质量

- 高分辨率 PNG 导出。
- 参数与随机种子伴随导出保存。
- 验证屏幕和导出使用相同坐标、颜色与实例定义。
- 补齐构建说明、示例图和性能记录。

### 阶段 F：任意四边形网格

只有方格 Wang 版本完成并通过验证后再开始。该阶段需要单独定义物理四边形映射、
边方向、网格有效性和 inverse/forward rendering 选择，不能仅凭论文结论直接外推。

## 7. 首个产品里程碑

首个里程碑交付一个桌面程序，能够实时显示 10 x 10 Wang 铺砌，切换周期噪声与
torus-safe QRP，查看 Jacobian、Newton 残差及接缝误差，并加载至少三套高质量预设。

## 8. 非目标

- 第一阶段不支持旋转或镜像瓦片。
- 第一阶段不支持任意四边形网格。
- 不预生成大型图片瓦片图集。
- 不以截图替代数值正确性验证。
- 不把论文中的占位实验图或未完成引用视为可复现证据。
