# 相位兼容 QRP 瓦片候选（2026-09-22）

## 1. 方法变化与结果

本轮接续 [独立瓦片首轮研究](qrp-reusable-tile-study.md)。保留有限固定库、端点编码的
四种边色 / 16 种类型、纯 ID 铺砌；不再把不同 QRP 来源的标量值大面积混合。
新方法先为每个 QRP 模态构造满足边界的相位，再用原来的非负归一化振幅求余弦和。
因此可以避免旧来源混合引入的额外振幅衰减，但仍存在 QRP 本身各方向之间的干涉。

实际完成三类参数 × 两种瓦片跨度，共六例，每例有两个布局：

- 环形组织、方向波带和两通道格纹仍有清楚差异。
- 相比上一轮匹配来源，波带更连贯，环形更完整；不能把这句话扩展为所有参数的保证。
- L=4 的环形仍明显锚定规则网格。L=8 虽减小相对相位梯度修正上界，却主要变成更大的
  重复单元，并未恢复全局 QRP 参考的自然组织。
- 本轮确实实现了边界兼容的内容生成，但其**相位闭合是对原 QRP 的实质性修改**。
  新候选不是原始全局 QRP 的无损裁切，也不等价于单一 canonical QRP。

用户已明确接受“边界约束下的 QRP 扩展”，优先验证风格与铺砌价值。因此继续以相位兼容
候选作为下一阶段研究基础，不再把精确恢复原始全局频谱作为硬目标；但仍明确记录这一
扩展与 canonical QRP 的差别，不能把授权探索解释为美感或商业价值已验证。
风格多样性、QRP 造型、Wang 内部铺砌的用户目标保持不变。

## 2. 从谱定义到相位约束

本节公式对应默认零内部相位偏移的原候选。后续 [相对相位状态扩展](qrp-retiling-study.md)
只扩展 β、γ 的内容定义，接边证明的结构不变；旧结果保持不变。

复用 `ParametricWangQrpField::modes()` 提供的只读谱：方向 `d_r`、二阶角谐波 `c_r,s_r`、
非负振幅 `a_r`，且 `Σa_r=1`。权重与载波方向公式没有在新模块中复制。
旧的全局 Wang 相位调制为零。令瓦片源跨度为 L，单位瓦片目标波矢为

\[
\omega_r=L\kappa d_r.
\]

为每个模态选择固定整数圈数和闭合修正：

\[
n_r=\operatorname{round}(\omega_r/(2\pi)),\qquad
\Delta_r=2\pi n_r-\omega_r.
\]

逐分量最近整数使 `|Δx|,|Δy|≤π`，只是在该固定构造中最小化闭合修正的平方和，
不是最优纹样或所有边界方案的最优解。

令 `h(t)=3t²−2t³`，`h(0)=0,h(1)=1,h′(0)=h′(1)=0`。
这是给定端值与零端点导数的三次插值，不是事后图像模糊。
沿用上一轮两个固定角点源偏移 `o0=(0.2,0.3), o1=(0.9,0.4)`。
对四角二值状态 aSW、aSE、aNW、aNE，定义

\[
S_\tau(u,v)=(1-h(v))[(1-h(u))a_{SW}+h(u)a_{SE}]
 +h(v)[(1-h(u))a_{NW}+h(u)a_{NE}].
\]

角点状态是内容库内部编码，不是新用户控件。每模态的固定初相位与状态差为

\[
\beta_r=\kappa d_r\cdot o_0+A c_r+B s_r+\varphi,
\qquad \gamma_r=\kappa d_r\cdot(o_1-o_0).
\]

最终相位和场为

\[
\Phi_{r,\tau}(u,v)=\omega_{rx}u+\omega_{ry}v
 +\Delta_{rx}h(u)+\Delta_{ry}h(v)+\beta_r+\gamma_r S_\tau(u,v),
\]

\[
T_\tau=\sum_r a_r\cos\Phi_{r,\tau},\qquad
\nabla T_\tau=-\sum_r a_r\sin\Phi_{r,\tau}\nabla\Phi_{r,\tau}.
\]

所有模态振幅不变，直接得到 `|T|≤1`，不需要归一化或 clamp。
不同于上一轮，这里没有内部原 QRP 恢复区域；修正分布在整个瓦片，相位梯度包含所有
闭合项与状态插值导数。不能把它宣传为“完全不改变造型”。

## 3. 接边、相位提升与周期骨架

合法东西邻接共享两个角点状态。东边和西边上 S 相同，S 的法向导数为零，
切向导数相同。两侧每个模态的相位相差 `2π n_rx`，完整梯度相同：
法向相位导数均为 `ωrx`，切向表达也逐项相同。因此余弦值和场的完整梯度一致。
南北邻接同理，角点的相位模 2π 与完整梯度也一致。合法拼接得到 C¹ 场。
若两个通道分别成立，其乘积也保持 C¹；不保证乘积零集交点处正则。

令实例位置为 g，仅用于证明，将其局部相位提升为

`Ψr(x)=Φr,τ(x−g)+2π nr·g`。

合法邻接让提升后的相位本身也全局 C¹。**运行时不使用 g 求值内容**，实例仍然复制
同一缓存图片。可进一步写成

\[
\Psi_r(x)=2\pi n_r\cdot x+
\Delta_{rx}[h(u)-u]+\Delta_{ry}[h(v)-v]+\beta_r+\gamma_r S(x),
\quad (u,v)=x-g.
\]

这个等式揭示了不能隐藏的代价：长期平均载波是整数波矢 `2π nr`，不是原 `ωr`。
当所有角点状态相同、或两个角点偏移相同时，内容退化为单瓦片周期纹样。
实际 Wang 状态产生位置相关的相位变化，16 类型并非同一张图的普通重复，但其底层仍有
相位闭合的周期骨架。不能声称精确保留原始不可公度频谱、全局五重旋转对称性或严格非周期。

这不是 B 路线的“外部规则模板＋QRP 形变”：仍从 QRP 谱生成余弦和。
但“没有外部模板”也不足以证明数学上仍是原始 QRP；应称作 QRP 谱驱动的相位兼容扩展。

## 4. 贯通核心带的充分条件

对振幅最大的模态 *，令 `a*=a_*`，其余振幅和 `R=1−a*`，方向 `e=ω*/|ω*|`。
由 `h′∈[0,1.5]`、二值角点插值的两个偏导绝对值均不超过 1.5，可得

\[
e\cdot\nabla\Psi_*\ge m=
|\omega_*|-1.5(|e_x\Delta_{*x}|+|e_y\Delta_{*y}|)
-1.5|\gamma_*|(|e_x|+|e_y|).
\]

如果 `m>0`，提升相位沿 e 严格单调，并沿该方向趋于正负无穷。每条固定相位线
是横向坐标上的连续图像。若同时 `a*>R`，那么

- `Ψ*=2kπ` 上有 `T≥a*−R>0`；
- `Ψ*=(2k+1)π` 上有 `T≤−a*+R<0`。

更一般地，在 `cos Ψ*>R/a*` 或 `<−R/a*` 的开带内符号确定。这给出两种颜色各自
贯通的核心带，而不是仅对若干采样点作观察。结论适用于此类型集的合法无限延拓；
有限裁图里的带可能被画面边界裁断。

**不推出**零轮廓处处无分支、无局部小岛、带宽恒定、所有原轮廓拓扑不变或整体美观。
两个方向通道各自有核心带，也不自动证明它们乘积后全部格子的拓扑。

当前方向性案例 η=1.5、q=5：`a*=0.542884848`、`R=0.457115152`。

| 源跨度 | 主通道 m | 90°通道 m | 核心带条件 |
| --- | ---: | ---: | --- |
| L=4 | 9.242055922 | 12.077055922 | 两通道分别成立 |
| L=8 | 21.791611843 | 24.626611843 | 两通道分别成立 |

等权环形案例 `a*=0.2<R=0.8`，没有这个保证；不能将方向性结论套给全部 QRP。

## 5. 瓦片跨度对照的依据与局限

相对于目标波矢，单个模态相位梯度修正的保守上界为

\[
\frac{\|\nabla\Phi_r-\omega_r\|}{L\kappa}
\le\frac{1.5\|\Delta_r\|+1.5\sqrt2|\gamma_r|}{L\kappa}
\le\frac{1.5\sqrt2(\pi+|\gamma_r|)}{L\kappa}.
\]

源偏移与 QRP 参数固定时，最后这个统一上界随 L 增大下降。但实际 Δ 随取整改变，
实际误差不必逐次单调，更不保证美感或相位值误差单调改善。相位值偏差仍可达到有限角度，
减小波矢相对扰动也不等于在固定视野收敛到同一张原始 QRP 图。

本轮对照固定源视野 `[0,32]²`、QRP 参数、总 768px 与每源单位 24px 的采样密度：

- 8×8 布局，每瓦片 L=4、96px；
- 4×4 布局，每瓦片 L=8、192px。

网格大小与合法布局随之改变，不能误称“只换一个像素参数、Wang 布局相同”。
两个配置仍各有同一 16 类型库、两个合法布局；大瓦片布局不必包含全部 16 种类型。
数值上相对修正的保守上界降低，视觉上环形重复单元依旧明显，因此不继续无目的地放大 L。

## 6. 固定配置与复现

沿用上一轮三类：q=5、κ=3.15、A=B=φ=t=0，旧 Wang 相位调制为零。
环形 η=0；波带 η=1.5；乘积的两个通道均 η=1.5，次通道旋转 90°。
同一深蓝 / 米色，F<0 填充，每像素 2×2 采样，不描边、不收缩、不做接缝后处理。

```powershell
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
.\build\Release\qrp_wang_qrp_experiment.exe --phase-tile-study
python tools\build_tile_board.py output\qrp-phase-tile-study --previous output\qrp-tile-study
```

入口自动输出标准跨度与 `larger-tiles/` 两组，每组 48 张瓦片、六张布局、三张全局参考，
另有三张单瓦片周期对照，合计 120 张原始 PNG。每组 manifest 记录 QRP 参数、完整模态（波矢、圈数、闭合量、振幅、
初相位和状态差）、布局、核心带充分条件和共享边抽样误差。

- `board_patterns.png`：本轮 L=4 三类成图。
- `board_phase_comparison.png`：全局参考、上一轮固定/匹配来源、本轮 L=4。
- `board_phase_scale.png`：全局参考、L=4、L=8。
- `board_wang_value.png`：库内类型 0 的合法周期重复、同库 Wang 布局 A、同库布局 B。
- 两目录各自的 `board_reuse.png`：实际瓦片库和两个布局。

`PhaseCompatibleQrpTiles` 是唯一相位公式实现；谱定义来自既有 QRP 模块。
旧、新瓦片共用同一填色、缓存烘焙、纯像素复制及检验入口；Python 不实现模型公式。
界面没有改变，也没有开放 Wang 参数。新候选没有替换此前用户认可的图样。

## 7. 必要验证与未决事项

Release 编译与七组 CTest 通过；在既有可复用瓦片测试中增加相位候选用例，不新增测试框架。
检查振幅与 QRP 谱一致、所有合法类型邻接的值/完整梯度、范围、非平坦内部解析梯度，
以及方向性充分条件成立、等权案例不得声称该条件成立。

两跨度六例的共享边采样最大误差不超过 `4.452×10⁻¹⁴`。
120 张原图全部解码，两个跨度共 480 个 Wang 布局实例、240 个周期对照实例均与源瓦片逐像素一致。
旧来源混合研究重跑的 111 张原图与上一轮字节一致；所有原始单元测试仍通过。
已目视检查两轮对照与复用板，没有把图片中的规则程度当作客观美感评分。

频率或旋转改变时，最近整数圈数可能跳变，所以当前不保证整个用户参数空间里图样连续变化。
固定圈数分支内，方向权重、A/B 和共同相位等连续参数保持公式的连续依赖。
未认证严格原 QRP 等价、全局准周期性、所有轮廓拓扑、任意参数下效果或商业适用性。

## 8. 接受扩展后的价值对照与下一步

用户确认接受扩展后，补充了同库单瓦片周期重复对照。选择四边均为 00 的类型 0，
其自匹配合法；不能随意选一个四边不自匹配的类型来制造接缝，冒充普通铺砌的缺点。
对照与两种 Wang 布局均只复制同一个缓存库，未改变 QRP 参数、颜色或采样。

可观察到：单瓦片重复中的环形、波带、格纹按固定节奏重现；多类型 Wang 布局可改变
局部形状、带的偏移和格纹的起伏，并在 A/B 重新铺砌中原样复用内容。环形的规则骨架
仍明显，Wang 并没有消除所有重复感。这是有限内容库可以合法重组的证据，不是商业价值
或严格非周期性的证明，也不是 CPU/GPU 性能基准。

下一阶段以风格与铺砌价值为主：保持独立内容接口和边界证明，优先验证兼容通道的层级、
门控等组织关系能否扩大风格跨度；不把同一风格的相位预设或单纯增大瓦片冒充新方法。
不推进 UI，Wang 内部参数仍不交给用户。若后续发现某种组织依赖实例全局坐标，必须重新
检查独立复用条件，不能沿用本轮的验证结论。

后续已完成 [父子组织研究](qrp-organization-tile-study.md)：兼容通道的门控保持独立复用，
但新引入的低频父场暴露平均波矢方向合并问题。该轮按闭合误差选择内部跨度，保留两轮
结果与推导；针对的是低频方向分辨率，不改变本页“扩大瓦片不保证消除周期骨架”的结论。

再后续已完成 [大范围重铺与相对相位状态](qrp-retiling-study.md)：证实旧库局部变化在大图
中仍受共同骨架限制，扩展父场状态后增加簇群形状与列的起伏，但损失部分完整大环。
仍保留原候选，不把较强变化作为自动替代依据。
