> 历史阶段记录：旧代码与命令已归档至 `b58337a`，见 [恢复说明](legacy-experiments.md)。当前入口见 [README](../README.md)。

后续定位修正：本文图样仍来自依赖全局坐标的 QRP，证明的是风格组合能力，不是同类
内容瓦片的独立复用。真正有限内容库的后续对照与问题见
[独立瓦片研究](qrp-reusable-tile-study.md)。下面保留当时实验和视觉观察，不以新候选
暂时受损的造型取代这里用户认可的基准。

## 1. 目标与本轮结论

用户再次明确：主线是用本方法得到风格多样的纹理，不是持续优化单一风格的可控性，
也不是制作调试台。保留用户认可的环瓣，不把形状混合自动判为缺陷。

本轮先做 10 组对照，再补 3 组层级组织对照，共 13 组。所有成图固定深蓝/米色，
直接比较结构，不以换色、旋转或共同相位变化充当独立风格。

视觉观察支持以下取舍，尚不代表商业价值或审美偏好已获用户确认：

- 保留原有环瓣与连续波带基准。
- 两个方向性 QRP 相乘，得到明显不同的交错格纹；同场描线得到曲线网格。
  格纹与网格线描是同一个结构构造的两种表达，不冒充两个独立生成方法。
- 父子门控在尺度比 6 时出现清楚的大环簇；方向性子场产生带留白的分区条纹，
  与铺满画布的连续波带有明显不同的组织方式。
- 联合能量两例仍偏环瓣同族，没有实现预期的细胞分区风格。保留负面结果，不继续微调包装。
- 尺度比 3.5 的初轮门控已改变分布，但组结构不如尺度比 6 清楚；相位变化主要是同族变体。

因此，扩大能力的有效方向是 **QRP 通道之间的组合关系**，而非只增加单场相位预设。
下一轮优先根据用户对交错格纹、网格、环簇和分区条纹的评价选择方向；
若仍需更大跨度，应提出新的结构组织假设，不退回“全部单元必须一致”或大规模参数扫描。

## 2. 方法边界

唯一公式实现在 `src/model/QrpChannelComposition.*`，精确定义与梯度见
[模型 §5.4](content-constrained-wang-model.md#54-面向风格跨度的-qrp-通道组合)。
它接收两个 `ParametricWangQrpField` 的值和梯度，提供 Direct、Product、JointEnergy、Nested。

两个通道共用同一个 Wang 权重样本；各自仍是 QRP，不使用图片模板、规则载波或随机噪声。
这是对原方法的组合扩展，不把它称为单一 canonical QRP 的等价复现。
不修改 Wang 标签生成或边界构造，不向用户暴露 Wang 参数，不接入试调台。

Nested 不是原 `HierarchicalQrpComposition` 的边界残差叠加：
父场决定子场在哪些区域出现，子场决定区域内部的结构。
门控过渡会收缩、截短边缘子结构；它不保证保留完整的独立图元。
这一取舍在分区条纹中表现为长度渐变的条纹端部，而不是突然裁断的直线边缘。

## 3. 固定配置与案例

所有案例共用：

- 20×20 窗口，K=5，种子 `0x4d595df4d0f33173`。
- Wang：中心 0.5、rho=0.1、sigma=0.4、认证半径 0.4。
- 每个 QRP 通道 q=5，A=B=0，方向混合 t=0。
- 每个通道内部耦合分别为 `(0.11,-0.08)*该通道频率/3.15`。
  因此改变频率时并非严格只变载波；内部耦合遵循既有统一缩放规则。
- 主通道角度 0°、共同相位 0°；次通道共同相位默认 0°。
- 区域为 F<level；不做几何收缩。默认 level=0、面状填充。
- Nested：父场中心 h=0、门控宽度 w=0.35。
- 固定深色 RGB(24,55,67)、浅色 RGB(241,226,193)，边缘在线性光空间混合。

## 4. 复现与查看

```powershell
cmake --build build --config Release
.\build\Release\qrp_wang_qrp_experiment.exe --diversity-study output\qrp-diversity-study 32
python tools\build_style_board.py output\qrp-diversity-study
.\build\Release\qrp_wang_qrp_experiment.exe --diversity-study output\qrp-diversity-study\high-resolution 80
ctest --test-dir build -C Release --output-on-failure
```

根目录为 640px，高分辨率目录为 1600px。各自的 `manifest.json` 记录全部参数。
每例有 `_color.png`、`_field_gray.png`、`_mask.png`；灰度是**组合后的场**，固定映射 [-1,1]。
不再将组合场误命名为粗父场。父、子来源通过 X09、X10、X13 对照。

对照板：

- `board_selected.png`：环瓣、连续波带、交错格纹、分区条纹代表比较。
- `board_diversity.png`：首轮八个候选，包含联合能量的负面结果。
- `board_nesting.png`：低频父场、高频子场和门控输出。
- `board_grouping.png`：尺度分离、方向性子场和全幅条纹参考。

排版脚本只读取实际 C++ 输出，缩放用于展示，不参与纹样算法。
原图、对照板和 manifest 都留在忽略的 output 目录，源码内保留复现方法。

## 5. 验证与尚未解决的问题

Release 构建、六组 CTest 通过。新增一个紧凑的组合测试用例检查公式、链式梯度、
范围和真实 Wang 横竖共享边连续性；不新增测试框架。
13×3×2=78 张原图均解码且非空；基准三视图与上一轮逐字节相同。
同场不同绘制/阈值的灰度一致，640/1600 的配置和轮廓段数一致。
已检查全部小样及高分辨率网格和分区条纹，未观察到明显的瓦片接缝或出图方向异常。

轮廓仍在 [-1,21]² 以每瓦片 64 格提取，输出裁切 [0,20]²；
640/1600 共用相同几何采样率，不把提高像素分辨率说成提高数学精度。
Product 交点处梯度可能为零，现有轮廓近似未认证这些交点的精确拓扑；
现有线宽下的网格外观不代替这一认证。没有实现织物上下穿插或 Voronoi 细胞结构。

本轮只验证固定窗口中的风格候选，不证明无限非周期、外边界周期重复、
任意参数下的风格稳定性，也不宣称已证明商业适用性。
