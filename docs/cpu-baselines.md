# CPU 基准与复现记录

## 1. 用途

CPU 基线是 GPU 实现和后续交互程序的数值、坐标与视觉参照。所有图片都从同一条
`WangGrid -> CoonsWarp -> inverse -> TorusGenerator -> GradientPalette` 数据流生成。
输出文件属于生成产物，不提交到 Git。

## 2. 复现命令

```powershell
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
.\build\Release\qrp_cpu_reference.exe output\cpu
```

程序输出二进制 PPM 图像。除单瓦片外，每个基线还输出
`*_seams_x1e14.ppm`：深蓝线表示接近双精度零误差，暖色表示将独立求值误差放大
`1e14` 后的大小，洋红色表示逆映射失败。

## 4. 阶段 B 验证结果

2026-09-07 在 Windows、MSVC 19.44、Release 构建上记录：

| 基线 | 逆映射失败 | 最大逆残差 | 最小 detJ | 最大标量接缝 | 最大线性 RGB 接缝 |

| `tiling_qrp_10x10` | 0 | `1.000e-12` | `4.881e-01` | `1.665e-15` | `1.571e-14` |
| `tiling_mineral_10x10` | 0 | `9.998e-13` | `4.881e-01` | `2.415e-15` | `1.227e-14` |
| `tiling_aurora_10x10` | 0 | `1.000e-12` | `4.881e-01` | `1.471e-15` | `1.332e-14` |

所有基线的最大 8-bit 通道接缝差为 0。人工检查覆盖单瓦片、2 x 2、三套 10 x 10
图案及放大误差热图；没有发现断边、失败像素或单像素亮缝。离散瓦片扰动只承担细节
变化，主要的大尺度变化由共享世界坐标驱动，以降低方格感。当前图片仍是 CPU 参考采样，
缩放抗锯齿、材质光照和最终展示预设将在实时渲染与视觉系统阶段继续完善。
