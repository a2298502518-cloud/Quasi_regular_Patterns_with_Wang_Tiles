# Wang 纹理 Atlas 构造基线

本阶段在已有的经典 8-tile 铺砌器之前补上一条确定性的纹理 tile 构造路径。它借鉴
Cohen et al. 2003 的图像 Wang tile 思路，用四张预先确定的边标签样本生成有限纹理
atlas，再交给现有的边标签约束铺砌器。该路径用于研究“边标签如何约束可见内容”，目前
仍是与主论文并列的实验基线，不是正式预设，也不替代主论文的 Coons 逆映射方法。

## 1. 数据流与随机性边界

```text
一张源纹理
  -> 固定种子的候选样本组搜索
  -> 4 张受控源样本（NS0、NS1、WE0、WE1）
  -> 2 x 2 overlap quilting
  -> 45 度旋转与中心裁剪
  -> 8 张偶校验边签名 tile
  -> Wang 约束选片
  -> 直接栅格拼接
```

atlas builder 不接受随机种子，也不在 tile 内加入噪声、随机相位、旋转或镜像。同一组
输入样本与参数必须逐像素地产生同一套 atlas。实验中另有两个显式种子：样本搜索种子
只决定离线评估哪些 crop 组合，铺砌种子只在最后选择当前南边、西边约束下的两个合法
候选。二者都必须随结果记录，且都不会在 tile 内逐像素生成随机内容。

当前边标签数固定为 2，tile 集使用偶校验签名

\[
\mathcal S_8=\left\{(s,n,w,e)\in\{0,1\}^4
\mid s\oplus n\oplus w\oplus e=0\right\}.
\]

这 8 张 tile 可以由随机选片产生通常不严格周期的具体铺砌，但该集合本身不是数学意义
上的 aperiodic tile set。

后续字典规模实验还提供完整二值签名集合

\[
\mathcal S_{16}=\{0,1\}^4.
\]

S16 复用完全相同的四张边标签样本、旋转裁剪几何和公共角点，只补入 S8 排除的 8 个
奇校验签名。每个签名仍唯一对应一张确定性图像，不引入同签名变体、逐实例 seed 或
tile 内噪声。固定南边和西边后，可选签名由 2 个增加为 4 个。

## 2. 最小误差拼接

设源 patch 边长为 \(P\)，重叠宽度为 \(O\)，步长为

\[
D=P-O,
\]

则 2 x 2 quilt 的边长为 \(Q=P+D=2P-O\)。四张 patch 的位置固定为

```text
[ North  East  ]
[ West   South ]
```

像素误差使用 RGB 三通道平方差

\[
e(p)=\|I_{\mathrm{old}}(p)-I_{\mathrm{new}}(p)\|_2^2.
\]

竖向最小误差缝的动态规划为

\[
E_y(x)=e_y(x)+\min_{k\in\{x-1,x,x+1\}}E_{y-1}(k),
\]

横向路径使用其转置形式。合成顺序固定为 North、East、West、South；最后一张 South
patch 分别计算上侧和左侧两条独立最小缝，并使用两项条件的交集决定新 patch 的像素
所有权。这是确定性的 L 形双缝合并，不把它表述为整个 L 形区域上的全局最小割。

四条路径还必须经过由旋转裁剪几何推导出的 waypoint：每条路径穿过相应的最终 tile
角点，并在 quilt 的公共中心汇合。这个约束保证路径在裁剪区域内只从角点向内部延伸，
不会再次横穿本应完全由某一边标签样本控制的外边界。waypoint 之外的路径仍按累计 RGB
误差求全局最优，不使用手绘 cut 或经验偏移。

一张 tile 需要 4 条独立路径，因此 S8 共计算 32 条路径，S16 共计算 64 条路径。等价
代价下优先保持路径直行；最终端点等价时优先选择靠近 overlap 中线的位置，再选择较小
下标，避免平坦重叠区中的路径无意义地贴边。

按照 Cohen et al. 2003 的样本组优化思路，独立的 sample optimizer 从同一张源纹理中
反复选取四个满足最小原点距离的 crop，并用上述 32 条路径的 RGB 平方误差总和评分，
保留当前已评估候选中的最低成本组。搜索使用固定、可记录的伪随机序列；builder 本身
仍保持无 seed。这个分数只衡量切缝处的像素拟合，不等同于完整视觉质量，因此报告使用
`cut cost` 命名，并继续保留边界修正和邻域诊断，不能把“最低成本”写成“视觉最优”。

当前 optimizer 仍以 S8 的 32 条路径评分。S8/S16 对照有意复用这组已选样本，以隔离
“补齐允许签名”本身的影响；它不是经过 S16 目标重新优化后的最佳 atlas。不同规模间
比较 cut cost 时使用每条路径像素的平均值，不能直接比较 32 条与 64 条路径的总和。

## 3. 旋转裁剪几何

输出 tile 分辨率记为 \(T\)，默认取

\[
T=\operatorname{round}(\sqrt 2D)+1.
\]

令 \(M=T-1\)、\(C=(Q-1)/2\)。对输出像素 \((i,j)\)，其在 quilt 中的连续采样坐标为

\[
x=C+D\frac{i+j-M}{M},\qquad
y=C+D\frac{j-i}{M}.
\]

该式把顺时针 45 度旋转与中心方形裁剪合并为一个逆采样映射，不依赖经验比例或手工
偏移。图像坐标的第 0 行为 North。由同一映射可以验证：North/South 边沿源 patch 的
同向反对角线采样，West/East 边沿同向主对角线采样，因此相同边标签不会被转置或反向。

## 4. 离散边界后置条件

自由的 quilting 路径不保证恰好经过旋转裁剪后的四个角点；而仅有边标签的 Wang 编码也
不能令两个独立方向的源样本同时决定同一个角点。当前实现因此把四条由源样本几何推导的
边界序列作为权威边界，并使用一个显式、与样本无关的公共角点颜色覆盖最终一圈像素。

这项处理是为了满足当前直接栅格拼接所需的离散 \(C^0\) 后置条件，不能反过来证明自由
quilting 本身已经自然解决边界与角点问题。构建报告会同时记录覆盖像素数、覆盖前后的
通道修正量，以及边界到第一圈内部像素的跳变，避免“最终接缝为零”掩盖过大的修补。
如果以后进入 GPU atlas 过滤与 mipmap 阶段，还需单独加入 gutter 和滤波足迹验证。

## 5. 当前验收口径

- 最小误差 DP 与小规模暴力枚举 oracle 的最优代价一致；
- 8 个边签名唯一并满足偶校验规则；
- S16 覆盖全部 16 个签名，16 张内容图像互不相同，并固定生成 64 条独立 cut；
- S8 构建过程固定产生 32 条独立 cut，且重复运行逐像素一致；
- 32 个东西向与 32 个南北向有序兼容边对全部逐像素相等；
- S16 的 128 个东西向与 128 个南北向有序兼容边对全部逐像素相等；
- 非对称坐标样本能检出 N/E/S/W 交换、转置和反向错误；
- 修改一张源样本只影响引用该标签的 tile，不改变签名与相同 seed 的网格布局；
- 相同源图、搜索参数与搜索 seed 必须选择相同 crop；最佳组的 cut cost 不高于首个候选；
- 多个铺砌 seed 只改变 atlas 中 tile 的排列，渲染后全部接缝仍为 0；
- 调试 quilt 与 cut 路径只在显式开启时生成。

演示程序使用项目内确定性生成的四张诊断样本。它们的作用是暴露拼接路径、方向和
边界关系，并不代表已经完成视觉风格设计。等这条构造链通过数值和图像检查后，再讨论
真实素材、样本选择策略以及如何与主论文的内容模型形成可论证的关系。
