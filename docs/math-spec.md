# 数学与坐标规范

本文档是项目实现的权威数学定义。论文提供研究动机和基础构造；当论文表述与本文档
冲突时，代码与测试以本文档为准，并在修改本文档后再改变行为。

## 1. 坐标域与方向

| 符号 | 含义 | 范围或单位 |
| --- | --- | --- |
| `(u, v)` | 生成器参数坐标 | `[0, 1]^2` |
| `(x, y)` | 单位瓦片物理坐标 | `[0, 1]^2` |
| `(i, j)` | Wang 网格单元坐标 | 整数 |
| `(X, Y)` | 连续世界坐标 | 瓦片单位 |
| `(px, py)` | 屏幕或导出像素坐标 | 像素 |

边的正方向固定如下：

- South 和 North：从左到右。
- West 和 East：从下到上。

第一版瓦片不旋转、不镜像。未来若允许实例旋转，必须显式变换边编号与边参数方向，
不能只旋转最终图片。

## 2. 边映射函数

每种 Wang 边颜色 `c` 对应一个函数：

```text
f_c : [0, 1] -> [0, 1]
```

它必须连续、严格递增并固定端点。首个实现采用：

```text
f_c(t) = t + epsilon_c sin(pi t) + delta_c sin(2 pi t)
f'_c(t) = 1 + pi epsilon_c cos(pi t)
             + 2 pi delta_c cos(2 pi t)
```

端点条件由该参数族自动满足。默认边调色板从论文实现部分给出的保守区域
`epsilon_c^2 + delta_c^2 < 0.05^2` 产生，但“位于该圆盘内”不是唯一合法性判断。
调色板提交时仍必须计算导数下界和组合 Jacobian 安全裕量。

## 3. Coons 映射

给定四条边函数，参数域到单位瓦片物理域的映射为：

```text
Phi_x(u, v) = (1 - v) f_S(u) + v f_N(u)
Phi_y(u, v) = (1 - u) f_W(v) + u f_E(v)
```

Jacobian 分量为：

```text
dPhi_x/du = (1 - v) f'_S(u) + v f'_N(u)
dPhi_x/dv = f_N(u) - f_S(u)
dPhi_y/du = f_E(v) - f_W(v)
dPhi_y/dv = (1 - u) f'_W(v) + u f'_E(v)
```

行列式为：

```text
detJ = (dPhi_x/du)(dPhi_y/dv) - (dPhi_x/dv)(dPhi_y/du)
```

## 4. 可逆性条件

论文中的 `|epsilon| + 2|delta| < 1/pi` 只足以保证单条边函数单调，不能单独推出
所有四边组合的 Coons 映射全局可逆。

对某个四边组合，定义：

```text
lambda_h = min(f'_S, f'_N)
lambda_v = min(f'_W, f'_E)
Delta_SN = max_u |f_N(u) - f_S(u)|
Delta_EW = max_v |f_E(v) - f_W(v)|
```

项目采用的充分安全检查为：

```text
lambda_h > 0
lambda_v > 0
lambda_h lambda_v - Delta_SN Delta_EW >= jacobian_margin
```

当前参数族对边差使用解析上界：

```text
Delta_SN <= |epsilon_N - epsilon_S| + |delta_N - delta_S|
Delta_EW <= |epsilon_E - epsilon_W| + |delta_E - delta_W|
```

该上界可能比真实最大值保守，但不会因为离散采样遗漏峰值。

其中 `jacobian_margin` 必须为正，并在数值实现阶段通过误差分析确定默认值。满足该
条件时，Jacobian 的两个对角项为正且行列式为正；结合凸参数域上的全局单射条件，
可排除局部折叠。所有实际调色板组合还要经过稠密采样压力测试，但采样测试不能替代
解析安全条件。

非法组合不得进入正式渲染状态。UI 应保留原 committed 参数，并显示失败原因。

## 5. 逆映射

渲染需要计算：

```text
(u, v) = Phi^-1(x, y)
```

CPU 参考实现使用双精度 Newton 方法：

```text
q_(k+1) = q_k + J_Phi(q_k)^-1 (p - Phi(q_k))
q_0 = p
```

求解器必须返回具名状态，而不只返回坐标：

- 是否收敛。
- 实际迭代次数。
- 最终残差。
- 最小遇到的 `detJ`。
- 是否触发步长限制或边界保护。

CPU 版本允许回溯或阻尼；GPU 版本使用固定最大迭代次数，但必须在结束时检查残差。
边界上的一维函数通过单调求逆处理，可采用带括区间保护的 Newton 或二分法。

## 6. Wang 邻接规则

每个单元保存 `(south, north, west, east)` 四个颜色编号和独立随机种子。按从左下到
右上扫描时：

- `west` 继承左邻居的 `east`。
- `south` 继承下邻居的 `north`。
- `north` 与 `east` 由确定性伪随机序列产生。

同一项目参数与全局种子必须产生完全相同的网格。边编号匹配不允许依赖浮点比较。

## 7. 环面连续生成器

生成器 `G(u, v)` 必须满足：

```text
G(u, 0) = G(u, 1)
G(0, v) = G(1, v)
```

首批生成器包括：

### 7.1 周期 Fourier / torus-safe QRP

```text
G(u, v) = sum_k a_k cos(2 pi (m_k u + n_k v) + phi_k)
m_k, n_k are integers
```

整数波矢保证单位周期。方向集合可以逼近五重、八重、十重或十二重视觉结构，但不得
把论文中任意实方向的 QRP 公式误称为单位环面周期函数。

### 7.2 周期噪声

梯度晶格、置换和各 octave 频率都必须显式周期化。所有 octave 使用与基础环面兼容
的整数频率。

### 7.3 每瓦片内部扰动

每瓦片变化写成：

```text
G_tile(u, v) = G(u, v) + w(u, v) xi_tile(u, v)
```

`w` 在边界为零。当前实现采用具有边界二阶平滑性和大面积内部平台的窗口：

```text
s(d) = smoothstep5(clamp(d / a, 0, 1))
smoothstep5(t) = 6t^5 - 15t^4 + 10t^3
w(u, v) = s(u) s(1-u) s(v) s(1-v)
a = 0.18
```

每瓦片标量扰动和每瓦片参数域扰动都乘以该窗口，因此共享边值不依赖单元种子，且
边界一阶、二阶导数为零。需要继续在接缝邻域验证导数敏感效果，而不能只检查边界单点。

## 8. 颜色与材质

基础保证要求颜色函数 `C(G)` 连续。有限色阶在色标坐标中使用具有可配置宽度的
`smoothstep` 软阈值，等高线使用屏幕导数抗锯齿；不能直接使用未经滤波的硬阈值作为
默认路径。

调色板输入的 8-bit 色值先按 sRGB 解码到线性 RGB，再转换到 Oklab 做平滑插值；插值
结果转回线性 RGB 后进行接缝误差比较，写入显示图像时再编码回 sRGB。GPU 路径必须
遵守同一约定。

论文只保证标量颜色的 C0 边界一致性，不保证跨边界梯度和法线连续。因此：

- 不把未经处理的 `gradient(G)` 用作全局法线。
- 导数驱动的浮雕与高光在边界安全区域内衰减。
- 调色板、曝光和世界尺度调制必须在共享物理点上得到相同结果。

## 9. 像素与采样约定

屏幕和导出都以像素中心采样。网格单元采用一致的半开区间所有权，避免同一接缝被
两个实例以不同舍入方式重复覆盖。纹理采样使用显式周期寻址，并针对 0/1 边界做测试。

调试边界是最终图像上的覆盖层，不得改变底层图案求值。

## 10. 世界尺度变化

为了降低有限 Wang 组合的重复感，可以加入连续世界场 `M(X, Y)`。世界场在共享物理
位置必须唯一求值，不能从单元局部种子独立生成边界值。安全组合包括连续混色、曝光
变化和低频形状调制。参数坐标中加入由共享世界坐标计算的两个低频正弦位移；标量场
保留单方向调制，并可选叠加归一化的多方向世界细节：

```text
p0 = 2pi (fx X + fy Y)
p1 = 2pi (-0.73 fy X + 0.91 fx Y + 0.17)
p2 = 2pi ((1.31 fx + 0.47 fy) X + (-0.59 fx + 1.17 fy) Y + 0.43)
p3 = 2pi ((-1.73 fx + 0.29 fy) X + (0.41 fx + 1.53 fy) Y + 0.71)
M  = (sin p0 + 0.63 cos p1 + 0.41 sin p2 + 0.28 cos p3) / 2.32
```

世界细节振幅为 0 时不计算 `p2`、`p3`，旧预设的结果和成本语义保持不变。同一物理
接缝点的两侧使用完全相同的 `(X, Y)`，因此这些项不破坏边界一致性。

水墨预设还可以启用跨 tile 的连续世界颗粒：

```text
H = (sin(5.3 p0 + 0.8 sin(1.7 p1))
     + 0.5 cos(7.1 p1 - 0.35 p0)
     + 0.25 sin(13.7 p0 + 0.6 p1)) / 1.75
```

它只依赖共享世界坐标，不从单元种子重启，因此不会形成逐 tile 重复的笔触节奏。

最终连续标量 `s` 可以经过以下 profile，再进入同一颜色管线：

```text
natural(s) = s
ridges(s)  = 1 - 2 abs(clamp(s, -1, 1))
```

`cells` 不再是一元余弦重映射，而是在 `cellularScale * (X, Y)` 上搜索 3 x 3 相邻
格点内的确定性特征点。令 `F1`、`F2` 为最近和次近距离，`F2-F1` 控制胞元边界宽度；
最近格点的整数哈希给每个区域分配稳定色阶。区域值在 Voronoi 中轴附近通过
`smoothstep` 统一收束到深色，随后只混入少量 `tanh(s)` 细节。这样相邻区域具有不同
身份，同时任一 Wang 共享边仍只由相同世界位置和相同连续基底决定。

有限色阶数为 `L >= 2` 时，先将色标坐标乘以 `L-1`，再在每个整数区间的中点附近用
宽度 `posterizeSoftness` 的 `smoothstep` 过渡；`L=0` 表示关闭。CPU 与 GLSL 使用同一
公式，避免屏幕预览与高分辨率导出的色块层级发生变化。

`ridges` 的尖点、有限色阶的窄过渡以及胞元最近点选择都可能放大局部浮点差，因此仍
须通过 CPU/GPU 分阶段颜色误差门槛，而不能只依靠连续性推断。

## 11. 任意四边形扩展

任意四边形网格不属于第一阶段。开始该阶段前必须补充：

- 物理四边形参数化。
- 顶点绕序和共享边方向。
- 网格合法性与退化处理。
- Coons 逆映射与物理映射的组合顺序。
- inverse fragment lookup 或 forward mesh raster 的选择依据。

在这些定义完成前，不把论文中的概念性扩展表述视为已经实现的算法。

## 12. 论文差异记录

当前已知差异：

1. 论文的边函数单调条件不充分保证 Coons 映射双射；本项目增加组合安全条件。
2. 论文式 (5) 的一般 QRP 不满足单位环面周期性；本项目使用整数波矢版本。
3. 动力系统只有在参数与嵌入满足周期条件时才能定义在环面上；首个里程碑暂不实现
   论文中表述不完整的动力系统生成器。
4. 论文的硬区间着色与连续颜色映射假设矛盾；本项目默认使用抗锯齿连续过渡。
5. 论文最后三幅实验图缺失，因此视觉结果必须由本项目重新建立，不能用原文图片作为
   回归基准。
6. 论文未给出完整的任意四边形算法，该功能独立延期。
