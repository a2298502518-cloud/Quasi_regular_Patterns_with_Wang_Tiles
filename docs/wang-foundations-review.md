# Wang tiles 独立调研：匹配、内容、组织与复用

日期：2026-09-23。接续 [QRP 独立调研](qrp-foundations-review.md)。

## 1. 这轮解决什么，不解决什么

目的不是证明现有程序“身份正确”，而是分清 Wang 方法的必要条件、图形应用的额外条件，以及本项目自行选择的限制。使用图形研究技能按“文献事实 / 本文推导 / 项目选择”分别记录；PDF 对关键定义、公式和图示作了页面目视核对。

先给结论：

- Wang 的核心是有限类型与局部匹配约束，不是某种外观，也不等于随机排列或严格非周期。
- 当前二值角点成对编码边标签的 16 类型，是有效的 Wang 表示；但它只代表一个特定的受限集合。
- 对内容连续性负责的是“标签对应什么边界内容”的构造。只有相同标签，没有相应内容约束，不会自动无缝。
- 有限内容复用、长程组织、连续调参、审美和速度是不同目标，不由一次接缝测试一并证明。
- 允许 QRP 与 Wang 相互适配是合理的研究方向。现有角点状态、随机布局、C¹ 要求、整数相位闭合都不是不可改动的定义。

本轮没有修改生产 C++、Shader、参数配方或界面，没有执行外部项目，没有提交或推送。新增阅读报告和一个可丢弃的独立核对脚本；图样来自已有瓦片缓存，而不是新模型成果。

## 3. 数学对象：先把四个层次分开

### 3.1 固定方向的经典定义

设有限类型集 T，每个类型 t 带有四个符号标签 S(t)、N(t)、W(t)、E(t)。水平边与垂直边可以分别用不同字母表。铺砌是

\[
\tau:\mathbb Z^2\longrightarrow T,
\]

满足

\[
E(\tau(i,j))=W(\tau(i+1,j)),\qquad
N(\tau(i,j))=S(\tau(i,j+1)).
\]

这里 j 向上。经典问题不允许任意旋转或翻转；需要这些操作时，可以将变换后的标签与内容明确展开为其他类型，而不是运行时只转图不转标签。[W1，§4.1]

颜色是符号，不要求最终图片画出红黄蓝边框。正方形网格正是经典 Wang 的几何底板，因此“看起来还是方格铺砌”不构成否定。

历史上的出发点是逻辑判定问题：给定一套有限标签，能否判定它铺满无限平面？Wang 在 1961 年 §4.1 提出的周期猜想，是“可铺就存在周期铺法”，而不是“Wang 必须非周期”。若猜想成立，可并行寻找周期证据和有限不可铺证据来判定；后来 Berger 的结果否定了这条普遍判定路线。[W1、W8] 图形学是后来把这套局部规则用于内容组合，不能用后来的纹理应用反向缩窄原定义。

| 层次 | 定义的问题 | 不自动解决的问题 |
| --- | --- | --- |
| 类型与匹配规则 T | 什么可以相邻 | 相邻图案是否连续 |
| 布局算法 τ | 选哪个类型、如何满足规则 | 图案是否好看，能否无限延伸 |
| 内容函数 fₜ | 每类实际是什么纹样 | 任意乱排是否相容 |
| 显示 / 采样 | 怎样变成像素、几何或贴图 | 原连续场的所有性质是否保留 |

这四层可以共同设计，但不能在证明时混为一谈。

### 3.2 非周期、随机、准周期不是同义词

本报告用“无平移周期”表示一个无限配置不存在非零整数向量 p 使 τ(z+p)=τ(z)。用 **aperiodic set** 表示：集合至少允许一个平面铺砌，而且所有合法平面铺砌均无平移周期。不同文献中 periodic 有单周期 / 双周期措辞差异；引用具体定理时须保留作者语境。[W6]

因此：

1. 某个布局无周期，不代表它所用集合强制非周期。
2. 随机算法不代表每个种子都必然产生无周期结果。理想无限独立随机模型的“概率为 1”也不是“所有结果”。
3. 有限 PNG 的低自相关、FFT 或目测，都不能证明无限配置性质。
4. 无平移周期不等于保有 QRP 式的长程组织；“准周期”的具体频谱或复现定义还需另行指定。

Cohen 的实用随机集合明确允许周期铺砌；它不以最小 aperiodic 集为必要条件。[W2，§2] 相反，Stam 使用的 16 张 Ammann 瓦片具有另外的规则与替换结构，不能因为数量也为 16，就与项目的 16 张角点编码混同。[W5，§2]

**有限哈希的反例（本文直接代入）：** W3 Eq. (2) 使用长度 N 的置换 P：

\[
h(x,y)=P[(P[x\bmod N]+y)\bmod N]\bmod C.
\]

于是 h(x+N,y)=h(x,y)=h(x,y+N)。通过它生成的角点和类型场都有这两个轴向周期（可能有更小周期）。原文已提醒周期性，因此不能只摘录“stochastic”就宣传数学无周期。[W3，§4.2]

### 3.3 可铺一张大图不等于可以铺满平面

对任意有限 T，若每个大小的有限方块都可铺，则可用有限分支的紧致性论证取得无限铺砌。但这需要“每个大小”，不是测试到一个固定大小。

Jeandel 的作者说明给出一个警示：有一组 10 瓦片可以铺 200×200，却不能铺满平面。[W6] 一般 domino problem 的不可判定性是对任意集合的结论，不表示我们这种有显式构造的完整角点集合也难以求解。[W8]

## 4. 我们的角点编码究竟是什么

### 4.1 直接推导与代码对照

四角 a=SW、b=SE、c=NW、d=NE 均取 0 或 1，令

\[
id=a+2b+4c+8d,\quad
S=2a+b,\;N=2c+d,\;W=2a+c,\;E=2b+d.
\]

这就是 `src/model/EndpointWangTiles.hpp`。南北边统一从左向右读，东西边统一从下向上读，不按各瓦片逆时针边界方向分别读。

相邻两块 E=W 等价于两个对应端点都相等。竖直方向同理。故合法边匹配与共享角点状态一致，二者不是“只是长得像”。W3 Fig. 4 明确给出了 C=2 的角点集到四种边色、16 瓦片的编码。[W3，§3]

**限制：** 它不是“四条边可各自任取四种颜色”的完整 256 类型集。四条边的端点彼此关联，所以只有 16 种组合。Wang 方法本身不要求这种关联。

W1 §4.3 已讨论角点矩阵与边标签的编码，并说明可以用更大块构造反向的可铺性归约。因此 W3 中反向“一般不行”不能被理解为两种问题在允许扩张状态/分块后仍绝对无法互相编码。应区分“原尺寸、原类型逐块表示”与“改变表示的归约”。

### 4.2 相同数量，不同表达空间

**本文组合计数：** 两种集合各有 16 类型，却具有不同合法局部配置。

| 集合 | 完整定义 | 2×2 块合法配置数 |
| --- | --- | ---: |
| 当前二值角点集 | 2⁴ 种四角 | 2⁹ = 512，来自 3×3 个共享顶点 |
| 完整二值边集 | 2⁴ 种四边 | 2¹² = 4096，来自 12 条不同网格边 |

计数针对自由外边界、固定方向、类型可区分且每组标签只有一个内容类型。它不是“4096 比 512 更美”的评分。独立脚本穷举了两个集合的全部 16⁴ 个候选，结果与计数一致。

当前集在每一邻接方向有 64 个合法有序类型对；0、15 均能合法自重复。由此直接知道当前类型集**不是 aperiodic set**，但不影响其作为图形学 Wang 集的有效性。

## 5. 标签何时真的保证内容接上

### 5.1 连续场的充分条件：本文统一表述

固定一个风格配置 θ，为每类定义连续场 fₜ:[0,1]²→R。在所有合法水平有序对 (t,s) 上要求

\[
f_t(1,v)=f_s(0,v)\quad (0\le v\le1),
\]

竖直方向作对应要求。这些条件覆盖整条闭边，且每块自身连续，则任意合法布局的分片场为 C⁰：边上由等式相接，四角交会处由相邻等式的传递性一致。

若各块在闭方形上具有连续的一阶导数，再要求共同坐标中的梯度相等，就得到 C¹。单位同向正方形中，水平缝还需 ∂u fₜ(1,v)=∂u fₛ(0,v)；切向导数一致可由可微的相同边迹推出。若使用两块各自的**外法向**，它们方向相反，对应外法向导数应相反，不能误写同号。

这是足够条件，不声称 C¹ 是所有装饰图案、阈值区域或矢量轮廓的唯一正确要求。对全部标签匹配对检查也可能强于某个受限全局布局真正需要的条件，但能直接支持“任意合法重铺”。

### 5.2 有限标签代表的是一套内容接口

可为每个边标签 c 规定共享边迹 g_c(s)，必要时再规定共同坐标中的法向导数 d_c(s)、跨边曲线交点/切线或一定宽度的邻域。瓦片内容必须实现它所携带的四组接口，并在角点满足相容条件。

只让四个端点一样不够：g(s)=s 与 g̃(s)=s² 在两端相同，中间不同。角点标签必须通过一个确定的内容构造约束整边，不能凭 corner tiles 的名字就跳过内容证明。

**本文自由度示例：** 给已有 C¹ 相容场加上

\[
b_t(u,v)=u^2(1-u)^2v^2(1-v)^2r_t(u,v)
\]

（rₜ 为 C¹），不会改变边界值或梯度。因此匹配条件并不唯一决定内部。这个示例仅说明存在内部自由度，不是提议用多项式小扰动作为新纹样方法，也不是本项目创新声明。

### 5.3 corner problem 不否定上面的拼接推导

W3 讨论的是传统边式内容构造不直接提供充分的对角邻域信息，导致角附近大图元、采样邻域等难以协调。对任意受限 Wang 集，不能泛化为“所有对角类型都可以任意组合”；间接约束仍可能限制它们。

如果一套连续函数已经在所有合法闭边上精确一致，四角的点值不会神秘地产生另一个 C⁰ 缝隙。实际 corner problem 往往涉及邻域结构、共同角补丁的限制或滤波，不是反驳基本粘合事实。角点构造可以改善这些问题，但仍不自动保证好看的结构或全部采样尺度正确。[W3，§2、§5–7]

### 5.4 “独立生成”不等于“禁止共同设计”

Cohen 的方法会共享边界图元/样本并预处理内容；Stam 让相容瓦片共享输入噪声的边邻域，再应用有有限支撑的纹理算子。[W2，§3；W5，§3–4]

对本项目真正需要的独立复用条件是：**固定 θ 与类型 ID 后，局部内容确定；放到另一合法位置无需知道那个实例的绝对位置再重新造图。** 它允许共享边界字典、离线联合优化、统一 QRP 参数。调节 QRP 参数后重新生成一整套相容库也是允许的，不要求一套固定像素永远容纳所有风格。

布局算法用全局整数坐标选择 ID，与内容函数偷用实例全局坐标，是两回事。Wei 的随机访问映射正是前者。[W4，§4.2]

## 6. 算法和公开工程：不同路线解决不同问题

### 6.1 三种常见布局机制

| 机制 | 成立条件 / 代价 | 不能偷换的结论 |
| --- | --- | --- |
| 从西北开始逐行选择 | 对每个可能的 N、W 输入标签对，至少存在一个候选；每对有两个候选则可随机选择 | 对自由外边界的构造，不自动解决预先固定的四边边界或环面闭合 |
| 对共享边或顶点坐标哈希 | 共享位置产生一致符号，再查完整类型表 | 需要相应完整表；有限哈希未必无周期 |
| 一般约束求解 / 传播 | 在允许集合中排除不相容候选，需要处理矛盾或回溯 | 求解器名字不保证任意规则都可铺，也不保证内容连续 |

Cohen 使用前一种充分构造；Wei 为直接访问采用完整边组合，类型数量为 K_h²K_v²，而不是前者的 2K_hK_v。[W2，§2；W4，§4.1–4.2]

当前项目的角点法不要求四种边色的所有 NW 组合都出现：北边与西边必须同意公共 NW 角状态。直接生成共享顶点后，四角总能查到一张瓦片，所以无需 WFC 去重新求解一个已经保证合法的配置。[W3，§4；本文代码核对]

### 6.2 WFC 不是 Wang 的定义，也不是自动补全内容的方法

阅读 [P1] 的 README、`SimpleTiledModel.cs` 的邻接表构建/旋转展开、`Model.cs` 的 Observe / Propagate / Run。它把允许的相邻类型读入表，再选择候选并传播；可能返回矛盾。没有克隆运行、性能测量或审阅全部项目。

README 也区分 Wang 与 non-Wang tile sets。**本文简单反例：** 若右邻接集合 A→{X,Y}、B→{Y,Z}，且不允许其他组合，不能在原样不拆分的 A、B、X、Y、Z 上用单个边色相等实现：为了共同允许 Y，A、B 的右边色必须相同，那么两者的允许集合也应相同。一般允许表比这种逐块单色表示宽；允许增加状态或分块后的编码是另一个问题。

因此不是“换成有名的 WFC 工程”就会解决 QRP 的边界构造或长程形态。

### 6.3 stb 的例子说明工程还会主动处理重复感

阅读 [P2] `stb_herringbone_wang_tile.h` 的头部说明、六个约束标签的类型结构、角点颜色生成与 anti-repetition 段。其人字形矩形块不是本文单位正方形网格的直接实现；它提供边/角约束，并额外调整局部重复。没有执行、移植或评价质量优劣。

这个工程说明：满足匹配后，重复感仍可能需要独立处理。其启发是职责区分，不是引入另一个框架。

### 6.4 解析连续不等于纹理过滤正确

Wei 的作者网页明确补充：只保证最外一行 texel 一致，不足以保证低分辨率 mipmap 正确；过滤足迹更大时需要相应邻域，输入图集的最粗 mip 层也不足以代表任意大的虚拟纹理。[W4，作者 Notes and Hindsights]

所以 C⁰ / C¹ 的场证明、阈值轮廓的性质、离散像素接缝、图集滤波应分别验证。相邻像素采样点本来不同，不能机械要求两块边缘像素列完全相等；也不能用标签计数代替连续场验证。

当前图板是固定分辨率 PNG 拼接，不涉及新图集或 mipmap；本轮不因此追加 GPU 工程。

### 6.5 性能价值须指定对照

**本文成本拆分：** M 个类型，每块 P² 像素、每像素 R 个模态，缓存生成约 O(MP²R)。输出 K 个实例，直接拼成大图仍需 O(KP²) 的复制与输出空间；仅瓦片缓存为 O(MP²)。随机访问虚拟纹理可以不存整张输出，但显示仍有逐可见像素开销。[W4 提供后一种架构，复杂度拆分为本文分析]

与直接逐像素计算昂贵内容比，预计算可能省生成成本；与普通单次纹理读取比，额外哈希/查表可能更慢。没有当前机器、目标分辨率和同质量基线，不能直接宣布“商业价值就是性能更好”。

## 7. 局部变化为何不自动产生长程组织

### 7.1 当前随机状态的范围

`apps/TileStudyExport.cpp::makeLayout` 使用共享二值顶点，并固定一处的四个顶点来确保类型 6 出现。它不是任意摆放 16 张图，而是从一个保证相容的顶点配置导出 ID。

**本文理想化分析：** 若顶点彼此独立随机，一个类型只依赖周围四个顶点。两块的顶点集不相交时，其 ID 独立；在网格偏移满足 |Δx|≥2 或 |Δy|≥2 时已如此。实际 PRNG 与固定类型标记不严格等同这个无限独立模型，但不能反过来把它们称为经过设计的长程相位组织。

边界连续的带状图案仍可能贯通许多瓦片，所以“ID 远处独立”不等于所有视觉对象都局部终止。它说明的是布局生成没有显式携带远程相位状态。

### 7.2 随机 ID 也可以保留网格骨架

固定风格和瓦片内坐标 (u,v)，若各网格位置具有相同类型概率 pₜ，则

\[
\mathbb E[I(i+u,j+v)]=\sum_t p_t f_t(u,v)=\mu(u,v).
\]

如果 μ 随瓦片内坐标变化，期望图就在每个网格单元重复。这是“布局在变，但平均轮廓位置/纹样骨架仍像重复”的一种机制。它是本文分析，不是本轮测出了所有现有配方的频谱；μ 也可能为常数，所以不能断言有限 Wang 必然有明显方格伪影。

有限库必须反复用到内容。重复本身不应被当作错误：装饰纹样往往需要节奏。要讨论的是复用哪些结构、变化哪些结构，以及这些变化是否对应可解释的 QRP 参数。

### 7.3 Wang 也并非只能表达随机性

W6 的自相似结构和 W7 的环面旋转 / Markov 分割提供了真实反例。W7 的摘要谨慎区分：11 瓦片例子的构造对应 Jeandel–Rao shift 的一个真子系统；另一个 19 瓦片例子才等于相应最小 Wang shift。不能将二者或“所有 Wang”混成一个结论。[W6–W7]

这条文献线提示可以研究组织与匹配的共同设计，但没有证明它可直接保留当前 QRP 公式、允许我们的全部参数连续调节或生成商业风格。本轮仅标出连接，不选择立刻移植。

## 8. 当前工程的科学定位

| 实际机制 | 可支持的陈述 | 不应升级成的陈述 |
| --- | --- | --- |
| `EndpointWangTiles.hpp` | 二值 corner tiles 的四边编码正确 | 这是唯一 Wang 规则，或者必须始终 16 类型 |
| `PhaseCompatibleQrpTiles.cpp` | 在当前公式下，可推导合法接边的值与梯度一致 | 这就是原 QRP 的完整保留，或唯一相容方案 |
| 同一标量 Sₜ 驱动各模态的状态项 | 提供一条受约束的相位状态路径 | 已覆盖任意多维形态组织 |
| `makeLayout` 的共享顶点生成 | 特定有限库可直接合法铺砌 | 所有 Wang 集都可以同样随机生成 |
| `assemble` 只查 ID 并复制像素 | 当前导出实例可以原样复用 | 全项目每条历史路径都已满足相同条件 |
| QRP 参数改变后重建库 | 用户可以不接触 Wang 技术参数 | 每种参数变化都具有连续且可预测的风格效果 |

### 8.1 现有接边推导为什么成立

将代码中的一条模态记为

\[
\Phi_{r,t}(u,v)=\omega_{rx}u+\omega_{ry}v
+\Delta_{rx}h(u)+\Delta_{ry}h(v)+\beta_r+\gamma_rS_t(u,v),
\]

其中 h(s)=s²(3−2s)，Δᵣ=2πnᵣ−ωᵣ，nᵣ 各分量取最近整数绕数。Sₜ 用同一个 h 对四角二值状态插值。

对一个合法左右邻接，同一高度的两侧 S 值及切向导数相同，法向导数因 h′(0)=h′(1)=0 为零。两侧 Φ 只差 2πn_rx，且相位梯度一致，因而每条余弦模态的值与梯度一致。固定模态系数的和仍一致。竖直边同理。

这是一种明确的**充分构造**，不是 Wang 强制要求每条波的相位绕整圈，也不是完整内容模型的唯一解。整数绕数改变时的调参跳变，旧 [相位兼容研究第 7 节](history/qrp-phase-compatible-tile-study.md) 已记录；上轮 QRP 报告新增的是反例，本轮已纠正“新发现”的标题。

### 8.2 我们需要撤回或限制的观点

1. 不能用“是不是标准 / 权威路线”替代对问题的研究；要明确对象与保证，允许双方修改。
2. 不能把正方形网格、隐藏标签、允许周期布局当作“不是 Wang”的证据。
3. 不能把 corner 编码成立等同于整个方法已充分发挥 Wang 价值。
4. 不能把增加随机性、像素差异或预设数量等同于风格跨度。
5. 不能把所有接缝证明升级为原 QRP 全局频谱、拓扑或调参连续性的证明。
6. 不能把“同库可复用”误解为内容预处理阶段不准共享信息。

## 9. 与 QRP 对接前的一条必要边界：本文推导

下面不是 Wang 或某篇 QRP 论文的原结论，也不作为新颖性声明，而是两种要求之间的一个简单约束。

**假设：**

- F 是整个平面上的实解析标量场，例如固定参数的有限余弦波叠加；
- F 没有非零整数网格平移周期（若瓦片边长为 L，则指 LZ² 上的非零周期）；
- 要用有限个固定、仅平移复用的内容函数，在无限网格上逐点精确等于 F。

**推导：** 有限库在无限位置必有同一类型出现于两个不同位置 p、q。因此对瓦片内部开集的局部坐标 u，

\[
F(p+u)=f_t(u)=F(q+u).
\]

令 d=q−p。实解析函数 G(x)=F(x+d)−F(x) 在一个非空开集上恒为零，根据解析函数的唯一延拓，在连通的整个平面上恒为零。这使 d 成为非零平移周期，与假设矛盾。

**准确含义：** 在上述条件同时成立时，不可能用有限固定内容库逐点精确复现整个原非周期解析场。仅两处完全相同的开集副本就已触发这个约束。

**不包含的结论：**

- 不否定 Wang 与 QRP 的结合；恰恰说明必须讲清楚保留什么、扩展什么。
- 不适用于只比较有限像素、二值阈值后的区域、近似结构或感知相似度；这些不满足本证明的逐点解析场相等条件。
- 不否定具有周期的 QRP 特例，也不否定非解析的新拼接场具有有序非周期结构。
- 不推出“必须采用当前相位闭合”；相容边迹、模态条件、局部拓扑、类型状态或布局组织都可以参与新构造。

用户已接受边界约束下的 QRP 扩展，所以接下来不再反复询问是否允许扩展。应把重点放到：扩展后保留了什么有意义的 QRP 组织；Wang 的有限状态与接口怎样承载它；哪些 QRP 参数仍对应可预测的设计变化。

## 11. 下一步研究应收敛到一个问题

建议讨论的论文问题（尚未确立贡献）：

> 如何把 QRP 的可调形态组织转化为有限、可复用且边界相容的内容单元，使其在不同合法铺砌中保有可解释的风格变化？

不要立即把这个问题等同于“继续调当前闭合项”。下一轮应联合两份报告，做一次方法层的选择：

1. **规定所要保留的 QRP 性质。** 在相位关系、方向结构、等值线组织、局部对称等中选主对象；明确哪些只近似保持。不能全部含糊承诺。
2. **选择真正需要交换的边界信息。** 依据主对象确定边迹、曲线交点/切线、相位状态或邻域；让匹配规则与内容一起设计，不预先锁死二值角点或独立随机布局。
3. **区分同风格重铺与跨风格控制。** 前者检验 Wang 复用价值，后者检验 QRP 参数语义；两者都不以最大随机性为目标。

完成这一步后再挑一组最小对照验证，不先扩充界面、预设、测试框架或第三方工程。若有两个科学目标无法兼得，应把具体取舍交给用户，而不是继续小改默认参数。
