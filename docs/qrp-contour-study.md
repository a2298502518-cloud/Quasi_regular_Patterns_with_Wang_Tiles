## 1. 当时的判断（审美前提已由上方说明修正）

- 将场值带改成几何距离描线，解决的是线宽受局部梯度影响的问题，不是基本形状的规则性。
- 向内收缩可增加留白、断开部分细颈，但无法统一圆环、花瓣和连接体的造型；
  大幅收缩还会损失小单元。
- 固定同一个 QRP 场，改变等值区域的选取：中间层级保留环、瓣等关系，也保留复杂连接；
  更极端的层级得到简单单元，却逐渐变成大小不一的点状图案。
- 因此，不把四组干净的绘制样例称为四种成熟风格，不把点状化视为问题已经解决。
  下一重点是局部形状的家族一致性，以及在参数变化时能否保留这种一致性。

这些是固定窗口内的视觉观察，不是全参数空间证明或美感评分。

### 2.1 等值区域与几何距离

默认深色区域为 `C < level`，不是正值区域。原对照板中把深色标成正值的文字已纠正，
旧图和旧公式不因此改变。V04–V08 另比较 `C > level`；这只改变区域选取，原始场完全相同。

在固定的 64 格/瓦片顶点网格上提取 `C=level` 的分段线性轮廓。
marching squares 的四边交点歧义用双线性渐近判别处理：
角点按左下、右下、右上、左上记 f0…f3（均已减 level），检查 `f0*f2-f1*f3`。
精确为零时保留经过鞍点的临界交叉，不随意选择一条对角线。

判别依据参考 Nielson 与 Hamann 的
[The Asymptotic Decider: Resolving the Ambiguity in Marching Cubes（1991）](https://graphics.stanford.edu/courses/cs164-10-spring/Handouts/paper_p83-nielson.pdf)，
本项目只使用其双线性面歧义判别思想，不是复现三维 marching cubes。

记 D 为到提取轮廓的有符号几何距离，选中区域内为正。
令 `L=2π/κ`，s 为收缩比例，w 为描线宽度比例：

```text
面状：D > s L
线描：|D - s L| < w L / 2
```

L 是特征波长，不是 QRP 的严格重复周期。距离单位为世界坐标，
不是场值差；像素边缘只做线性光覆盖混合。距离搜索截断在当前绘制需要的范围内。

距离来自分段线性轮廓，不能把它称为解析场的精确距离或 C¹ 曲线。
偏移轮廓可能消失、分裂或形成尖角；线带在近邻处仍可能合并。
解析场的内部共享边 C¹ 性质不等于提取形状的拓扑或审美保证。

### 6.1 这轮实际做了什么

原来的 A、B 仍分别乘 cos(2θ)、sin(2θ)。这增加了一个相位自由度，
并没有改变“标量叠加后取等值区域”的造型机制。
完整定义见 [模型说明 §5.3](content-constrained-wang-model.md#53-共同相位研究参数)。

### 6.2 当时提出的方法问题（后续解释已修正）

现有生成规则只约束连续场的数值、方向和共享边，并未直接约束：
什么构成一个基本单元、单元之间允许哪些变形、何处允许连接、形状应保持何种局部对称。
由这些场约束不能直接推出设计意义上的形状秩序。

下一轮应先提出并比较新的生成规则，例如由 QRP 的几何关系组织局部单元，
在生成阶段显式约束其对称、尺度与连接，而非继续扫描相位、阈值、线宽。
这不是已经实现或已经选定的新模型。必须说明新规则保留了 QRP 的什么作用，
以及相对 A 的全局等值线方法改变了什么；不能悄悄退回固定规则载波或通用图标排列。

后续的主线应是“生成机制与设计约束 → 完整窗口及局部纹样对照 → 邻近控制的稳定性”，
而不是“更多旋钮 → 挑选一张好看的图 → 界面化”。
