# 独立 QRP Wang 瓦片研究（2026-09-22）

> 历史阶段记录：旧代码与命令已归档至 `b58337a`，见 [恢复说明](legacy-experiments.md)。当前入口见 [README](../README.md)。

后续已完成 [相位兼容候选](qrp-phase-compatible-tile-study.md)：保留有限类型与纯 ID 铺砌，
改为逐模态约束相位而非混合场值；有造型进展，但整数相位闭合的周期骨架是新的理论取舍。
本文保留第一轮公式、负面结果与当时的下一步，不将两个候选的结论混用。

## 1. 问题修正与本轮结论

主线仍然是通过本方法生成风格多样的纹理：QRP 负责造型，Wang 负责铺砌，不向用户开放
Wang 参数。用户指出，前一阶段虽然生成了多种风格，却没有充分体现内容瓦片的独立复用。

旧模型 `C(g+u, Wτ(u))` 使用实例全局位置 g。其全局 C¹ 推导仍成立，但同一种标签签名
搬到别处会重新取不同的 QRP 内容。因此，旧结果只能证明“Wang 标签调制全局 QRP”，
不能据此声称“预先生成的同类内容瓦片可在任意合法布局中原样复用”。需要修正的是这一
方法定位与推论，而不是把旧梯度、范围或风格对照全部判错。

本轮实现的位置无关形式是 `Tτ(u; p)`：p 是整套瓦片共同的 QRP 风格参数，τ 是有限类型，
u 是局部坐标。先生成 16 张图片，再仅按类型编号复制到两个不同的合法 8×8 布局。

结果分开评价：

- **机制成立**：两种布局确实复用同一套缓存内容；合法共享边的场值与完整梯度一致。
- **造型尚未达标**：固定来源有较明显的方格重复；按边界邻域匹配来源虽降低局部数值误差，
  但部分环瓣粘连、方向性波带出现端部和断连，并未稳定保留全局 QRP 参考的造型。
- 两方向乘积仍与直接场明显不同，但不能用“已有风格差异”掩盖基础造型受损。
- 当前只是可复用机制的研究候选，不替换此前用户认可的效果，不接入试调台。

这里的“造型受损”指相对于同参数参考，连续波带或环瓣组织发生了明显变化；不是主张
所有局部形状必须一致，也不把更规则或更不规则自动等同于更美。

## 2. 有限类型、标签与局部坐标

单位瓦片轴对齐，不旋转、不镜像。四角状态 `aSW,aSE,aNW,aNE ∈ {0,1}`；类型编号为

`id = aSW + 2 aSE + 4 aNW + 8 aNE`。

边颜色编码两个有序端点：`c(a,b)=2a+b`。南北边从左向右，西东边从下向上：

```text
S = c(aSW,aSE)    N = c(aNW,aNE)
W = c(aSW,aNW)    E = c(aSE,aNE)
```

这是四种颜色、16 种允许类型的 Wang 集合，**不是全部 4⁴ 个独立边签名**。
相等边颜色同时确定这条边的两个角点状态；沿共享边传播即可满足四瓦片交点的一致性。
这轮没有额外的边内部状态或同签名内部变体。原 `WangGrid` 的全 K⁴ 生成器不适用于
这个受限集合，故不复用它来产生不允许的签名。

研究入口随机生成共享顶点状态，再将每个四角组合映射为类型；只用于生成合法布局。
内容生成器只接收类型和局部坐标，不能读取布局、实例位置或邻居。

## 3. 九块来源的凸组合

令 `Qp(x)` 为现有参数化 QRP，将旧的 Wang 相位调制设为零。保留方向数、方向权重、
旋转、A/B、共同相位和通道组合等 QRP 语义。每个来源均是 `Qp(Lu+o)`，L 为源跨度，
o 是有限目录中的源偏移。不是引入外部图片、规则载波模板或随机噪声。

对 `0<δ<1/2`、`t∈[0,1]`，定义

\[
b_\delta(t)=
\begin{cases}
1-3(t/\delta)^2+2(t/\delta)^3,&0\le t\le\delta,\\
0,&t>\delta,
\end{cases}
\]

\[
w_0(t)=b_\delta(t),\quad
w_1(t)=b_\delta(1-t),\quad
w_I(t)=1-w_0(t)-w_1(t).
\]

三个权重非负、和为 1，在端点和支撑边界的一阶导数均为零。
分别为两种角点、四种竖边、四种横边、16 种内部选定源偏移：
`oV[a]`、`oE[c]`、`oH[c]`、`oI[τ]`。

对 `i,j ∈ {0,I,1}`，源片定义为

\[
\begin{aligned}
P_{ij}(u,v)&=Q_p(L(u-i,v-j)+o_V[a_{ij}]),&&i,j\ne I,\\
P_{iI}(u,v)&=Q_p(L(u-i,v)+o_E[c_i]),&&i\ne I,\\
P_{Ij}(u,v)&=Q_p(L(u,v-j)+o_H[c_j]),&&j\ne I,\\
P_{II}(u,v)&=Q_p(L(u,v)+o_I[\tau]).
\end{aligned}
\]

其中竖边 `c0=W,c1=E`，横边 `c0=S,c1=N`。最终场为

\[
T_\tau(u,v)=\sum_{i,j\in\{0,I,1\}}w_i(u)w_j(v)P_{ij}(u,v).
\]

解析梯度包含来源梯度和权重梯度两部分，例如

\[
\partial_u T=\sum_{ij}
\left[w_i'(u)w_j(v)P_{ij}+w_i(u)w_j(v)\partial_u P_{ij}\right].
\]

来源梯度也乘上 L，不能漏掉局部坐标的链式因子。

### 3.1 为什么可以独立接边

在东边 u=1 和西边 u=0，两侧的竖边来源都在同一有符号法向 n=0 求值：
左瓦片使用 n=u−1，右瓦片使用 n=u；两者 `∂n/∂u=+1`，不是相反的外法向。
端点相同使角点来源一致；其余来源的权重及法向权重导数为零。因此两侧的值、
切向导数和固定坐标方向的横向导数一致。南北边同理；四角也一致，得到分片 C¹ 场。

该论证对本目录中任意合法邻接成立，并不依赖两张特定布局。若两通道分别满足这些条件，
其乘积及解析梯度也保持接边一致性。

### 3.2 哪些性质没有得到保证

- 凸组合保持 `[-1,1]`；在 `[δ,1−δ]²` 完全恢复内部选定的 QRP 来源。
- **过渡区不是原单一 canonical QRP**，是多个 QRP 来源的空间凸组合；不声称全图仍有
  原全局 QRP 的对称性、频谱或拓扑。
- C¹ 不保证正则零等值线、无粘连、无小碎片、波带贯通或视觉上不显网格。
- 本轮 δ=0.2，内部原样区面积仅 `(1−2δ)²=36%`，过渡带并集占 **64%**。
  因而不能把它描述成“只在一条很小接缝上修补”。这是当前方法的重要代价。
- 不保证大图外边界周期衔接。集合含可周期铺砌的类型，不能称作严格非周期瓦片集。

## 4. 来源选择对照

固定目录用 `oV[0]=(0.2,0.3), oV[1]=(0.9,0.4)`。每条边的初始偏移是将两个角点
来源变换到该边坐标后取平均；内部初始偏移是四个角点来源变换到内部坐标后的平均。
这只是确定性的起点，**平均坐标不等价于平均相位，也不保证好的内容兼容性**。

匹配目录在同一个九块组合公式下，依次选择边来源和内部来源。候选为固定偏移本身，
加上整数二维偏移 `{-6,…,6}²`。选择目标为样点上的平均

\[
E=\operatorname{mean}\left[(Q-Q_*)^2+
\frac{0.1}{(L\kappa)^2}\|\nabla_u Q-\nabla_u Q_*\|^2\right].
\]

先在每条边的两个端点邻域比较边与角点来源；再在四条边的内部过渡位置比较内部与
已选边来源。每条边用 12 个样点，每种内部用 20 个样点。确切位置和完整偏移目录保存在
实现与 manifest 中。来源选择发生在瓦片库构建时，不发生在每个实例的铺砌时。

固定候选始终保留，所以每一步不会增加其局部目标值。但这不是最终场的整体能量，
也不是美感评分、零集拓扑匹配或跨瓦片宏观组织目标。尤其不能从较小误差推出贯通波带。
匹配政策中的 `interior_fixed` 针对**已选新边源**计算，与固定政策的内部目标不同，
不应跨政策直接相除来宣称统一质量提升。

视觉结果支持：这种逐级独立、稀疏样点的来源匹配不足以同时保留局部造型与接边。
本轮保留它作为负面对照，不通过扩大搜索或微调权重直接声称问题已解决。
另外，有限目录的最优候选会随 QRP 参数改变而切换，当前不保证调参过程的图样连续变化。
空间上的 C¹ 与参数变化时的平滑性是两回事，后续不能混为同一个控制保证。

## 5. 实验配置、输出与复现

三类 QRP 配置分别比较 fixed / matched，共六例：

| 名称 | 方向偏置 η | 通道关系 |
| --- | ---: | --- |
| rings | 0 | 单通道 |
| ribbons | 1.5 | 单通道 |
| product | 两通道均 1.5 | 第二通道旋转 90°后相乘 |

其余均为 q=5、κ=3.15、A=B=φ=t=0、L=4、δ=0.2、旧 Wang 相位调制为零。
每个乘积通道独立建立兼容源目录，然后在瓦片内部进行通道组合。
只用 `F<0` 点式双色填充，每像素 2×2 覆盖采样，在线性光空间混色；本轮不含轮廓距离
描边、几何收缩或全图接缝后处理。上述邻域算子的独立瓦片实现需另行论证。

两种布局种子为 20260922、20260923，均为 8×8。类型 6 分别固定在 `(1,2)`、`(5,4)`；
坐标从左下角计，实际两种布局都出现全部 16 种类型，类型 6 各出现六次。
更改固定位置时调整共享角点，不强行覆盖单瓦片边标签。

```powershell
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
.\build\Release\qrp_wang_qrp_experiment.exe --tile-study output\qrp-tile-study 96
python tools\build_tile_board.py output\qrp-tile-study
```

输出包含 96 张 96×96 源瓦片、12 张 768×768 布局、三张同尺寸全局 QRP 参考，
共 111 张原始 PNG。参考不含 Wang，且不是此前全局 Wang 调制基准；使用相同 QRP 参数、
源跨度和采样密度，供造型比较。对照板使用缩略图，不参与算法。

- `board_comparison.png`：三类参数的全局参考 / 固定来源 / 匹配来源。
- `board_reuse.png`：matched_rings 瓦片库、两种布局与编号；彩色边和红框仅为诊断标记。
- `manifest.json`：参数、完整源偏移、每步匹配误差、边标签、布局 ID 与抽样接缝误差。

实现的职责边界：`ReusableQrpTiles` 定义场与源目录；`ReusableTileStudy` 编排布局、
烘焙和复制；Python 只核验像素与排版。铺砌函数仅接收缓存图片与 ID，不接收场求值器。

## 6. 必要验证与下一步

Release 构建和七组 CTest 通过。新增紧凑测试覆盖：全部 16×16 类型对中的合法邻接，
两方向各 64 对；值与完整梯度；角点、边与过渡区；内部恢复；凸组合范围；
过渡交叠区的解析梯度中心差分；固定/匹配两种政策的局部目标非增。

两张实际布局上、六个案例的共享边采样最大值/梯度误差均为 0；这是一组数值结果，
一般连续性依据 §3 的解析构造。111 张原图全部解码；排版脚本另外核验全部 768 个
瓦片实例与对应源 PNG 的 RGB 逐像素一致。检查的是实际成图，不只比较类型编号。
已目视检查三类六例对照与复用板。不增加 UI、大规模防御测试或美感指标。

下一步应研究 **QRP 造型与边界的联合兼容生成**：

1. 保留“有限固定库、纯 ID 铺砌、相等边标签约束内容”的接口与证据。
2. 重新设计源目录的联合约束，而不是继续逐块独立选源再大面积标量混合。
3. 至少区分边上的轮廓交点、切向与带状结构的连接关系；仅匹配值/梯度均方误差不够。
4. 检查约束是否仍允许环瓣、波带和通道组合三类结构，不能为救单一风格转向固定模板。

这些是下一轮需先推导的方向，**尚未实现或证明可行**。当前不能宣布已得到满意的
通用造型解，也不应把所有随机局部混合结果自动排除；具体审美仍需结合实际图样判断。
历史 Word 报告尚未同步本轮定位修正；不能将其作为独立可复用内容瓦片的证明。
