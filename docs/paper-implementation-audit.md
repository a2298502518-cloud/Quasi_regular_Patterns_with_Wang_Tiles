# 主论文与当前实现审计

本文档核对本地主论文《Quasi-regular Patterns with Wang Tiles》与当前 C++/GLSL 实现。
本地主论文是项目要实现和持续修订的研究对象；外部文献只用于澄清术语、补足理论背景、
比较相关方法和启发后续设计，不是本项目需要逐篇复现的目标。

## 1. 研究层级与审计结论

当前主方法已经形成一条可验证的无缝渲染管线：合法的 Wang 邻接网格为每个方格提供
四个边标签；标签选择四条边重参数函数；四条边函数经 Coons 型混合产生单位方格内的
坐标变形；渲染器求该变形的逆映射，再采样定义在单位环面上的周期生成器。CPU 与 GPU
共同实现这条数据流，测试覆盖邻接、边界周期性、Jacobian 安全界、逆映射残差和最终
颜色接缝。

这条管线应被视为**主论文提出并由本仓库实现的方法**。Cohen 等人的 Wang tile、Yin
等人的 QRP、Wang 等人的四边形不变映射分别提供背景和借鉴，但不能取代主论文自身的
算法定义，也不应被当作验收当前实现的逐式模板。

此前新增的预设 6–8 把风格生成逻辑放在主方法之外，尤其是连续世界坐标 Worley 场和
独立的 Wang 边连接图形，使视觉结果不再主要由“边标签—Coons 逆映射—周期生成器”这条
主论文管线产生。本轮已决定完整移除这些方向，保留预设 1–5 与经过验证的核心管线；
后续风格从主方法内部重新设计，而不是把已偏离的实现强行解释为论文算法。

后续两次探索也未通过准入。`FlowingRibbon` 只更换公共周期母纹，仍保留明显的长程
周期节奏；`StructuredBankV1` 则以边签名、tile seed 和风格种子生成内部编号与多组
相位，并用高强度边界窗口替换公共母纹。后者在数值上保持了共享边连续，但消融结果
表明其宏观外观主要由随机内部而非 Coons 形变决定，因此同样已从实现中移除。

公开项目 `sashaouellet/WangTile` 提供了“边界编码与 tile 内容构造应分开考察”的
启发，但它采用预生成图片 tile、patch quilting 和有限 tile set 选择，与本论文的
单一程序化环面场路线不同。本项目没有复制其源码或资产，也没有把该项目描述成主论文
算法的一部分。为了让两条路线可以实证比较，当前另行实现了一个 clean-room 的经典
图像 Wang tile 基线：独立枚举 8 个偶校验边签名，用受约束的扫描线选择有限图像 tile，
再直接拼接。它是相关方法对照，不是新预设。

## 3. 外部文献的正确用途

### 3.1 Cohen et al. 2003：Wang tile 语义

Cohen 等人的工作帮助区分边颜色标签、tile set、合法铺砌、随机非重复外观和严格的
aperiodic tile set。对本项目最重要的启发是：相邻标签相等只是拓扑条件，还需要说明
标签如何影响最终内容。它用于检查主论文论证是否完整，不意味着本项目必须采用纹理
atlas 或复现其最小 tile set。

### 3.2 Lagae & Dutré 2006：角点问题

边标签只直接约束上下左右邻居，不自动约束对角邻居。若以后让离散图元、笔画或胞元同时
跨越两条边，应引入角点标签、角点安全区域或其他可证明的兼容构造。当前连续环面场在
四角取同一周期值，因此基础路径没有明显的 C0 角点冲突，但仍应保留四 tile 交汇测试。

### 3.3 Yin et al. 2024：QRP 背景与模型对照

Yin 等人的 QRP 公式和对称映射用于解释 quasi-regular pattern 的来源，并帮助主论文
明确自己采用的生成器。当前整数波矢 Fourier 场具有单位环面周期性；如果主论文把它
定义为自身的 torus-continuous QRP 生成器并给出公式、参数与周期证明，它就是主论文
方法的一部分，而不是“错误地没有复现 Yin 2024”。论文写作中应明确二者的继承关系和
差异，避免把外部公式与本项目定义混为一谈。

### 3.4 Wang et al. 2025：Coons 与四边形扩展参考

该文对边界不变映射、Coons 插值和任意四边形处理有直接启发，但研究对象是四边形周期
基本区域，不是 Wang tile。当前项目的标量边重参数 Coons warp 是主论文自己的构造；
任意凸/凹四边形、mean value coordinates 和相应逆解尚未实现，不能提前写成已有结果。

## 4. tile 数量的统一口径

“多少个 tile”至少包含三个不同含义，报告和答辩时应明确口径：

- 展示画布中的实例数：预设 3–5 均为 `10 × 10 = 100` 个方格实例；
- 默认五种边标签允许的理论边组合：最多 `5^4 = 625` 种；
- 预先存储的图片 tile 数：0，当前内容由程序逐像素生成，不使用 tile atlas。

上面三项专指主论文现有预设。独立的经典图像对照则固定包含 8 张不同边签名的图片
tile，并把它们实例化为 `10 x 10 = 100` 个格子；它不应与主论文预设的数量口径混用。

因此，对“这个效果是多少个 tile”的直接回答应是“画面使用 10 × 10、共 100 个 tile
实例；边类型由五种标签组合产生，并不是准备 100 张独立图片去平铺”。

## 5. 主论文与实现需要共同补强的内容

1. 明确区分随机非重复铺砌与数学意义上的 aperiodic tile set；没有证明时使用
   `stochastic non-periodic` 或 `non-repeating` 更准确。
2. 把边函数、Coons 混合、Jacobian 安全条件、逆映射和周期生成器写成完整公式，并让
   符号、坐标方向和代码参数一一对应。
3. 对每个核心预设固定相机、seed 和生成器参数，输出 identity warp、正常边函数和增强
   边函数三组消融图，同时记录接缝误差、最小 Jacobian 和图像差异。
4. 给出当前整数波矢生成器的正式定义与周期证明；Yin 2024 作为模型来源和相关工作，
   不作为必须逐式一致的复现目标。
5. 删除或降级尚未实现的任意四边形结论；进入该阶段时另行定义几何参数化、共享边方向、
   凸凹合法性、逆解和退化处理。
6. 用当前 C++/GLSL 程序重新测量性能和误差，替换草稿中的占位数据与结果文件名。

## 6. 后续风格的准入条件

新风格可以改变周期生成器、调色和材质表现，但必须先通过以下检查：

1. 在关闭全部可选内部扰动时，图案主体仍沿“Wang 边标签 → 边函数 → Coons
   warp / inverse → 单一周期生成器”产生；
2. 固定生成器、相机和调色后，恒等边函数、所有标签统一映射到同一边函数，以及标签
   分别映射到真实 Wang 边函数三者之间必须出现可解释、可测量的结构差异；
3. 若恢复主论文的边界消失扰动，只允许一个低幅度控制量，并从零开始单独消融；不得用
   多层哈希相位、旋转、极性或高强度内容替换挽救失败的核心效果；
4. CPU 与 GPU 使用同一数学语义，且共享边、角点、缩放和导出均通过验证；
5. 新增表现层不能成为与主算法平行、甚至压过主算法的独立生成器；
6. 每个风格先形成最小实验和因果矩阵，通过审查后再进入正式预设。

还必须承认一个表达力边界：当 `Phi_T` 是微分同胚时，`G \circ Phi_T^{-1}` 只会改变同一
母纹等值线的几何形状，不会自动创造经典道路 Wang tile 那样的新连接拓扑。若实验表明
单一母纹和 Coons 形变不足以达到目标，应先修订论文中的内容构造定义，而不是继续叠加
与边标签关系不清的随机场。

这组条件不限制视觉风格本身，而是保证每张结果图都能回到主论文的算法贡献上。

## 7. 当前决策

- 保留预设 1–5、Wang 邻接、边函数、Coons 逆映射、周期生成器、CPU/GPU 渲染、交互和
  导出框架；
- 删除旧预设 6–8、`FlowingRibbon` 与 `StructuredBankV1` 及其专用生成、着色、UI、
  元数据、测试、文档和样例输出；
- 不改写 Git 历史，旧实验仍可从历史提交中查阅，但不再属于当前产品与论文基线；
- 已用独立的 `qrp_paper_core_audit` 生成无内部扰动的论文核心因果矩阵，没有注册新的
  正式预设；
- 经典 image-atlas Wang 铺砌已作为独立对照进入 `src/atlas/*`，但不接入正式预设；
  patch quilting 和纹理 atlas 构造仍只在后续依据正式论文 clean-room 实现，并使用
  自有或明确授权的素材。

首轮因果审计表明：真实 Wang 边标相对恒等/统一边标使结果不再满足单 tile 平移重复，
同时保持严格接缝连续；但公共母纹的等值线拓扑和单 tile 周期骨架仍然十分明显。这验证
了实现忠实性，也支持第 6 节的表达力判断。下一步不应重新加入大量随机项，而应先讨论
主论文是否需要把“边标如何约束 tile 内容”从纯坐标同胚扩展为更强、仍可证明兼容的内容
构造。
