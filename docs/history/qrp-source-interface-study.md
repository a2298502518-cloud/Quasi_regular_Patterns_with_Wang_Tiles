# QRP 源位置与共享接口的联合选择

日期：2026-09-26。研究探针，不替换默认 C++ 方法；三组已认可设计不变，本轮只验证 q=8 靛蓝细描。

## 1. 问题与本轮边界

[边界结构诊断](qrp-boundary-structure-study.md)说明，固定源池中的不同边界结构不能全部塞入预定共享接口。
本轮不再只排列现成源块，而让每个类型的 **QRP 取样位置与相容场一起求解**。
这是内容—接口共同构造的一步，不是已经完成了内容驱动的 Wang 目录设计：类型标签和合法集合仍固定，以隔离源构造的作用。

保持 16 类型、每方向 4 接口、28×28 Hermite 网格、原 H¹ 权重、源尺度 16、频率 2、原线描高度和配色。
基线为上一轮的 q8_matched，不重新排列类型。改变源位置意味着目标内容发生变化，误差必须各自相对各自源块报告，不能声称在同一目标上获得更好的拟合器。

## 2. 联合问题

设初始源中心为 cₜ⁰，源位移为 δₜ∈R²，用户 QRP 参数为 ψ，则

\[
G_t(u,v;\delta_t,\psi)=F_\psi(16u-8+c^0_{t,x}+\delta_{t,x},\;16v-8+c^0_{t,y}+\delta_{t,y}).
\]

目标仍是同一 QRP 的精确局部限制，不独立随机改变每块的波谱、幅度或设计相位。这里的源坐标仅用于离线建库，不是铺砌实例位置。

\[
\min_{\delta,\{T_t\}\in V_{\rm shared}}\sum_t\int_{[0,1]^2}
\left[(T_t-G_t(\delta_t))^2+\|\nabla T_t-\nabla G_t(\delta_t)\|^2/32^2\right]du\,dv.
\]

每个源位移坐标限定在 [−π/2,π/2]，即频率 2 的轴向半波长范围；从 δ=0 开始一次局部求解。
这使每个源块只在自己的原区域附近移动，并不证明已搜索所有可取的 QRP 区域。
仍按共享自由度构造整边场值和完整一阶梯度匹配，角点兼容条件不变。
不在最终像素上补缝，也不对合法重铺的实例重新优化源位置。

### 2.1 消去场系数，不使用额外边界代理目标

固定谱时，平移仅改变每个模态的相位。对导出的模式直接展开

\[
\cos(w\cdot u+\phi+w\cdot\delta/16)
=\cos(w\cdot u)\cos\theta+\cos(w\cdot u+\pi/2)\sin\theta.
\]

所有值及解析梯度基由已有 source_field 求值，不在 Python 重建 q 到谱的定义。
令 A 为既有加权 Hermite 采样矩阵，B 为按类型分块的加权谱基矩阵，z(δ) 为所有 sin/cos 系数。
联合问题中的场变量可精确消去：

\[
\min_c\|Ac-Bz\|^2=z^THz,\qquad
H=B^TB-R^T(A^TA)^{-1}R,\quad R=A^TB.
\]

“精确”针对同一离散积分问题，不是连续目标的精确积分。
每次研究运行重新生成 H；不保存跨算法版本的优化缓存。最终仍用原 Projection.fit 重建系数，并用原全维残差核对二次型能量。
这只是把既有最小二乘场变量消去，不能把线性代数化简作为新颖贡献。
非线性源位置问题使用已有 [SciPy SLSQP](https://docs.scipy.org/doc/scipy-1.16.0/reference/optimize.minimize-slsqp.html)，提供解析梯度；只报告局部收敛，不宣称全局最优。

## 3. 内容差异约束：为什么标量 RMS 不够

所有内容测量在每块同一局部坐标的内部 Ωᵢ=[0.15,0.85]² 上进行，用原 96×96 验证网格中的内部点。
不消除平移/旋转等价，因而它们是场空间覆盖指标，不是感知风格数或美观分数。

第一版 RMS 对照要求：

- 所有 120 对源块的内部 L² 距离至少保留各自初始距离的 80%。
- 16 块相对其均值的整体 RMS 至少保留初始值的 95%。

两个比例在运行前固定，不按图像结果调参。这不是保证完全不改变源内容，而是给出明确的允许变化预算。
实际结果显示第一版能降低接边代价，但其内容有效秩从 5.44 降为 4.04：整体能量保留不能阻止变化方向的集中。
因此不能用“仍保留 95% 差异”断言内容覆盖基本不变。

### 3.1 针对性修正：保留全部原有变化方向

令内部值基的 Gram 矩阵 Q=RᵢRᵢᵀ，只保留其非零方向。q=8 的反向波使原 sin/cos 系数有冗余，不能直接对白化前的奇异系数协方差求逆。
每个源块的实际场特征为 yₜ=zₜRᵢ，初始协方差为 C₀。
在当前非退化初始样本张成的空间中，要求

\[
C(\delta)\succeq 0.95^2 C_0,
\qquad C(\delta)=\tfrac1{16}\sum_t(y_t-\bar y)^T(y_t-\bar y).
\]

即每个线性观测方向的源内容变化标准差至少保留 95%，而不只是所有方向的平方和保留 95%。
同时保留每对距离的 80% 条件；它约束具体类型之间的关系，与总体协方差不等价。
这仍未保护所有等值线连接或感知母题，不能当成最终多样性定义。

初次直接约束白化协方差的特征值，SLSQP 在 250 次迭代后仍未收敛，残余约束违反约 2.9×10⁻⁵；该结果不作为成功候选。
特征值重合处的非光滑性是这一表达的已知数学风险，日志本身不足以把它证明为唯一不收敛原因。
随后改用等价平滑约束

\[
C_0^{-1/2}C(\delta)C_0^{-1/2}-0.95^2I=LL^T,
\]

其中 L 为下三角未知量，初始为 √(1−0.95²)I。没有放宽覆盖下限，没有把未收敛的解当成有效结果。
矩阵等式、目标和距离约束都提供解析导数；最终独立核对最小广义特征值。
平滑形式在 ftol=10⁻¹⁰ 下也达到迭代上限，尽管能量已稳定、覆盖约束违反小于 3×10⁻¹⁰；
以 ftol=10⁻⁸ 完成 231 次迭代后正常收敛，随后从实际场采样独立核对约束，并非仅相信优化器状态。
此处改变的是数值停止容差，不是 95% 的覆盖要求。RMS 对照 ftol=10⁻¹⁰，21 次迭代收敛。

## 4. 结果：较大的接边收益伴随内容变化方向的收缩

零相位三种结果：

| 指标 | 原固定源库 | 联合选择 / RMS 约束 | 联合选择 / 协方差约束 |
| --- | ---: | ---: | ---: |
| 对各自源块的值 RMSE | 0.063410 | 0.044499 | 0.060684 |
| 相对基线值误差下降 | — | 29.82% | 4.30% |
| 原离散 H¹ 能量 / 基线 | 1 | 0.584834 | 0.925365 |
| 改变的边槽×高度计数 / 512 | 295 | 211 | 274 |
| 固定分配的必要计数变化下界 | 239 | 182 | 232 |
| 源内容内部类型间 RMS | 0.291482 | 0.276908 | 0.291063 |
| 源内容有效秩 | 5.4424 | 4.0446 | 5.3668 |
| 最小广义协方差特征值 | 1 | 0.019471 | 0.902500 |
| 固定显示下颜色分歧 | 7.600% | 6.104% | 7.468% |

这里的计数不是改变面积，广义协方差特征值不是保留的风格比例。
RMS 版最弱变化方向只剩约 1.95% 的原方差，虽然所有方向合计仍保留 95% 的标准差。
协方差版的八个广义特征值为约 `[0.9025,0.9025,0.9025,0.9025,0.9261,1.0786,1.2420,1.3098]`，
因此没有用放弃某个原变化方向换取本轮收益。两版最小源块两两距离比例均约为 0.8；这些约束仅施加于源，不是对所有拟合输出的直接保证。
拟合输出有效秩分别为 5.4403、4.0445、5.3650，与各自源接近，但不能把这等同于形态完全保持。

最大源坐标位移分别约为 0.9434、0.2427（模型单位），均未碰到 π/2 上限。
位移小不等于方法只改了参数微量：变量集合由固定源拟合改成了源与相容场联合选择；但结果仍须按实际收益评价。

### 4.1 视觉判断与保留意见

三列图板使用同一个固定布局的左上 2×2 窗口；没有按美观换种子或挑窗口。
图案仍有 q=8 多层环状线描特征，两种候选都没有换显示配方、重新归一化或做后期美化。
RMS 版部分接边形变减弱，但不能忽略上表中的内容覆盖代价；协方差版与原方法的整体差异较小。
两版都还能看到接边附近的合并、窄颈与小闭合形状，未解决所有局部结构变化。

details.png 分别按“固定 wide_A 中改动最大中心窗口”的同一规则选原方法和候选各一处，
不是把同一源图上的误差直接前后比较。源位置不同、最坏邻接也可能不同；左列源块本身仍有接缝。
该图是诊断最坏例，不是平均质量。较低误差或较高有效秩不能单独裁定哪版更好看。

### 4.2 冻结源位置后的 QRP 相位响应

保持各自源中心与标签不变，从 ψ=(0,0) 改为 (0.8,0.4)，不重新优化 δ。

| 指标 | 原固定源库 | RMS 版 | 协方差版 |
| --- | ---: | ---: | ---: |
| 混合相位值 RMSE | 0.064971 | 0.056269 | 0.063046 |
| 改变的边槽×高度计数 / 512 | 305 | 233 | 294 |
| 相位响应余弦相似度 | 0.983200 | 0.982784 | 0.983048 |
| 相位响应相对 L² 误差 | 0.182971 | 0.184942 | 0.183776 |

两版在该相位下仍减少接边误差，但相位响应保真没有因此改善；零相位优化不是全参数族的保证。
RMS 版和协方差版在新相位的最小两两源距离比例分别约 0.7868、0.7992，说明零相位的 80% 两两约束不能自动延伸到任意相位。

两个相位的广义协方差特征值则数值相同。这不是两次独立的覆盖证据：
在本次固定波向量、奇阶反向相位成对的 q=8 谱中，共同设计相位在实际 sin/cos 模态空间上是共同可逆线性变换。
参考与候选协方差同时作合同变换，广义特征值不变，且 `C候选 ⪰ ρ² C参考` 被保留。
这个条件性论证针对源谱覆盖；不推出相容投影的结构保真，也不能不加分析地推广到改变 q、波向量或非线性多通道组合。

协方差版混合相位的拟合场在验证点上取值约 `[−1.020549,1.014248]`，原方法约 `[−1.016876,0.990491]`。
当前投影仍没有原始 QRP 的范围约束；没有裁剪或隐藏这项代价，也不因其他指标变好就忽略它。

## 5. 当前决定与下一步

本轮支持“源位置不应总被预先固定”，但**不足以把固定目录下的源位置优化当作最终方法**。
较弱覆盖约束得到的较大收益伴随内容变化方向收缩；保留这些方向后，当前局部解的改善较小。
不能据此证明所有更好的局部解都不存在，或宣称这是一条不可突破的多样性—误差定律。
协方差也只是本轮控制变量，不应直接替代用户的风格目标或感知评价。

下一步应把 **内容兼容关系、边标签与允许类型集合** 一起考虑，而不只是在既定二值角点目录下移动源块。
需要先构造角点与边曲线一致、能延拓且有实际重铺选择的有限目录，再比较同一类型预算下的结构代价。
目录调整不能退化为把一张原图切开后只能原位拼回；须继续验证同类型在不同合法邻接中的内容复用。
目前不扩大风格预设、不做调试台、不用优化权重继续掩盖这个方法层问题。

后续实验见 [内容驱动 Wang 目录](qrp-content-catalogue-study.md)：固定本轮之前的完整源池，单独比较内容分组与布局自由度，不沿用已优化源位置。

## 6. 复现与工程边界

```powershell
# 需先生成上一轮内容覆盖库，并已有 qrp_export_sources
python -X utf8 tools/source_interface_study.py --coverage rms
python -X utf8 tools/source_interface_study.py --rms-reference output/qrp-source-interface-study
```

RMS 对照输出 `output/qrp-source-interface-study/`，默认协方差对照输出 `output/qrp-source-interface-covariance-study/`；两版不互相覆盖。
可用 --source 指定覆盖库、--exporter 指定核心源导出程序、--output 和 --font 指定输出与字体。
每个输出目录有原方法/候选的零相位与混合相位四套库、各自 16 张缓存、两种 4×4 合法重铺、源谱、数值及图板。
--rms-reference 只读取明确指定的 RMS 结果作三列图板，并核对源清单与显示一致；不把其系数用作求解缓存。
不指定时为原方法/当前候选两列完整 4×4 图板，不依赖先运行另一版。

主要实现为 tools/source_interface_study.py；共同求解器仅增加 target_energy_gram 能量消元接口，原 fit/evaluate 不变。
边界计数与局部窗口测量复用上一轮诊断函数，未另复制谱、显示或边界拼接公式。
本轮不新增生产 C++ 入口、不扩展测试框架。第一版作为必要内容覆盖对照保留，不把每次试验变成独立生成器。

必要验证：

- 两版零相位目标和约束的方向导数核对，最大误差小于 3×10⁻⁸；平滑矩阵等式导数另作一次方向核对。
- 降维能量与原全维加权残差平方和相符（容差 10⁻⁹），不把代理目标下降当成原问题下降。
- 全部 C++ 源值/梯度核对误差最大约 1.53×10⁻¹³；线性方程相对残差小于 1.8×10⁻¹⁵。
- 每套库检查 128 个合法边对的值与完整梯度，采样差为 0；两版共 8 套库、1024 次合法边对核对（其中基线重复计算）。
- 每库两个 4×4 布局共 32 个实例纯缓存像素复用；合计 256 次实例核对。没有把演示布局传入优化目标。
- 四个不同候选/相位的源边与拟合边计数在 8,193/16,385 点下稳定；仍不是严格根隔离或拓扑证书。
- 原零相位、混合相位基线系数库和 32 张瓦片 PNG 与上一轮逐值/逐像素一致；原 fit/evaluate 行为未改。
- 最终协方差下限从实际源场采样独立计算为 0.9025000000067；不是仅检查优化器的变量。
- 检查数值图板、Python 语法、diff 与链接；生产 C++ 未改，不重复全量编译和无关测试。
