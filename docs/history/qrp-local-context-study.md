# 可局部替换的 QRP–Wang 上下文目录

日期：2026-09-27。沿用同一目录实验入口，离线研究，不替换默认 C++ 方法。

## 1. 先修正构造条件，再生成纹样

[上一轮](qrp-content-catalogue-study.md)的内容图能降低场误差，但上下文标签把整行整列绑定；完全删除上下文则损失较多源内容。
本轮问：能否仅替换有限区域的瓦片，保持外部标签和周围内容不变，同时保留部分上下文？

旧二值端点目录本来就有局部自由：改变一个内部顶点的二值状态，只改变相邻 2×2 的四块类型，外周标签不变。
因此本轮不是首次赋予 Wang 局部变化能力，而是在新内容驱动图目录中恢复上一轮完整上下文所限制的能力。
局部替换不能单独作为候选优于旧端点目录的理由。

先检查上一轮图 `[(0,1),(1,2),(2,0),(0,2)]` 的四条弧所有 15 种上下文分组。
在同步乘积图中穷举可达状态 `(s,t,是否已使用不同弧)`：两条路径同步走同色弧，从同一状态出发，寻找使用过不同弧后回到同一状态的路径。
状态数至多 3×3×2=18，不是给路径长度设一个小上限后试运气。

结果：只有全部合成一种颜色时存在这样的替换；其余 14 种分组均不存在。
对于任一保留至少两种颜色的分组，给定颜色词、起点和终点后，至多有一条弧路径，故给定颜色词至多有 9 条路径。
若横竖两个方向都采用这种非平凡分组，则 n×n 的布局数至多为 `(KₓKᵧ)ⁿ9²ⁿ`，对数除以面积趋于 0。
因此单纯在该图上“合并部分标签”不能得到随面积增长的组合选择；这是该图及该分组族的结论，不是一般 Wang 不可能性结论。

上一轮的 A⁸ 全正只是一个方便验证的充分条件，不是持续铺砌的必要条件。
本轮允许具有周期状态结构的强连通图；三状态图用 `I+A+A²` 全正检查强连通。
这会保留某种标签周期，必须明确报告，不能把去掉 A⁸ 条件说成已实现严格非周期性。

## 2. 局部替换与任意合法矩形延拓

仍有四条横弧 i、四条纵弧 j，类型 t=i+4j，使用原来对应的 QRP 源块。
横弧 i=(x₀,x₁)，纵弧 j=(y₀,y₁)；新增上下文分组 gₓ(i)、gᵧ(j)，标签为

\[
S=(y_0,g_x(i)),\quad N=(y_1,g_x(i)),\quad
W=(x_0,g_y(j)),\quad E=(x_1,g_y(j)).
\]

与旧完整上下文不同，标签不一定携带唯一弧 ID。
若两条横路径有相同起终状态及相同 gₓ 颜色序列，就可以替换一行中的该段路径：
外侧 W/E 标签不变，沿段的 S/N 标签逐项不变，内部横状态仍相接。纵向同理。
这是纯粹替换缓存类型，不改变相邻实例，不重新拟合场，也不在图像上补缝。

**有局部替换不自动保证任意有限合法矩形可延拓。** 本轮另外要求如下分层循环充分条件：

1. 每个图状态的所有出弧属于同一上下文颜色。
2. 同色弧终点的出弧颜色相同，形成颜色到下一颜色的函数。
3. 该函数是覆盖所有上下文颜色的单环；原状态图强连通。

于是同一方向的所有路径共享颜色调度，却不必共享弧路径。
强连通保证每个状态都有入/出弧；单一颜色环保证向前、向后的颜色调度唯一。
任意合法矩形中的各行横路径、各列纵路径可独立延长，同时维持共同的上下文词；再补充新的行列，即可延拓到整平面。
它不证明一般目录可延拓，也不声称任意有孔图块可填补。

角点仍由实际标签端点的传递闭包决定，共享 Hermite 场的边界值和完整一阶梯度；本轮不改变求解公式。

## 3. 有限搜索实际选择了什么

同一 16 个 q=8 源块不移动、不淘汰，跨度 16、频率 2、三阶相位基与原显示均不变。
三状态、四弧的规范编号强连通图共有 72 个，其中旧 A⁸ 条件留下 48 个。
在所有上下文分组中同时要求局部替换证据与分层循环条件，两色、三色各保留 12 个方向候选。
每种预算穷举 12×12=144 个横竖组合，按零相位的边迹代理能量选择。

竖边能量取决于横图端点与纵图上下文，横边反之，不能错误地分轴各选一个最低值再拼起来。
仍使用 65 点梯形积分的 `(f,f_u/32,f_v/32)` 组内平方差，不把代理目标当作全场 H¹ 最优或全局目录最优。
改变 QRP 相位时冻结图、分组和源位置。

### 3.1 两层：真正改变邻接的双瓦片替换

横竖均选择弧 `[(0,1),(1,0),(0,2),(2,0)]`，上下文颜色为 `[0,1,0,1]`。
状态 0 属于层 0，状态 1/2 属于层 1，颜色调度为 0↔1。
局部路径 `[0,1]` 与 `[2,3]` 均从状态 0 返回状态 0，上下文词均为 `[0,1]`。
所以一对相邻瓦片可以替换成另一对，改变内部共享边标签，但保留整段外部标签。

有 16 张内容缓存、16 种不同的 S/N/W/E 四元组，每方向 6 种接口、4 类角点、47,968 个场自由度。
没有把所有瓦片做成同一种边框后任意拼；真正的边匹配约束仍在。
代价是上下文颜色有两格周期，并非完全没有规则骨架。

### 3.2 三层：同标签的单瓦片内容变体

横竖均选择弧 `[(0,1),(1,2),(2,0),(1,2)]`，上下文颜色为 `[0,1,2,1]`。
颜色调度为 0→1→2→0，弧 1 与弧 3 是同端点、同颜色的平行弧，可单步替换。

有 16 张内容缓存，但只有 **9 种不同的边标签四元组**；不能把它报告成 16 种不同的 Wang 组合。
每方向 9 种接口、9 类角点、48,636 个场自由度。
它是三格标签骨架上的局部内容变体对照；四元组没有发生局部重组，机制与两层候选不同。
这些局部路径和图乘积论证仅用于构造性验证，不将通用图论条件本身宣称为论文新颖贡献。

## 4. 自由度不是只凭两张图判断

设 W_c(n) 为从颜色层 c 出发的长度 n 弧路径数，包括各起点和不同弧 ID。
某一横向上下文词由起始颜色唯一确定，但每一行可独立选路径，所以单方向贡献是 `Σ_c W_c(n)ⁿ`。
横、竖相乘得到完整 n×n 缓存类型布局数。这是组合计数，不是可感知风格数量。

| 目录 | 独立边四元组 / 缓存数 | 每方向接口 | 6×6 布局数 |
| --- | ---: | ---: | ---: |
| 旧端点目录 | 16 / 16 | 4 | 562,949,953,421,312 |
| 上轮完整上下文 | 16 / 16 | 12 | 256 |
| 两层局部路径 | 16 / 16 | 6 | 290,339,789,209,600 |
| 三层局部变体 | 9 / 16 | 9 | 150,994,944 |

两层的 W_c(6) 为 `[8,16]`；三层为 `[4,4,4]`。
独立枚举 2×2 合法组合，分别得到 400 和 81，与公式一致。
当 n 为偶数，两层布局数为 `2^(n²)(1+2ⁿ)²`；当 n 为 3 的倍数，三层为 `9·2^(2n²/3)`。
两者都具有随面积增长的选择，不再仅有整行整列的组合自由；两者也都允许周期铺砌。

计数相近不表示两层与旧端点目录的空间统计相同。
三层在固定标签位置只有 1、2 或 4 个内容变体，源块的长期使用频率也并不均匀。
本轮均匀加权 16 张库内容的拟合指标，不能冒充特定布局采样分布下的平均图像质量。

## 5. 同一 QRP 源上的实际结果

| 指标 | 旧端点 | 完整上下文 | 两层局部路径 | 三层局部变体 |
| --- | ---: | ---: | ---: | ---: |
| 零相位值 RMSE | 0.063410 | 0.035684 | 0.060220 | 0.049968 |
| 归一化梯度 RMSE | 0.078109 | 0.039557 | 0.076652 | 0.061930 |
| 混合相位值 RMSE | 0.064971 | 0.037594 | 0.060880 | 0.051738 |
| 零相位改变的边槽×高度计数 / 512 | 295 | 220 | 272 | 260 |
| 零相位必要计数变化下界 / 512 | 239 | 98 | 184 | 176 |
| 混合相位改变的计数 / 512 | 305 | 221 | 279 | 268 |
| 零相位颜色分歧 | 7.600% | 5.779% | 7.307% | 7.394% |
| 相位响应相对 L² 误差 | 0.182971 | 0.106231 | 0.161500 | 0.139068 |

相对旧目录，两层零相位场误差降低 5.03%，三层降低 21.20%；两者混合相位亦较低。
但接口分别从 4 增到 6/9，角点也增加，不能把改善全部归因于上下文构造或内容搜索。
本轮没有提供同接口、同角点预算下的全场性能归因；不声称找到普遍占优的方法。

计数也非全面改善：原源在八个显示高度的边界穿越总数为 2,108，旧目录保留 1,696，两层反而只有 1,664，三层为 1,908。
因此较少的“计数发生变化的组数”不等于整体结构损失都更少。
这仍只是离散高度下的边界诊断，不是二维拓扑或审美评分。

按源 ID 排列后，四种方法的源场逐值相同；源内部有效秩均约 5.442415，两层/三层输出为 5.442119/5.441371。
没有通过收缩源集合获得改善，也不能用内部秩接近来否认边界母题变化。
三层混合相位的采样范围为 `[−1.033898,1.022847]`，依旧越出原 QRP 范围；两层本次采样没有越界，但并未施加范围约束或证明全域有界。
没有裁剪或重新归一化显示。

### 5.1 确实只替换了局部

固定种子布局 A 中按坐标顺序找到第一处可替换路径，不按美观挑位置。
两层示例替换第 0 行、第 1/2 列的两个类型，三层示例替换第 0 行、第 2 列的一个类型；布局行号向上，图片行号向下。
重新组装只复制同一套已烘焙缓存，不重新求解场。

零相位两层替换区内改变 120,111 个像素，三层改变 60,027 个像素；相位迁移后分别为 119,891 和 60,538。
四次替换的区域外改变像素数均为 0，外周边标签逐项不变，新内部邻接合法。
这证明演示不是改了类型编号但内容完全一样，也不是带着周围区域一起调整。

每列采用自己的固定合法布局 A，统一展示左上 2×2 窗口；零相位与改变 QRP 相位各一行。

## 6. 决定与下一步

保留两层目录作为具有真正局部邻接变化的研究候选；三层作为“周期骨架＋内容变体”的必要对照。
不把任一候选立即替换主线，也不以组合数、较低 RMSE 或 C¹ 接边代替风格和视觉判断。

本轮修正的是方法前提：不能把 A⁸ 全正当成必要条件；不能以局部合并标签自然获得二维自由；
也不能把有局部替换当成任意有限矩形可延拓。这些条件现在分别有了明确证据。

下一步优先把该局部复用机制带回已认可的 q=5/8/12 三组 QRP 设计，检验各自的形态特征与相位响应是否保留。
对比时记录接口预算、周期骨架和接边母题变化，不先继续增加目录种类或开发 UI。
若跨风格结果不支持它，则回到源场与边界共同构造，而不是默认本轮图目录必须正确。

后续[三组设计检验](qrp-local-context-styles.md)已完成：局部复用成立，但两层不跨风格一致占优；
连续源的统一显示也暴露当前几何家族偏近，需把源形态控制与接边代价分开判断。
