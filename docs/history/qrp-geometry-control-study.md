# 冻结 Wang 目录后的 QRP 几何控制

日期：2026-09-27。承接[三组设计检验](qrp-local-context-styles.md)。本轮是既有控制能力的分离实验，不宣称新增了一套 QRP 公式。

## 1. 结果与研究判断

固定 q=8、尺度、相位、显示及 Wang 目录后，环簇到条带、条带旋转的差异仍能经过有限内容库表现出来。
这不是更换配色造成的区别；两层候选也没有因参数改变而重新选图、移动源块或按铺砌实例重算内容。
双向混合得到较明显的菱格组织，但仍含嵌套闭合轮廓，不能夸成完全不同的视觉语言；旋转也不另算一种风格。

目前不足的不是“QRP 只能生成圆团”。共享拟合保留了大体方向，却可能改变局部连接与条带走向。
在原始源具有明确条带充分条件的零高度上，旧端点库出现了一个数值确认的回折反例。
两层库在同一有限搜索中未找到零高度回折；不能把未找到当成全域无回折证明，也不能因此否认其图中可见的接边波折。

两层保留为下一步研究候选；旧端点保留为反例对照。两层仍有更高接口预算和两格上下文周期，不因本轮有效就忽略上一轮 q=5 的退步。

## 2. 本轮只改变什么

所有实际模态由 `ParametricQrpField` 构造，通过 C++ 源导出进入 Python；没有在 Python 重建 q 到波谱的公式。
方向为 `dᵢ=Rα(cos θᵢ,sin θᵢ)`，θᵢ=2πi/8。以下为当前代码在 q=8 下的等价写法：

\[
w_i(\beta)=\frac{e^{\beta\cos 2\theta_i}}{\sum_j e^{\beta\cos 2\theta_j}},\qquad
a_i=(1-m)w_i(\beta)+m w_i(-\beta),\qquad
F(r)=\sum_i a_i\cos(2d_i\cdot r).
\]

代码使用减去共同指数的数值稳定写法。β 是方向权重集中程度；m 混合主方向与正交方向权重；α 旋转载波，不旋转 Wang 网格。
β=0 时 m 不产生新自由度。q=8、零相位时 m=0.5 等于单向场与其旋转 90° 场的平均，不是两个通道相乘或真实织物的上下穿插。
β 趋于无穷时会趋向少数平面波主导的周期极限，不能无限加强偏置而仍把它解释成不变的准规则组织。

| 配置 | β | α | m | 用途 |
| --- | ---: | ---: | ---: | --- |
| rings | 0 | 0° | 0 | 等权环簇；精确复现上一轮 q=8 零相位 |
| bands | 2 | 0° | 0 | 主方向条带 |
| rotated | 2 | 30° | 0 | 同一条带的旋转对照 |
| crossed | 2 | 0° | 0.5 | 双向菱格组织 |

上述值在出图前固定，没有根据图片循环搜参。保留原靛蓝细描的全部高度、色值和强调线；不归一化、不裁剪输出场。
16 个源中心仍为 `(16i,16j)`，跨度 16，频率 2，三阶相位基，A=B=0；28×28 Hermite H¹ 投影与 wave_scale=32 不变。

旧端点分配仅从 rings 源池按原规则计算一次。两层使用上一轮 q=8 的图 `[(0,1),(1,0),(0,2),(2,0)]` 和颜色 `[0,1,0,1]`。
四个配置冻结各自目录、类型分配及两个 6×6 布局，分别为 4+4 与 6+6 接口、16 种边四元组、16 张缓存。
这里比较的是两个固定目录承接 QRP 控制的能力，不是每个新风格下重优化目录后的最佳表现。
不同目录的布局不逐点对齐；同一目录的四个配置则始终复用相同类型布局。

固定目录下投影是同一有限维线性算子 P：T(ψ)=P G(ψ)。固定 q 的源场对这些参数平滑，故系数也平滑；不会因为重新离散选图而跳变。
这不意味着像素阈值、等值线连接或不同 q 之间也连续，更不证明任意参数都保持同一种几何组织。

## 3. 条带不能只由主方向指标定义

本轮针对单向与旋转源，独立推导一个充分条件。合并反向且相位共轭的主波对，在法向 n 与条带方向 t 的坐标 (s,z) 中写成

\[
F(s,z)=M\cos(ks+\phi)+R(s,z),\quad |R|\le r,\quad |\partial_sR|\le kD.
\]

M、r、D 直接从实际模态的非负幅度及波向量求得，不按图片拟合。若

\[
|h|+r<M,\qquad \sqrt{M^2-(|h|+r)^2}>D,
\]

则在每个主余弦半周期两端，F−h 异号；所有可能的根处主导方向导数严格压过余项导数。
根的穿越方向在该半周期内相同，因而恰有一根；隐函数定理给出随 z 平滑延伸的根分支。
所以这个等值集合由沿条带方向持续延伸的图形分支组成，不会在法向上出现非退化回折。
这是当前相位配对源模型的充分条件，不是所有 QRP 的必要条件，也不自动适用于投影后的瓦片。

单向和旋转源均为 M=0.775803493、r=0.224196507、D=0.148483352。
条件可写为 `|h| < 0.537265083`，包含零高度及原显示中的 −0.35、−0.16、0.03、0.22、0.32、0.41。
原显示另有 0.60、0.79，不在这份保证内；这些高度出现闭合形态不构成反例。
等权与双向配置不满足该充分条件，不表示其不存在其他结构规律。

### 旧端点中的数值回折反例

旋转配置的旧端点类型 0，在局部 `(u,v)≈(0.0013462604,0.1905860054)`：

- T≈1.48×10⁻¹⁶，∂ₙT≈−4.44×10⁻¹⁵；
- ∂ₜT≈−7.579286，非零；
- ∂ₙₙT≈1500.47727，非零；方向差分步长 10⁻⁵ 与 5×10⁻⁶ 相符。

在这个光滑单元内部，零线可以局部写成 z(s)，其一阶导数为 0、二阶导数非零，是非退化回折的数值证据。
它位于边界附近，说明全域方向接近、空间 C¹ 接边都不足以保证原条带组织。
这不是区间算术证明，也不是全库拓扑计数。
搜索只从每块 32×32 网格选 12 个低残差初值，用有界最小二乘找一个反例；两层未找到不能解释成完备证明。

## 4. 拟合、方向与参数响应

| 配置 | 旧端点值 RMSE | 两层值 RMSE | 旧端点 / 两层改变的边槽×高度计数（512 项） |
| --- | ---: | ---: | ---: |
| 环簇 | 0.063410 | 0.060220 | 295 / 272 |
| 单向条带 | 0.092654 | 0.081892 | 142 / 170 |
| 旋转条带 | 0.124207 | 0.085337 | 455 / 163 |
| 双向菱格 | 0.068145 | 0.060658 | 221 / 200 |

两层本次四个配置的场误差均较低，但单向条带的边计数变化更多；不能宣称所有结构指标都优于旧目录。
旋转配置的内部 `[0.15,0.85]²` 方向统计与源接近，较大变化位于其余边界区域。

用 J=平均(∇F∇Fᵀ)，方向集中性 η=(λmax−λmin)/(λmax+λmin)。这不是美观分数。

| 旋转条带指标 | 源场 | 旧端点 | 两层 |
| --- | ---: | ---: | ---: |
| 全库 η | 0.964024 | 0.895053 | 0.935401 |
| 全库主法向 / 度 | 29.9975 | 30.6139 | 29.4432 |
| 边界区域 η | 0.963998 | 0.817363 | 0.905748 |

法向不是条带走向；对应条带方向需加 90°，方向按模 180°理解。
等权与双向场的 η 接近 0，此时主轴角度不稳定、没有主要方向意义，不能解读它们报告中的角度漂移。

按源 ID 对齐的参数变化响应，相对 L² 误差（旧端点 / 两层）：环簇→条带为 0.167075 / 0.150405，
条带→旋转为 0.193861 / 0.150827，条带→双向为 0.164741 / 0.144568。
这是三个有限参数变化，不是连续路径上全体参数的保证；不同配置源目标不同，也不能把其绝对 RMSE 横向排列为风格难度定律。

两层单向采样范围约 `[−1.047305,0.997458]`，旋转约 `[−1.011151,1.013925]`；仍未解决投影越界，不做裁剪隐藏。

## 5. 图像、决定与下一步

输出目录 `output/qrp-geometry-control-study/`：

- `comparison.png`：四个控制状态，原连续源、旧端点和两层库，全部保持原线描配方；旋转行不算新增风格。
- `zero_level.png`：同一旋转配置，统一零高度双色诊断。只换显示，不改场，避免亚像素窄线干扰结构观察。
- `reuse.png`：旋转配置的两层库在两个完整 6×6 布局中复用。
- `wang_library.png`：同一库的 16 张实际瓦片及真实 H/V 标签。
- `boundary_details.png`：两种目录各自固定布局中最大场改动的接边窗口，不是平均效果或同一目标前后对照。
- 各配置/目录下保存全部瓦片、系数及布局；`results.json` 与 `sources.json` 记录配方、冻结目录、模态、指标和反例。

连续源展示原本相邻的 0、1、4、5 四块；Wang 图统一截取固定布局左上 2×2，不挑美观种子或裁图位置。
原线描使用的是标量高度带宽，不是等几何线宽；偏置增加梯度后，部分细线变得很窄，不能把缩略图里的细线缺采样当作场断裂。
零高度图仅诊断结构，不能反过来取代原配方或声称商业审美已达标。

本轮说明源控制确实可用，不需要先另造一批 QRP 函数来证明差异。它没有完成所有风格扩展，也没有证明两层就是最终答案。
下一步把“方向偏置”提升为可表达的形态要求：以有充分条件的条带为最小目标，研究共享边界是否能同时承接有序的等值线穿越和兼容角点，
而不只约束场值与梯度相等。先推导这种边界约束能否覆盖不同合法邻接，再决定需要修改源构造、目录还是拟合表达。
不能简单追加罚权重、强制所有原轮廓不变，也不能绕回逐实例大图生成或忽略原有的有限复用条件。
用户控制继续位于 QRP 层；不开发调试台。

## 6. 复现与必要验证

```powershell
cmake --build build --config Release --target qrp_export_sources
python -X utf8 tools/geometry_control_study.py
```

脚本只依赖已批准配方快照和 C++ 导出，不需要先跑上一轮所有目录。支持 `--output`、`--exporter`、`--font`。
导出程序末尾可追加 `bias angle_radians cross_mix`，原调用不变。没有修改核心 QRP 数学或默认生产入口。
从目录实验中提取 `fit_library` 复用建库、测量及缓存复制；这轮新增的是实验编排与针对性的几何诊断，不是第二套求解器。

已完成：

- 导出器及相关 QRP 测试目标构建；`qrp_parametric_qrp_field_tests` 通过。
- 原两种代表性导出调用的完整输出 SHA-256 不变；环簇的两个系数/映射库与 32 张 PNG 精确复现上一轮。
- 8 套库；896 次合法边对核对的值和完整梯度采样差为 0；720 次实例逐像素复用。
- 两层四次局部替换区域外像素不变、区域内确有变化；外周标签保持，内部邻接合法。
- C++ 原场值/梯度核对误差最大约 2.74×10⁻¹³，方程相对残差小于 1.8×10⁻¹⁵。

图形研究技能用于区分参数含义、实际形态与共享边界；简化技能用于复用建库流程；审阅技能用于本轮实现者自审，不声称独立评审。
