以下第 1～6 节保留前一阶段四轮研究时的事实；其“尚未接入/等待取舍”描述为当时状态。最新实现与验收见第 7 节。

## 1. 本轮问题与边界

用户要求新 Q、频率、旋转参数也能进入统一、可复用的生成过程，而非每次完整离线建库。
不是只要求旧参数读缓存快，也不是增加操作台功能。本轮最多四轮，不提交或推送。

必须保留有限类型、位置无关的内容、合法边标签的标量场 C¹ 相容和已认证的相位关系。
QRP 参数仍由 C++ 源模型定义；不增加逐 Q 特例或 Wang 用户参数。
研究若出现明显的速度与内容质量取舍，报告证据，不擅自把实验替换成正式方法。

本轮只新增一个实验入口 `tools/parametric_pipeline_study.py` 和本说明，更新工具索引。
主求解模块、桌面界面和工作台缓存协议均未改动。其余未提交文件是先前工作，未清理或还原。

## 3. 可复用构造的推导

沿用[方法边界](qrp-method-and-paper-scope.md)中的 `W=A V` 与相位表达。
记共享 Hermite 系数为 `c_d`，每个基础相位的目标为

`r_dt(u,v) = z_dt + delta_dx (u-1/2) + delta_dy (v-1/2)`。

对于固定类型目录，所有 Q 的目标都在同一类仿射目标空间内。
16 个类型分别有一个常数项，两个斜率在类型间共同，因此这里只需要 **18 个目标基**。
Q 改变目标系数及 A，不要求另写空间构造规则。

把加权采样算子记作 M，`H=MᵀM`，目标基的法方程右端矩阵记作 R。
无约束最优响应为 `B=H⁻¹R`，可以复用 B。**但这个等式不能直接推广为有界问题的完整解。**
加入 `|D_x A c|, |D_y A c|≤8` 后，活跃的空间约束随目标改变；有界最优解一般不在 `range(B)` 中。

第三轮明确改成 `c_d=B z_d`，在这个较小空间内优化，而不是冒充原全空间优化的等价加速。
对 B 在 H 内积下正交化后，目标矩阵为 `(AᵀA)⊗I`，约束仍检查全部单元的 Bernstein 导数控制系数。
每次解小问题后检查全部约束，把尚未加入且违反的约束加入，直至数值可行。
这种约束分离在降阶空间有效，不代表第二轮全空间分离有效。

性质：B 的每列使用同一个共享 jet 映射，线性组合仍共享同标签边的值与导数；A 的相位关系不变。
载波与上下文规则未变，故合法接边的相位模 2π 与标量 C¹ 推导仍成立。
这不是源频谱、局部闭合轮廓、参数路径连续性或全局审美的保证。

第三轮的 B 随频率对应的 H 改变；第四轮试用固定尺度 8、16、32、64 的响应并集，数值秩为 69。
固定尺度空间有跨 Q/方向/频率复用的可能，但当前原型每个案例仍重新组装它，没有完成持久算子编译与在线更新接口。
两种响应基原型都没有加载已有内容库来跳过求解；基线缓存只用于输出对照。

## 4. 四轮结果

下表第二至四轮为 **相位构造时间**，包含响应基准备、整数分支与拟合，但不含 C++ 导出、纹样采样与 PNG 保存。
不能将其直接称为完整预览速度，或与第一轮完整预览算出端到端加速比。

| 方案 | Q8 / Q12 / Q9.25 构造秒数 | H¹ 能量 / 原方案 | 结论 |
| --- | --- | --- | --- |
| 第二轮：全空间约束分离 | 6.833 / 105.305 / 15.235 | 约 1.000 / 1.000 / 1.000 | 可近似重现原解，但无提速，拒绝接入 |
| 第二轮：4×4 粗拟合网格 | 1.385 / 5.795 / 2.455 | 1.156 / 1.100 / 1.135 | 轮廓有变化，不是无损加速；Q12 仍非即时 |
| 第三轮：18 维响应基 | 0.713 / 0.910 / 0.737 | 2.351 / 2.140 / 2.024 | 亚秒相位构造原型成立，但改变源拟合程度 |
| 第四轮：69 维多尺度响应基 | 7.809 / 38.365 / 18.363 | 1.191 / 1.238 / 1.187 | 改善拟合，速度优势丢失，不接入 |

这里的“能量”是原公式的平方残差和，不是 RMS，也不是美观分数。
18 维方案能量约两倍不能解释成“美观下降两倍”；同样，图片看着不错不能证明源组织和控制意义保持。
4×4 网格行在其自己的 Gauss 积分下计算，且整数提升代理空间也变化，不能把差异全部归因于单一环节。

第三轮 RGB 平均绝对差约 51～58/255，说明不是旧结果逐像素不变的提速。
目视总体风格仍可辨认，部分局部轮廓和重复组织发生改变。本轮没有充分依据决定用户应接受哪种取舍。

必要检查：每案例 96 对合法边、值及完整梯度检查；最大接边数值差约 `3.2e-13`。
全部单元的 Bernstein 归一化约束最大超差小于 `2e-7`（限值 8 对应约 `1.6e-6` 的数值容差）。
铺砌均逐块精确复制对应类型像素。上述是解析构造加数值核验，不把采样检查当作全域证明。
Q=8、12、9.25 仅覆盖独立、关系耦合与非整数三种代表输入，不证明所有合法 Q 的性能或外观。

## 5. 交付与停止判断

已完成：定位主瓶颈、推导共享响应空间、实现必要对照及两种降阶原型、记录计时和同参数纹样。
未完成：可直接替换现有操作台的统一快速生成管线、端到端交互延迟验收、广泛参数下的视觉与控制验收。
没有改正式方法，也没有把 0.7 秒的构造时间宣传为操作台响应时间。

本轮结论不是“现有算法没有工程价值”，也不是“有了缓存就已经解决”。
更准确的是：当前有界全空间拟合代价较高；较低维参数化有提速证据，但质量目标需要明确。
下一阶段的关键选择是：是否接受重新定义残差相位参数化、以视觉组织与参数响应验收，而不要求逼近旧 H¹ 最优结果。
这不是询问是否可以改算法——用户已允许修改；需要的是对具体内容变化与速度优先级的判断。
四轮到此停止，不无限增加响应基或新的小修补。

## 7. 用户接受后的三轮接入

用户确认“中间的情况可以接受”。因此采用第 3 轮的响应空间，不再要求逐点逼近旧全空间最优纹样。
保留源定义、Wang 目录、整数相位关系和 C¹ 接边；不把该选择宣称为普遍的审美优越。

### 第一轮：共享生成器

- `ResponseProjection` 拥有响应基和小规模有界求解；`ResponseWorkspace` 最多保留三个频率尺度的算子。
- 同频率的新 Q、新角度复用同一算子，改变目标与 A；频率变化仍须准备对应算子，不隐瞒此成本。
- `PhaseTransport` 接受显式投影对象；既有离线研究默认不变，工作台明确采用响应空间。
- `qrp_export_sources --grid-size` 在一次 C++ 调用中批量导出，所有波向、幅度和相位仍来自原 C++ 模型。
- `RegularValueSampler` 用同一 Hermite jet 的张量积求值；预览和高清只是采样分辨率不同。
- 退出逐参数 `atlases/` 烘焙/加载与旧基线导入，不再保存几十至数百 MB 的逐像素模态相位缓存。
- 模型版本升级 v2；v1 配方可经用户确认只迁移参数，不混用历史系数或图像。

首次接入的 Q8 / Q12 / Q9.25 完整引擎预览为 1.828 / 1.997 / 1.760 秒，与用户认可图板的 RGB 平均差均小于 0.005/255。
收尾版本另用新缓存复核为 1.708 / 1.742 / 1.739 秒；Q8/Q12 与认可图逐像素相同，Q9.25 的 RGB 平均差约 0.0000735/255。
这是实际源导出、相位准备、16 瓦片、6×6 铺砌、连续源、证据和 PNG 的流程，不只是优化器耗时。
不含启动 Python、窗口通信和显卡上传；不拿结果缓存命中充当新参数生成。

### 第二轮：参数覆盖与实际缺陷修复

Q=5.5、频率 1.77、角度 17° 的回归暴露 OSQP 达到 30000 次上限：选中 448 行，实际仅 145 个精确不同约束。
共享边/角点导致大量重复约束，影响此案例的迭代收敛。只去除精确重复行后，同一目标与容差下通过；没有放宽边界或偏导条件。
去重不表示所有数值病态已消失；仍只在求解成功并检查全部 Bernstein 约束后输出。

同一频率 2.03、角度 13° 的七组未缓存参数结果如下。每次新 Q 均实际求解，整个进程只编译一次空间算子。

| Q | 完整引擎出图（秒） |
| --- | --- |
| 1 | 1.371 |
| 5.5 | 1.087 |
| 7 | 1.403 |
| 10 | 1.409 |
| 16 | 1.331 |
| 9.75 | 1.238 |
| 32 | 1.987 |

这不是 Q 白名单；算法仍按导出谱和关系矩阵运行，也不是所有合法 Q 的速度保证。
测试同时确认幅度、共同相位和显示变化不增加拟合次数，换 Q/方向增加拟合但不重新编译同频率算子。

### 第三轮：工程收尾

5 项针对性操作台测试通过，覆盖批量/单块 C++ 导出一致、解析/快速采样一致、预览/高清、配方和纯复制重铺、算子生命周期。
桌面 Release 构建及 3 项 CTest 通过。原生集成验收覆盖非整数 Q、相位控件、配方回读、取消重启、全部视图、2304px 输出及实际 OpenGL 截图。
高清单次约 9.5 秒；称为秒级预览，不称为任意参数实时系统。迁移确认与系统文件对话框尚未做人工点击验收。
最终重建后的原生验收再次以退出码 0 结束，高清为 9.915 秒；截图为 `output/qrp-response-integration/native-workbench-final.png`，所属进程已退出。

按代码简化技能将研究原型的已采用求解实现收敛到 `response_projection.py`，实验入口只调用它；全空间分离/粗网格/多尺度仅为必要历史对照。
自审覆盖实际未跟踪文件；未委派、未提交、未推送，也没有删除旧研究图样。
