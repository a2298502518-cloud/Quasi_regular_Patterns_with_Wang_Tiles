# 大范围重铺与 QRP 相对相位状态（2026-09-22）

## 1. 问题与结果

接续 [父子组织研究](qrp-organization-tile-study.md)，先固定已有三类 QRP 配置、L=16、
384px 瓦片，将可见布局从 2×2 扩展为 8×8。目的不是放大纹样，而是扩大铺砌视野，
区分“可复用机制成立”和“重铺有可见的设计价值”。不改 UI，不暴露 Wang 参数。

第一轮确认：同库重铺确有局部变化，但大范围的组织节奏仍非常接近单瓦片重复。
这不是对规则纹样的否定；只是不能把不同的瓦片 ID 数量直接解释成强烈的视觉多样性。

回查方法发现，已有二值内部状态只编码一条源坐标平移路径。第二轮将状态扩展为同时
编码父场的 QRP 相对相位，子场保持不变。实际结果中，前两类的父场区域形状更有变化，
第三类的短条列出现更明显的起伏；前两类同时失去部分完整大环，变成松散簇群。

本轮保留两类研究候选：原来的规整装饰组织、新的松散分簇/起伏组织，不自动以新替旧，
也不把不规则程度增加当作审美进步。整体仍有相位闭合骨架，未证明严格非周期或商业适用性。

## 2. 第一轮：只扩大范围

每例仍用一个 16 张的固定内容库；A/B 两个布局都包含全部 16 类型。
每张源瓦片 384×384，源跨度 L=16，仍为每源单位 24px。
总图变为 3072×3072，源视野从 [0,32]² 扩为 [0,128]²；不是相同视野的分辨率升级。
布局继续从共享顶点二值状态生成，四种边色编码两个端点，C++ 逐邻接检查合法性。

同一个实验进程内每类烘焙一次，随后 A/B 和类型 0 周期对照只按 ID 复制 RGB。
作为独立可复现实验，程序会重新烘焙库，而非从上一轮 PNG 解码；核验确认三类共 48 张
源 PNG 与上一轮 `resolved-scale/` **逐字节一致**，因此没有通过修改内容制造差异。
周期对照采用可合法自匹配的类型 0，不用非法拼接当反例。

大范围中能看到局部轮廓、条纹位置和小孔的差异，但大环、团簇中心及列状骨架仍明显重复。
原像素局部检查与全貌分开；缩略图不能独立用于判断局部形状质量。

## 3. 为什么旧状态主要改变局部位置

沿用相位模型的符号，`Sτ(u)` 是由四角二值状态得到的 C¹ 插值。旧状态项为

\[
\gamma_r S_\tau=\kappa d_r\cdot(o_1-o_0)S_\tau.
\]

因此，各方向的状态相位来自同一源偏移 `o0+(o1−o0)Sτ`，并非独立的 QRP 相对相位。
局部闭合项仍固定在瓦片坐标中，所以不能把整个兼容瓦片说成原图片的刚性平移；
准确说法是**源平移型的状态变化**。

本轮低频父场 κ=1.15，`o1−o0=(0.7,0.1)`，状态相位变化幅度上界约为 0.813 rad。
相同的整数圈数与闭合项保留了公共骨架。子场频率 6.9 对同一源偏移更敏感，因而旧结果
更容易表现为内部细节变化，而不是父场区域的显著重组。

这揭示的是当前状态编码的能力限制，不是 Wang 接边失效，也不意味着必须消除规则节奏。

## 4. 第二轮：边状态同时编码 QRP 相对相位

新增内部参数 `vertexPhaseOffsets[2]`，其元素 `p0=(A0s,B0s)、p1=(A1s,B1s)` 是
相对于基础 QRP 全局 (A,B) 的偏移。默认两者均为零，保持原库。
复用权威谱提供的二阶角谐波 `H_r=(cos 2θ_r,sin 2θ_r)`，不重写方向或振幅公式。

只需修改每模态的两个常量：

\[
\beta_r=\kappa d_r\cdot o_0+(A,B)\cdot H_r+\varphi+p_0\cdot H_r,
\]

\[
\gamma_r=\kappa d_r\cdot(o_1-o_0)+(p_1-p_0)\cdot H_r.
\]

原有求值式、闭合量、振幅和梯度公式不变：

\[
\Phi_{r,\tau}=\omega_r\cdot u+\Delta_{rx}h(u_x)+\Delta_{ry}h(u_y)
+\beta_r+\gamma_r S_\tau(u).
\]

对本轮 q=5，二阶角谐波与表示空间平移的一阶角谐波在离散方向集合上正交。
因此，在未取模的相位向量中，非零的二阶相对相位不能用一个源平移向量表达。
这是增加了 QRP 的内部造型自由度，而不是仅把旧源偏移放大。
不过两个状态仍由同一个标量 S 插值，不是任意多维风格空间，也不保证保留大环拓扑。

固定对照配置为父场 `p0=(−1,−0.5)、p1=(1,0.5)`，子场保持 `p0=p1=(0,0)`。
这是一个以零为参数中心、弧度量级的明确候选，没有声称是最优相位选择。
两轮基础 QRP 参数、源偏移、门控 h=0/w=0.35、采样、色彩、布局与边标签编码完全相同。
新旧方法的内容库会不同；**只在各自库内部声称 A/B 原样复用**。

边状态只是对 QRP 内容的内部编码，不向用户增加 Wang 控件；最终用户仍应使用 QRP 的
造型语义调节纹样。本轮没有设计新界面，也没有把内部相位状态做成用户开关。

## 5. 连续性、范围与原结论的变化

β、γ 对一个库的所有类型固定。合法邻接仍共享 S 的值和切向导数，法向导数均为零；
每模态跨边相位仍只差整数 `2π n`，完整梯度相同。因此场及父子组合保持 C¹。
振幅非负且归一化的事实未变，值域仍是 [−1,1]。不使用标量来源混合或接缝后处理。

贯通核心带充分条件中的 γ 必须使用新的总状态相位差，不可沿用旧数值。
实现的 `bandCertificate()` 已直接读取该总量。本轮方向性父场的梯度下界由约 16.518
降为 13.518，但仍为正且主振幅大于其余和，故其输入场核心带条件仍成立。
该保证仍不适用于门控组合的全部零轮廓，也不意味着短条能贯穿整个纹样。

原整数圈数与平均闭合误差不变；上一轮 ε≤0.25 准则仍约束平均波矢，
不约束新增相对相位所引起的全部局部梯度变化。周期骨架也没有因此消失。
`source()` 保持为未闭合的基础全局 QRP 参考，不偷偷加入内部状态偏移。

## 6. 可见变化与测量的解释

| 候选 | 原平移型状态 | 相对相位状态 |
| --- | --- | --- |
| 细环形组织 | 完整大环与装饰节奏更清楚 | 大环拆分为不同簇群，区域形状变化更明显 |
| 条纹组织 | 环内条纹与规则簇心 | 大小、分布不同的条纹簇，留白更不均匀 |
| 带内短条 | 较直的列状节奏 | 列的位置与粗细起伏更明显，仍保留方向性 |

这些是固定窗口的视觉观察。前两行的拓扑变化既可能有设计用途，也可能损失用户喜欢的
完整装饰图形；不凭像素差异决定优劣，不自动再修复成一致单元。

`retiling_metrics.json` 记录相隔一张瓦片时，重叠区域内 RGB 不同的像素比例，不作环绕。
类型 0 周期重复的横纵指标严格为 0，Wang 图均非零。两合法布局 A/B 同坐标像素差异为：

| 候选 | 原状态 | 相对相位状态 |
| --- | ---: | ---: |
| 细环形组织 | 18.32% | 19.51% |
| 条纹组织 | 22.07% | 23.58% |
| 带内短条 | 12.23% | 22.40% |

像素差异受背景比例、抗锯齿和轮廓移动影响，既不是美感分数，也不是感知变化强度。
例如前两行数值只略增，但“完整环变为簇群”的组织差别不能由这一个数字充分描述。
没有计算销售价值、速度提升或无限非周期性。

```powershell
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
.\build\Release\qrp_wang_qrp_experiment.exe --study retiling
python tools\build_tile_board.py output\qrp-retiling-study --previous output\qrp-organization-tile-study\resolved-scale
```

根目录为旧状态的大范围结果，`relative-phase/` 为新状态。每组 3 例 × 19 张原始 PNG，
合计 114 张；不重复生成上一轮的独立输入场和全局参考。

- `board_wang_value.png`：旧库的大范围单瓦片重复、A/B 合法重铺。
- `board_retiling_detail.png`：同位置的原像素接边局部；截取中央四片交会处，不缩放。
- `board_phase_states.png`：两方法在同一布局 A 的全貌，以及新库的布局 B。
- `board_phase_states_detail.png`：上项的原像素局部，不以缩略图代替局部检查。
- `relative-phase/board_reuse.png`：新方法的实际 16 张源瓦片及 A/B 编号。
- 新方法目录也保留自身的周期对照图板和测量记录。

Release 编译与七组 CTest 通过，没有新增测试目标。既有父子用例同时覆盖零/非零状态
相位：全部合法邻接的值和完整梯度、值域、支撑区域包含及过渡处解析梯度。
补充两个端点状态与直接 QRP 求值一致的检查，防止将相对相位误实现成其他操作。
114 张原图全部解码，768 个 Wang 实例和 384 个周期实例均逐像素复用；
两布局各覆盖全部 16 类型，实际接边抽样最大误差≤1.009e−12。
旧库的 48 张源图与上一轮逐字节一致。新参数默认零，旧相位研究 120 张与旧来源研究
111 张原图重跑后全部字节一致；manifest 增加相位状态元数据，不要求字节一致。

本轮不把新候选覆盖成默认“更优方案”。下一阶段应以风格用途组织 QRP 配方，保留规整
装饰与松散分簇两类选择；是否继续增强变化取决于实际视觉目标，而不是最大化差异指标。
