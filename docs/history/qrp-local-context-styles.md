# 局部 QRP–Wang 构造的三组设计检验

日期：2026-09-27。承接[局部上下文目录](qrp-local-context-study.md)，仅作离线研究，不替换默认 C++ 方法。

## 1. 结论

同一套局部目录构造规则能够用于 q=5/8/12，有限内容库、合法重铺、局部替换和本次 QRP 相位响应均有实际证据。
但它没有成为跨风格一致占优的方法：两层候选在 q=5 的场误差与颜色分歧上退步；三层误差较低，却增加接口并保留三格标签周期。
共享边附近仍可观察到窄颈、轮廓重接及小闭合区域，不以 C¹ 连续或较低误差替代美观判断。

统一黑白显示后的连续源场本身也以圆环、团簇为主。因此，三组已认可配方仍有区别，但不能据此声称已覆盖广泛的几何风格；
这种相近性并不全是 Wang 接边造成的。该判断限于本次源区域和显示高度，不是对所有 QRP 的分类结论。

## 2. 固定比较条件

- 保留青金叠瓣 q=5、靛蓝细描 q=8、铜金镶边 q=12 的实际模态与显示配方。
- 各自使用原 16 个源区，中心 `(16i,16j)`，跨度 16、频率 2；不移动或淘汰源块。
- 每种设计从自己的零相位源边迹，按上一轮同一有限搜索规则选择两层、三层目录；不是冻结 q=8 的图直接套给全部设计。
- 从相位 `(0,0)` 改到 `(0.8,0.4)` 时，冻结所选图、源位置、类型分配和显示。q=5 使用二阶相位基，q=8/12 使用三阶。
- 使用原 28×28 Hermite H¹ 拟合、wave_scale=32、96×96 测量点；384px/瓦片，2×2 线性光超采样。不裁剪场值、不重新归一化。

原端点基线保留已有匹配分配；两个候选保留源 ID 顺序。按源 ID 还原后，三个目录的源场逐值相同。
q=8/12 选到上一轮相同的图；q=5 的弧与源内容对应关系不同，具体保存在各自 results.json 中。
候选的延拓条件、局部替换证据和计数公式沿用上一轮，不新增图族。

| 目录 | 缓存数 / 不同边四元组 | 横 / 竖接口数 | 角点类 | 场自由度 |
| --- | ---: | ---: | ---: | ---: |
| 旧端点 | 16 / 16 | 4 / 4 | 2 | 47,528 |
| 两层局部路径 | 16 / 16 | 6 / 6 | 4 | 47,968 |
| 三层内容变体 | 16 / 9 | 9 / 9 | 9 | 48,636 |

三层是同标签的内容变体，不是 16 种独立边组合。两层和三层分别保留两格、三格上下文颜色周期；都不保证严格非周期性。
指标均匀加权 16 张库内容，不能代表所有合法布局分布下的平均视觉质量。接口预算不同，也不能把收益单独归因于图分组。

## 3. 数值结果及反例

表内为“零相位 / 改变相位”的值 RMSE，均相对同一组原始源块。

| 设计 | 旧端点 | 两层局部路径 | 三层内容变体 |
| --- | ---: | ---: | ---: |
| q=5 | 0.062162 / 0.058873 | 0.064995 / 0.062037 | 0.051960 / 0.050878 |
| q=8 | 0.063410 / 0.064971 | 0.060220 / 0.060880 | 0.049968 / 0.051738 |
| q=12 | 0.046547 / 0.051156 | 0.039562 / 0.040912 | 0.035211 / 0.037254 |

两层在 q=5 的误差增加 4.56% / 5.37%，在 q=8 降低 5.03% / 6.30%，在 q=12 降低 15.01% / 20.03%。
三层分别降低 16.41% / 13.58%、21.20% / 20.37%、24.36% / 27.18%；这不是视觉改进百分比。

边界结构并未随场误差一起全面改善。下表为计数发生变化的“边槽×显示高度”项目数，仍按零相位 / 改变相位排列。

| 设计及项目总数 | 旧端点 | 两层局部路径 | 三层内容变体 |
| --- | ---: | ---: | ---: |
| q=5，512 | 272 / 254 | 291 / 258 | 272 / 259 |
| q=8，512 | 295 / 305 | 272 / 279 | 260 / 268 |
| q=12，384 | 268 / 241 | 274 / 223 | 248 / 222 |

例如 q=12 两层零相位的 RMSE 降低约 15%，变化项目却从 268 增至 274。
q=5 三层在两个相位都降低场误差，但该计数分别持平、变多。
另一方面，计数变化项目减少也不等于保留的总穿越更多：q=8 零相位原源总计 2,108 次，旧端点 1,696 次，两层仅 1,664 次，三层 1,908 次。
这些都是有限高度下的边界诊断，不是二维拓扑、坏像素比例或审美评分；不同设计的分母也不同。

固定显示下颜色分歧（零相位 / 改变相位）：

| 设计 | 旧端点 | 两层局部路径 | 三层内容变体 |
| --- | ---: | ---: | ---: |
| q=5 | 10.039% / 9.748% | 10.346% / 9.923% | 8.997% / 8.571% |
| q=8 | 7.600% / 7.612% | 7.307% / 7.178% | 7.394% / 7.239% |
| q=12 | 11.075% / 10.738% | 10.019% / 9.134% | 9.877% / 9.191% |

相位响应比较的是按源 ID 对齐后的场差 `T(0.8,0.4)−T(0,0)` 与原 QRP 场差，不把图像排布改变算作参数响应。

| 设计 | 旧端点相对 L² 误差 | 两层 | 三层 |
| --- | ---: | ---: | ---: |
| q=5 | 0.185600 | 0.175264 | 0.181847 |
| q=8 | 0.182971 | 0.161500 | 0.139068 |
| q=12 | 0.204892 | 0.149932 | 0.137477 |

本次两个候选的响应误差都较低，但只检验了一个相位变化，不证明任意参数族的响应保真。
q=5 三层混合相位取值约 `[−0.839395,1.002730]`，q=8 三层约 `[−1.033898,1.022847]`；无范围约束的问题仍在。

## 4. 图像和下一步判断

根输出目录 `output/qrp-local-context-styles/` 的图板：

- `comparison.png`：三组设计 × 旧端点、两层、三层，零相位固定彩色配方。
- `phase_comparison.png`：对应的混合相位；目录与显示不变。
- `neutral_comparison.png`：三个目录统一黑白、六个等值高度与线宽；只是诊断，不是新增设计。
- `source_geometry.png`：左列是原本相邻的源区 0、1、4、5，直接组成连续 QRP；后两列为两层和三层合法重铺。源场未经共享投影，不是无约束源块乱拼。

各合法布局固定种子并统一截取左上 2×2，不根据效果挑种子或窗口。连续源图和重铺图不逐点对齐，不能当成空间误差图。
每种设计另有完整 6×6 重铺、真实边标签图集、局部替换及最大改动接边窗口；后者是诊断最坏例，不代表平均效果。

实际图像仍能辨认青金层叠、靛蓝细描及铜金色带。黑白源图同时说明：当前三个源配方的几何语言比较接近，
大量都是嵌套闭合线与圆团；更换 q 和显示配方并不足以证明广泛的形态控制能力。
接边则额外改变部分轮廓的连接、宽窄和局部节奏。源形状发生改变不自动等于不好看，也不要求以后无损保留每条原轮廓。

因此不继续增加目录种类，也不把三层最低 RMSE 宣布为最终方法。保留两层作局部邻接重组候选，三层作周期骨架上内容变体的对照。
后续的核心问题应收敛为：**QRP 的可控形态变化，如何在有限共享接口下仍然有效地表现出来？**

下一轮先从现有 QRP 的方向、幅度与通道组织定义少量几何差异明确的目标，例如环簇与方向流带；先推导控制含义，不承诺尚未验证的图案。
在同一显示下并排检查连续源与 Wang 库，形成一个从源控制到重铺的完整小实验，不独立堆积裸 QRP 预设或界面。
若主要差异在源端就不足，应修改源构造；若在共享接口处被破坏，再推进边界与内部内容的共同构造。
不能把曾做过的“固定目录内移动源位置”重新包装成新方案，也不以调权重或加密网格替代这个判断。
三组已认可设计继续保留为回归样例，用户控制仍只在 QRP 层。

后续[冻结目录后的几何控制](qrp-geometry-control-study.md)已验证环簇到条带的差异，并用源条带充分条件区分主方向保持与局部组织保持。

## 5. 复现、工程收敛与必要验证

```powershell
python -X utf8 tools/catalogue_study.py --local-switches --q 5 8 12
```

需要已有零相位覆盖源池和相位迁移源池；可用原 `--source`、`--phase-source`、`--output`、`--font` 参数指定位置。
多个 q 的局部比较只生成三个目录，不重复上轮完整上下文对照；单个 q=8 默认行为保持不变。
源相位从实际通道元数据读取，兼容没有顶层 global_phase 的旧零相位清单，不填猜测值。

沿用同一个实验入口、求解器、结构测量与缓存拼接。唯一共同显示改动是允许线描配方不带强调线，以支持中性诊断；原配方未改变。
本轮 q=5 的拟合已完成后曾在图板分支报错；修正后直接从保存的结果恢复图板，不为补图重跑拟合。没有隐藏失败候选。

必要检查已完成：

- 18 套库；1,704 次合法边对核对，场值和完整一阶梯度采样差均为 0；1,728 次彩色实例逐像素复用检查。
- 12 次实际局部替换：区域外改变像素均为 0，区域内均有非零变化，外周边标签保持、内部邻接合法。
- C++ 源值与梯度核对最大误差约 2.22×10⁻¹³；线性方程相对残差小于 1.8×10⁻¹⁵。
- 全部源/拟合边界计数在 8,193 与 16,385 点下稳定；不声称严格根隔离。
- 三组连续源图的实际邻接值及完整梯度差小于 7.2×10⁻¹⁴，确认其原生相邻关系。
- 三组旧端点 × 两相位与原覆盖结果完全一致；q=8 的三个目录 × 两相位与上一轮完全一致。合计 12 次库映射/系数对照、192 次 PNG 对照，其中 q=8 旧端点同时对两个历史基准核验。
- 检查最终彩色、黑白、源场及接边图板；Python 语法、文档链接及 diff 格式检查。生产 C++ 未改，不重复无关构建。

按图形研究技能分开源控制、接口兼容和视觉判断；按简化技能复用原入口；按审阅技能做实现者自审，未声称独立评审。
既有未提交研究改动保留；本轮未提交、未推送。
