## 1. 验证原则

1. 先验证局部公式，再验证共享边连续性，最后检查完整实验图。
2. 解析梯度必须与中心差分一致，不能只检查场值。
3. 所有范围结论必须来自公式证书或固定阈值，不使用逐图归一化修补。
4. 参数因果对照一次只改变一个因素。
5. 数值差异、视觉差异、拓扑差异和严格非周期性是不同强度的结论。

## 2. 七组单元测试

当前 CTest 包含原五个模型目标、轮廓几何目标和独立可复用瓦片目标。
下文历史阶段的“五个 / 六个目标”是当时状态。

### 2.1 `qrp_wang_grid_tests`

验证内容：

- 网格尺寸、标签范围和参数校验；
- 相邻瓦片共享边标签完全相等；
- 相同尺寸、标签数和种子生成相同网格；
- 不同合法种子仍满足邻接约束。

该测试只证明有限网格合法且可复现，不证明无限 Wang tile set 严格非周期。

### 2.2 `qrp_canonical_qrp_tests`

验证内容：

- canonical QRP 参考和的原点值、模态数和振幅界；
- 四方向特殊情形的闭式值、闭式梯度和周期性；
- 解析梯度与中心差分一致；
- 完整共振方向集合的旋转对称性；
- 归一化采样坐标到模型坐标的映射；
- 项目实际使用的非晶体学方向组合不能误写为单位环面周期。

### 2.3 `qrp_wang_content_weight_tests`

验证内容：

- 合法与非法参数的统一处理；
- 局部解析梯度与中心差分一致；
- `K=5` 的代表性认证参数下，全部 `5^4=625` 个边标签签名保持有限并满足范围；
- 每一方向上的全部兼容标签对在共享边上具有相同场值与完整梯度；
- 瓦片角点统一满足 `W=w*`、`grad W=0`。

共享边测试必须同时覆盖切向和横向导数，只比较像素颜色或只比较场值均不充分。

### 2.4 `qrp_hierarchical_qrp_composition_tests`

验证内容：

- 解析梯度与中心差分一致；
- 中、细尺度强度为零时精确恢复粗场值和梯度；
- 默认参数的保守范围采样；
- 负强度和不安全的强度和被拒绝。

### 2.5 `qrp_parametric_wang_qrp_field_tests`

验证内容：

- 零全局相位、零 Wang 相位时退化为归一化 canonical QRP；
- 参数化 QRP 的解析梯度与中心差分一致；
- 改变方向数、空间频率、全局相位或 Wang 相位会改变场值；
- 余弦平均始终位于 `[-1,1]`；
- 非法方向数、频率、权重中心或认证半径被拒绝。

### 2.6 `qrp_contour_geometry_tests`

验证直线距离、幅值缩放不变性、扫描线奇偶性、双线性鞍点连接和圆形近似，详见 §11。

### 2.7 `qrp_reusable_qrp_tiles_tests`

在固定与匹配来源政策下验证受限 16 类型集的全部合法类型邻接（两方向各 64 对），
比较局部边坐标上的场值与完整梯度；检查内部精确恢复、范围、过渡交叠处梯度中心差分，
以及局部来源匹配目标非增。它不借用相邻瓦片相同的全局求值位置。

| P0–P1 | 0.291436 | 36.69% |
| P0–P2 | 0.436893 | 59.82% |
| P0–P3 | 0.438151 | 60.49% |
| P1–P2 | 0.276631 | 34.20% |
| P1–P3 | 0.389104 | 51.56% |
| P2–P3 | 0.447371 | 61.16% |

这些统计量用于证明参数组在固定窗口中不同，不能单独证明轮廓拓扑发生变化。

## 6. 视觉检查

每次改变数学模型、采样坐标、色带或输出尺寸后，至少检查：

- 七张图均成功解码、尺寸正确且画面非空；
- `A` 图中的四个粗骨架具有清楚差异；
- `B` 图中的统一层级没有覆盖粗骨架差异；
- `C` 图可识别 Wang 调制贡献，同时没有明显瓦片方格和共享边裂缝；
- P0 仍含 Wang 调制，不能误标成 canonical 或 uniform 基准；
- 图像方向与全局坐标约定一致，没有上下翻转导致的误读。

## 8. 固定 Wang 的 QRP 参数探索

`--style-study` 沿用本项目同一模型与采样路径，不新增 CTest 目标。
改变实验参数或排版时，按本轮改动选择必要检查：

- 共 16 组、每组三种视图，原图尺寸为 `640 × 640`，能正确解码；
- 灰度使用固定 `[-1,1]` 映射，不做逐图归一化；
- S13–S16 的粗场应与 S03 相同，S13 的分层结果应恢复粗场；
- 改动共享采样路径时，确认旧的七图实验未被改变；
- 人工对比结构与着色，结论注明是视觉观察还是数值统计。

Wang 配置在此模式中固定，不作为用户控制变量。历史 uniform–Wang 图用于内部机制对照，
不能用于判断 Wang 是否应承担用户风格控制，也不能单独衡量其铺砌价值。

## 13. 风格跨度研究

沿用六个 CTest 目标。参数化 QRP 测试增加一个通道组合用例，覆盖四种关系的解析梯度、
范围采样、横竖共享边的场值与完整梯度，以及父子门控的内部恢复和外部背景。
门控梯度差分特意取在过渡中心，不以平坦背景上的零梯度检查代替链式求导验证。

Release 构建与六组 CTest 通过。13 组配置各输出 640px 和 1600px 三种视图，
共 78 张原图全部解码、尺寸正确且非空。两组 Direct 基准的三种视图与上一轮字节一致；
乘积填充/线描、联合能量两种阈值各自的原始场一致；两个分辨率的参数与轮廓段数一致。
已目视检查全部 640px 对照板及 1600px 曲线网格、分区条纹代表图。

这是必要的模型与成图检查，不增加大规模防御测试或“美观分数”。
风格跨度目前是视觉观察结论，乘积零集交点的离散拓扑、任意参数组合的效果、
外边界周期重复与商业适用性未被认证。配置和候选取舍见 [风格跨度研究](qrp-diversity-study.md)。

## 15. 相位兼容候选

沿用七个测试目标，在可复用瓦片用例中检查谱振幅复用、全部合法类型邻接的值/完整梯度、
范围、解析梯度中心差分及贯通核心带充分条件。等权案例不满足该条件，不作过度声明。
Release 构建与七组 CTest 通过。两个跨度共 120 张原图解码，480 个 Wang 实例与各自源图
RGB 完全一致；六例实际布局接边采样最大误差约 4.452e−14。旧来源混合 111 张 PNG 回归
字节一致。已检查三风格、两跨度及两布局复用板。
另检查 240 个单瓦片周期对照实例的像素复用；类型 0 可合法自匹配，未用非法拼接制造反例。

核心带结论来自相位提升和梯度下界推导，不等同于全部零轮廓拓扑认证。
整数圈闭合有周期骨架，不是原始 QRP 等价实现；增大瓦片的实验没有消除规则组织。
数学身份与参数分支跳变等限制见 [相位兼容研究](qrp-phase-compatible-tile-study.md)。

各自字节一致。manifest 新增组合关系与门控参数，不将图片回归扩展为元数据字节一致。

谱分辨率规则直接读取模型导出的模态，不在 Python 重写生成公式。最大平均波矢闭合

## 17. 大范围重铺与内部相对相位

新增一个研究模式而非测试目标；先将旧 384px 库扩到 8×8，再只改变父场内部 QRP 相对
相位状态。两布局各含全部 16 类型，新旧方法共 114 张原始 PNG 全部解码，768 个 Wang
实例和 384 个合法周期实例均逐像素复用。旧库 48 张源图与上一轮字节一致。

模型新增状态相位偏移，默认零保持旧构造。Release 编译及七组 CTest 通过；既有父子
用例同时检查零/非零偏移的合法接边、完整梯度、范围、支撑域与门控差分，并核对两个
端点状态与直接 QRP 求值一致。两方法实际接边抽样最大误差≤1.009e−12。
