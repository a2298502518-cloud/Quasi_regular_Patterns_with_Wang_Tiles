# 有边界的 QRP–Wang 阶段研究

建立日期：2026-09-27。目标来自本线程用户确认的阶段安排；不是预先锁定某一种算法。

## 验收目标与边界

- 三类清楚不同的几何组织，每类两个 QRP 参数状态，共六组候选纹样；统一几何显示下仍有差异。
- 正常展示和固定局部放大中，没有明显由拼接造成的成排异常扭曲或网格痕迹；保留有意义的类内变化。
- 每组先生成固定有限 Wang 内容库，再在两个以上合法布局中逐像素复用；实际标签保证接边，并有内容变化的合法局部替换。
- 不使用实例坐标重生成，不对成图补缝；用户只调整 QRP 层。以 16 张库为起点，允许有证据地修改 QRP 与 Wang。
- 交付样张总览、必要局部图、实际库/布局证据和简明方法与局限；美观由用户验收，不拿 RMSE、方差或条带证明代替。

最多三轮方法级迭代，每轮含推导、实现、必要验证和真实出图。小参数调整不另计一轮。
达到上述目标则收尾；连续两轮无实质改善或出现必须由用户决定的取舍则提前报告；三轮后不自行扩展研究。
未满足目标不得标记纹样效果达标。不开发 UI，不扩大防御性测试，不擅自提交或推送。

## 轮次记录

### 第 1 轮：局部相位梯度约束（已完成候选交付）

前置证据：[相位推进研究](qrp-phase-transport-study.md)。上一轮统一缩放相位残差可满足条带充分条件，但同层内容变化仅保留原源约 35.9%。

本轮不是继续选择一个缩放系数，而是在原相位 H¹ 目标的求解中，直接约束每个单元的相位残差偏导。
固定 `|∂uψ|,|∂vψ|≤||ω||/4=8`，所有源块、目录、显示、相位整数提升仍与前置对照一致。
共享 Hermite 自由度继续保证边界，Bernstein 控制系数把全单元偏导界写成线性不等式，得到凸二次优化问题。
先比较同一旋转条带中的原总场拟合、原统一缩放与本轮局部约束；不把求解器成功视为视觉效果成功。
若有实质改善，再扩展三类形态及参数状态；没有改善就记录证据，不先堆六组图片。

使用 OSQP 求解该二次问题；接口、误差和状态语义依据[官方 Python 接口](https://osqp.org/docs/interfaces/python.html)及[设置说明](https://osqp.org/docs/interfaces/solver_settings.html)。
理论中的边界相容和相位约束由本项目推导；OSQP 的收敛状态不能替代接边、梯度界或视觉核验。

#### 三类扩样与相位控制

在同一局部约束下扩样，不重新优化目录、源位置、铺砌种子或每类的导数限值。全部采用 C++ 导出的 q=8 波谱：

- 环簇：等权单通道。
- 条带：方向偏置 2、旋转 30°的单通道。
- 双向格构：偏置 2 的主方向通道与正交通道相乘。此处使用已有 QRP 通道乘积，不把上轮的双向平均改名为格构。

乘积是新的合成场，不能继承单通道的全部等值线结论；零高度包含两个通道的零集，交点可以是临界点。
这不是有上下遮挡的真实编织模型。各通道仍用同一相位图和源谱幅度，乘积及梯度通过已有 `multiply_fields` 计算。

每类展示 (A,B)=(0,0)、(0.8,0.4)。**冻结零相位整数提升，而不是改参数时重新按最近整数选分支。**
固定波向下 C++ 相位控制给每个模态增加所有类型共同的常数 δⱼ。
共享相位 ψⱼ整体增加 δⱼ不会改变任何梯度约束；它同时平移目标与可行解，故原 H¹ 最优解可直接传递。
因此这条相位控制路径在连续场上平滑且接边性质不变，既不需要重选目录，也不需要重新求解。
改变幅度不影响逐模态的独立相位求解。改变波向/频率导致绕数变化的问题仍未解决，不把这条相位路径推广到全部参数。

环簇与双向格构共享角度为 0 的相位库；条带另用 30°相位库。只求解两次，不为六张图分别发明生成规则。
彩色展示借用已有三套高度/颜色映射；统一黑白等值线单独检查形态差异，不改写原 q5/q8/q12 配方快照。
扩样入口 `python -X utf8 tools/stage_study.py`，默认输出 `output/qrp-stage-round1`。
#### 六组结果

统一黑白图中可区分三种组织：不等大的嵌套环簇、沿主要方向延伸的条带、两个方向共同构成的格构。
两组相位改变了局部轮廓和位置关系，没有靠更换配色制造组内变化。环簇保留有机的不规则单元，格构保留行列节奏；
这不是全部变成正圆或直线，也不是要求抹去 QRP 干涉本身的变化。

正常样张、完整布局和固定接边窗口中，未观察到原总场对照中的集中成排接缝波折；仍有局部拉伸和粗细变化，不能说所有位置的形态完全不受约束影响。

## 方法边界与后续待判断事项

- 当前交付验证的是 q=8 的这三类组织和相位路径，不是任意 q、任意偏置或全部参数范围。
- 仿射载波仍量化为 π 整数，仍有两层周期背景；图案不等于严格全局 canonical QRP，也没有严格非周期性证明。
- 相位和幅度控制可以复用固定相位图；角度、频率跨绕数边界的跳变问题仍在。不能把已证明的 A/B 相位路径连续性推广到全部参数。
- 相位场连续不等于着色图处处连续，等值线的临界事件也不被排除。单向条带条件不推广为环簇或乘积的全域拓扑保证。
- 彩色映射分别借用青金叠瓣、靛蓝细描、铜金镶边的既有配方，但六组实际源均为 q=8；没有替换原三套 q5/q8/q12 基线。
- 尚未做用户研究、具体印花工艺或市场验证。用户下一步可依据候选图判断哪些组织值得作为论文和应用样例，不先扩展 UI 或自动新增实验目标。

## 工程收尾

图形研究技能用于把局部导数界、Wang 接边和 QRP 参数响应分开推导；简化技能用于收敛共同实现：
`phase_field.py` 拥有相位模型，`qrp_sources.py` 适配 C++ 导出，`joint_field.py` 拥有共享求解和 Bernstein 表达，
`wang_tiles.save_layouts` 统一三个实验入口的缓存重铺与局部替换核验。没有为六组样张复制六个生成器。
提取后的 C++ 导出适配器精确复现原 16 个环簇源，公共重铺输出与已生成三张布局 PNG 的 SHA-256 完全一致。
代码审阅为实现者自审，不冒称独立评审。已完成相关 Python 语法、文档链接和 diff 检查；C++ 未变，不重跑无关整套构建。
