# 从接边连续转向相位推进：条件、反例与代价

日期：2026-09-27。承接[几何控制研究](qrp-geometry-control-study.md)。这是旋转条带的最小可行性实验，不替换现有候选，也不新增一种风格。

## 1. 本轮改变了什么判断

1. 相同边标签上的值、梯度甚至任意阶边界数据，都不足以单独规定内部等值线的组织。不能只修边迹，便声称整个瓦片保持条带。
2. 有限 Wang 内容复用和有序条带**可以相容**：共享相位边界、全域主相位单调及余项导数界共同给出充分条件。
3. 把目前的总场 H¹ 拟合直接换成逐相位 H¹ 拟合，仍可能严重扭曲。统一压缩相位残差可以获得保证，却会压缩同一层上下文内的内容差异。本轮不把这种统一压缩方案升为主线。

这不是要求所有 QRP 都必须变成直条带，也不是要求所有源轮廓无损保留。单向条带只是一个能够明确写出形态条件的检验对象。
环簇、双向组织不受本轮条带条件约束。最终目标仍是 QRP 控制下的多样纹样与有意义的有限 Wang 复用，而不是追求一个拓扑指标。

## 2. 为什么只规定边界不够

取一个本来有序的条带场。在瓦片内部、某条等值线一侧、远离边界的位置放置一个光滑紧支撑扰动：
边界附近扰动恒为零，因此不改变任何接边值或导数；但足够大的扰动可让局部场值从阈值一侧越到另一侧，产生额外的封闭等值线。
所以边界兼容不能排除内部新环或回折。这个论证不针对某种 Hermite 网格，也不否定原方法的 C¹ 证明。

应当保留两种不同声明：

- 接边声明：所有合法邻接处实际内容连续；这是 Wang 复用的基本条件。
- 形态声明：某一族等值线持续按指定方向延伸；需要额外的内部条件。

## 3. 适用于相位扩展的条带充分条件

沿原主波法向 n 的坐标记为 s，垂直坐标为 z。把当前 q=8、反向共轭的主波对合并，写成

\[
T=M\cos\Phi+R,\qquad |R|\le r,
\qquad \partial_s\Phi\ge L>0,\qquad |\partial_sR|\le B.
\]

这里 Φ 不必是仿射函数，可以随 Wang 内容变化。若某个显示高度 h 满足

\[
|h|+r<M,\qquad \sqrt{M^2-(|h|+r)^2}\,L>B,
\]

则在 T=h 的点上，主波方向导数的绝对值严格大于余项方向导数，故 ∂sT 不为零。
在每个主相位半周期两端，T−h 异号；同一半周期中的所有穿越方向相同，因此恰有一个根。
由于 Φ 沿 s 严格增长并趋于正负无穷，隐函数定理把这些根延续成全局图形分支 sⱼ(z)，没有相对于 n 的回折或闭合分支。

这份结论要求合法铺砌有全平面延拓，且提升后的 Φ 全局 C¹；两层目录及下节构造满足这些条件。
有限图片中的曲线仍会被画框截断。它不保证带宽恒定、曲率小或美观，也不保证条件外高度的拓扑。
不满足充分条件不能反推存在回折。

若其他配对模态为 `aⱼ cos Φⱼ`，则可以取 `r=Σaⱼ`、`B=Σaⱼ sup|∂sΦⱼ|`。
本轮保持 C++ 导出的所有非负幅度，因此还有 `|T|≤Σaⱼ=1`；没有裁剪或归一化场值。

## 4. 两层 Wang 相位构造

沿用上一轮两轴图 `[(0,1),(1,0),(0,2),(2,0)]` 和弧颜色 `[0,1,0,1]`。
类型 t=i+4j，层起点颜色为 `(cᵢ,cⱼ)`；合法邻接使对应方向的颜色交替，另一方向的颜色相同。
仍是 16 种边四元组、6+6 边接口，原有两格局部替换保留。用户不接触这些内部参数。

对每个合并后的导出模态 ω，固定

\[
p=\operatorname{round}(\omega/\pi),\quad b=\pi p,
\quad \theta_t=\pi(p_xc_i+p_yc_j),
\]
\[
\Phi_t(u,v)=b_xu+b_yv+\theta_t+\lambda\psi_t(u,v).
\]

ψ 使用现有 Hermite 共享自由度构造，标签相同的边共享整个实值相位残差及梯度；角点按实际边标签闭包共享。
东西合法邻接的相位差为 `πpₓ+πpₓ(cᵢ−cᵢ′)=2πpₓcᵢ`，南北同理；残差及完整梯度一致。
因此所有余弦项及最终场的值、完整梯度都相同，不需要事后补缝。

令全局格坐标仅用于证明，可把每个相位提升成 `b·(x,y)+常数+λψ(x,y)`。
这里 ψ 是全局 C¹、有界的分片场；渲染和重铺时**不使用实例坐标**，只复制固定类型缓存。

### 本构造的必然代价与适用范围

长期平均波矢是 b，不是 ω。本例主波由长度 32、法向 30°变为 `b=(9π,5π)`，法向约 29.0546°。
λ=0 时内容退化成共同的两格周期场；λ>0 允许真正随合法类型变化，但仍带周期载波背景。
round 还会在参数跨越半整数界时跳变；本轮固定一个参数状态，**没有解决连续旋转/相位交互中的跳变**。

一个限制可以直接看出：若要求在无限格点线上精确保留某个固定仿射相位，每个单位格的推进量为 ωₓ，
同时每个格点的相位模 2π只能取有限个值，则两个不同格点必重复相位，迫使 `mωₓ∈2πZ`。
不可公度的仿射推进不能满足这个特定的有限相位状态要求。这个论证不是对任意标量 Wang 场、任意可变相位、所有 QRP 扩展的不可行性定理。

### 与早期逐模态闭合的关系

早期[相位兼容对照](qrp-phase-compatible-tile-study.md)已使用“相位模 2π接边”和周期载波，不能把这些原理重新包装成新发现。
区别是：早期用 `2π round(ω/2π)` 与固定三次闭合项；本轮利用两层调度允许 π 整数载波，并让共享 ψ 承接不同源块。
早期证明的是正负核心带贯通；本轮显式加入余项导数界，对规定高度给出每半周期唯一横截根的更强条件。
两者都实质修改 QRP 的全局谱；本轮并没有摆脱早期的周期背景问题。

## 5. 最小实验，避免把表示变化说成公平最优比较

只取上一轮 rotated 配置：q=8、方向偏置 2、旋转 30°、频率 2、跨度 16、三阶零相位。
16 个源中心、两层目录、三份布局及靛蓝细描配方全部不变。

相位目标为原模态相位减去载波与层起点，再按每块中心最近的 2π 整数独立提升。
这只是一个明确可复现的分支选法，**没有联合优化整数提升、源块分配或边界绕数**。
每个相位残差用 8×8 Hermite 网格（3,488 个共享自由度）与既有 H¹ 求解器拟合，导数尺度仍为 32。
对照总场使用上一轮的 28×28 网格；两者的函数表达、自由度预算不同，结果不能冒充等预算最优算法排名。

比较四列：连续原源、原两层总场拟合、未约束相位拟合 λ=1、受充分条件约束的统一缩放。
最后一种仅寻找使 `|h|≤0.41` 的充分条件成立的 λ 区间，取其边界的 90%留数值余量；不是按审美挑参。
该 90%不是用户控件，也不是原 QRP 幅度缩小；所有模态幅度保持不变，缩放的只是相位残差。

### 全域界怎样计算

每个 Hermite 双三次单元先转为 Bernstein 控制系数。偏导为相应方向相邻系数差乘 `3×cells`；
将二次方向升为三次后，线性组合得到 ∂nψ 的控制系数。非负 Bernstein 基的和为 1，因此系数最小/最大值包住整个单元。
取所有单元、所有类型的极值，得到 `[lⱼ,uⱼ]`。则

\[
L=b_*\cdot n+\lambda l_*,\quad
B=\sum_{j\ne *}a_j\max(|b_j\cdot n+\lambda l_j|,|b_j\cdot n+\lambda u_j|).
\]

这不是网格采样冒充全域界。实现使用双精度且保留正裕量，不是带定向舍入的区间算术认证；这些界也可能保守。
统一缩放只是可行性构造，得到的 λ 不是所有相位方法或所有有序纹样允许变化量的必要上限。

## 6. 实际结果与判断

M=0.775803493、r=0.224196507。未约束主相位导数下界约 −104.2655，不能获得条带充分条件。
充分条件边界约 0.116916，选定 λ=0.105224222。此时：

- 主相位方向导数下界 L=17.966039224；余项导数界 B=7.070407476。
- 在 |h|=0.41 处严格裕量为 0.957534746；实际充分条件覆盖 `|h|<0.444380363`。
- 包含零高度和原线描中的 −0.35、−0.16、0.03、0.22、0.32 强调线、0.41；不包含 0.60、0.79。
- 原源条件覆盖到约 0.537265083；不要把本轮扩展说成比原源保证更强。

| 方法 | 对原源值 RMSE | 主法向 / 度 | 全库类型差异 RMS | 同层上下文内差异 RMS |
| --- | ---: | ---: | ---: | ---: |
| 原源 | 0 | 29.9975 | 0.557888 | 0.335848 |
| 原两层总场拟合 | 0.085337 | 29.4432 | 0.545674 | 0.320075 |
| 未约束相位拟合 | 0.364582 | 29.5507 | 0.553754 | 0.359646 |
| 有界相位构造 | 0.983722 | 29.0599 | 0.558260 | 0.120550 |

有界构造改变源相位很大，因此逐源块 RMSE 大；RMSE 不能直接排美观，更不是必须逐点恢复源块的用户要求。
图中最后一列的接边走向较顺，但大图更接近重复组织。两份合法布局和局部替换仍有像素差异，所以也不能说 Wang 已经失效或完全等于普通重复。
全库类型差异 RMS 看似没下降，是因为它把不同层起点的载波相位也计入了差异。
按四组层起点分别减去组内平均场后，有界构造的差异只保留原源约 35.9%，而原两层约保留 95.3%；这是标量变化统计，不是风格数。
所有原始数字保存在 `results.json`，不把组合布局数当作视觉差异量。

**决定：保留为形态可保证的可行性对照，不替换总场候选，不再沿统一压缩 λ 调参。**
这轮排除的是“简单换成相位拟合、再整体压缩，就解决组织与变化兼顾”的做法，不是否定相位表示本身。
下一步应把相位兼容与局部推进约束放进生成/求解过程，同时保留层内内容变化；先检查可行自由度，
而不是拟合完再把所有残差一起缩小。整数提升和边界相位也应共同考虑，不能把本轮的独立最近整数分支选择当成唯一正确选择。
仍需用形态与变化的图像证据取舍，不能只优化一个证明条件；更不扩展 UI 或增加新预设来掩盖当前问题。

## 7. 复现、工程边界与验证

```powershell
python -X utf8 tools/geometry_control_study.py
python -X utf8 tools/phase_transport_study.py
```

后者读取前者的实际源谱、冻结目录与系数，记录报告和源文件 SHA-256；支持 `--reference`、`--output`、`--font`。
默认输出 `output/qrp-phase-transport-study/`：`comparison.png`、`reuse.png`、`phase_library.npz`、`results.json`，
以及四种方法的源/缓存图和两种新库的三份布局。比较图均取固定左上 2×2，源图仍取连续源 0、1、4、5；不是逐点对齐图片。

公共 `Projection.fit_samples` 让总场与相位残差共用原求解过程；`directional_bounds` 只承担该表示的导数界。
方向统计移入已有共享测量模块，两个实验入口都从它导入，不让新实验依赖旧实验编排。
没有改 C++ 源公式、生产入口、默认三组配方或现有内容库。新脚本是本轮研究对照，不添加生产模式枚举或 UI 状态。

必要检查：Hermite 已知多项式、仿射导数 Bernstein 界、随机多项式采样落在界内；提取求解接口后代表性系数逐项相等；
新场解析梯度与差分相符；原总场及两个新库各 96 个合法边对的值/完整梯度一致；两个新库各 108 次像素复用，
局部替换区域外像素不变、区域内确有变化；图板检查与语法/diff 检查。不重跑无关 C++ 或大规模拓扑测试。
