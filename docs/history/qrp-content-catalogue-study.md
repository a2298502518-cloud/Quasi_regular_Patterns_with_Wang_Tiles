# 固定 QRP 源池的内容驱动 Wang 目录

实验：2026-09-26；整理：2026-09-27。离线研究探针，不替换生产 C++ 方法，不新增用户 Wang 参数。

## 1. 本轮问题与控制变量

[上一轮](qrp-source-interface-study.md)在固定目录中联合选择源位置与相容场；保留源内容各变化方向后，局部改善较小。
本轮回到优化前的完整源池：同一批 16 个 q=8 靛蓝细描源块，不移动、不淘汰、不另调设计相位。
改变的是边标签的组织及其允许的类型邻接，而不是更换一批容易接边的源。

源中心为 `(16i,16j)`，i,j∈{0,1,2,3}；源 ID 为 i+4j。
每个源是 C++ 导出的真实 QRP 局部限制，频率 2、跨度 16、三阶相位基、vertex_shift=0。
因此本轮 raw 与 target 相同，不含依赖类型编号的二值角点形变。
保留原 28×28 双三次 Hermite 网格、H¹ 权重 32、显示高度、配色和 2×2 超采样。
所有目录都只生成 16 张固定内容图，铺砌只复制像素。

四种目录：

| 名称 | 内容到目录的安排 | 每方向接口数 | 角点等价类 | 场自由度 |
| --- | --- | ---: | ---: | ---: |
| endpoint | 原二值端点目录，沿用 q8_matched 分配 | 4 | 2 | 47,528 |
| fixed_graph | 预先固定的双图乘积，标签带另一方向上下文 | 12 | 9 | 49,284 |
| content_graph | 按源边迹选择双图，标签带另一方向上下文 | 12 | 9 | 49,284 |
| free_graph | 按源边迹选择双图，去掉另一方向上下文 | 3 | 1 | 47,308 |

固定图与内容图的拓扑同构，接口、角点、场自由度及合法布局数均相同，是隔离内容分组作用的对照。
旧目录与图目录之间则不是等预算比较。解除上下文也同时减少接口与角点自由度，不能把其损失全部归因于布局自由。

## 2. 图目录：真实 Wang 约束及其延拓

横、竖两个有向图各有 3 个状态、4 条带 ID 的弧。
横弧 i 为 `(x₀,x₁)`，纵弧 j 为 `(y₀,y₁)`，类型 t=i+4j 采用对应的原 QRP 源块。
边标签按 S,N,W,E 排列；H 与 V 分属不同的颜色空间，不相互匹配。

### 2.1 携带上下文的标签

\[
S=(y_0,i),\quad N=(y_1,i),\quad W=(x_0,j),\quad E=(x_1,j).
\]

实现用 `4*state+arc_id` 编码。
合法左右邻接要求纵弧 j 相同、横状态相接；合法上下邻接要求横弧 i 相同、纵状态相接。
因此任意合法矩形都是一条横路径与一条纵路径的笛卡尔乘积。
它不是只能复原原图：图中存在分支，同一张缓存瓦片可以接不同邻居。
但其横向弧 ID 在整列不变、纵向弧 ID 在整行不变，二维变化受到很强限制。

### 2.2 解除上下文的标签

\[
S=y_0,\quad N=y_1,\quad W=x_0,\quad E=x_1.
\]

现在每一行可独立选择横路径，每一列可独立选择纵路径；它们在交点共同确定类型 i+4j。
不需要在实例位置重新生成纹样，不需要拼完后修缝。
这恢复了二维组合选择，但把原来按四种上下文区分的边曲线合并到一起。

### 2.3 有限矩形可延拓，而非严格非周期性证明

设图的弧计数邻接矩阵为 A。搜索只接受 A⁸ 的每项均大于 0 的图，输出完整整数矩阵作为证据。
这保证任意状态间有长度 8 的路径，因此每条弧都可进入一条双向无限路径，没有不可延拓的端点。
对带上下文目录，分别延长两条路径；对解除上下文目录，分别延长已有的每行、每列路径，再任意补充新行列。
所以每个有限合法矩形都能延拓到整平面，且全部 16 类型均可出现。
此论证依赖本轮图乘积结构，不是对一般 Wang 目录的可判定性主张，也不声称任意有孔有限图块都能填补。

这些目录仍允许周期铺砌。A⁸>0 既不证明严格非周期性，也不意味着所有合法布局在视觉上都不重复。
示例只使用事先固定的种子 20260926、20260927，不为隐藏重复更换种子。

## 3. 边标签还必须决定实际角点相容性

旧 dof_map 直接用类型 ID 的四个二进制位规定角点共享。这对旧端点目录正确，不能沿用到新目录。
现在由真实边标签推导角点等价类：同方向、同标签、同一端的角点必须相同，再取传递闭包。
横边从左到右，竖边从下到上；使用共同局部坐标轴，不反转成外法线导数。

每个等价角点共享 `[f, h f_u, h f_v, h² f_uv]`；同标签边的全部内部节点也共享这些自由度。
双三次 Hermite 边迹由相同的端值/端导数确定，因此同标签的整边场值及完整一阶梯度一致，而不只是采样点恰好相等。
所有类型在同一个相容空间内联合拟合，生成后固定复用；不是逐张独立拟合再贴标签。

传递闭包在两种图目录中分别得到 9 类与 1 类角点，后者本身也是更强的形态约束。
旧目录则仍是 2 类，且生成的自由度编号与旧库逐项一致。
这项泛化修正了旧实现适用范围过窄的问题，不表示旧目录的既有计算错误。

## 4. 内容驱动搜索的实际范围

每个方向的 4 个源区间有 8 个端槽，每个端槽在另一方向有 4 种源上下文。
沿边取 65 个点，以梯形积分权重比较 `(f,f_u/32,f_v/32)`。
图标签决定哪些边迹必须共享，目标是这些边迹对其组均值的平方距离之和。
带上下文时四种上下文分别求均值；解除上下文时一起求均值。
这只是边迹兼容性的代理目标，忽略完整拟合中的内部响应和角点耦合，不冒充已消元的全场 H¹ 目标。

穷举 8 个端槽到 3 个状态的满射，规范首次出现的状态编号，去掉纯颜色重命名。
每方向恰有 48 个候选满足本轮 A⁸>0 的筛选；取其中代理目标最小者。
这是限定构造族内的穷举，不是所有 16 类型 Wang 目录的全局最优。
筛选条件是便于证明延拓的充分条件，不是一般可铺砌目录的必要条件。

固定对照的弧为 `[(0,1),(1,0),(1,2),(2,0)]`。
两种内容目标在本次 q=8 源池上均选择 `[(0,1),(1,2),(2,0),(0,2)]`，横竖相同：

\[
A=\begin{pmatrix}0&1&1\\0&0&1\\1&0&0\end{pmatrix},\qquad
A^8=\begin{pmatrix}4&3&5\\2&2&3\\3&2&4\end{pmatrix}.
\]

带上下文时，每方向代理能量从固定分组的 0.079239 降到 0.037348；
解除上下文时则从 0.164715 降到 0.162874。该数值仅在相同目标定义下比较。
图仅从零相位选一次，后续 ψ=(0.8,0.4) 不重选图或移动源块。
横竖结果一致不是跨风格验证；本轮尚未验证 q=5/12 或任意 QRP 参数。

## 5. 实际结果与不可隐藏的代价

### 5.1 同一源集合上的拟合

| 指标 | 原端点 | 固定图分组 | 内容图分组 | 内容图解除绑定 |
| --- | ---: | ---: | ---: | ---: |
| 零相位场值 RMSE | 0.063410 | 0.049808 | 0.035684 | 0.078314 |
| 零相位归一化梯度 RMSE | 0.078109 | 0.062781 | 0.039557 | 0.097959 |
| 混合相位场值 RMSE | 0.064971 | 0.050574 | 0.037594 | 0.076656 |
| 零相位改变的边槽×高度计数 / 512 | 295 | 220 | 220 | 314 |
| 该分组必要计数变化下界 / 512 | 239 | 138 | 98 | 228 |
| 混合相位改变的计数 / 512 | 305 | 242 | 221 | 323 |
| 零相位固定显示颜色分歧 | 7.600% | 5.856% | 5.779% | 7.945% |
| 相位响应余弦相似度 | 0.983200 | 0.989279 | 0.994342 | 0.977566 |
| 相位响应相对 L² 误差 | 0.182971 | 0.146052 | 0.106231 | 0.211064 |

带上下文的内容图，相对旧目录场值误差降低 43.73%；相对相同预算的固定图降低 28.36%。
后者支持“内容分组确实有作用”，不是仅靠增加接口数量。
但两种图分组的零相位计数变化同为 220：较低场误差和较低必要下界并未自动转化为更少的实际计数变化。
该计数只针对固定显示的八个高度，不是二维拓扑或审美评分。

四种方法按源 ID 对齐后的目标场逐值相同，源内容内部 RMS 均约 0.291482，有效秩约 5.442415。
输出内部有效秩分别约 5.440322、5.441454、5.441667、5.440011。
本轮没有通过源池收缩获得收益；这些内部场指标也没有保证接边母题完全保持。

内容图混合相位的采样范围为 `[−1.051632,1.022759]`，比旧目录 `[−1.016876,0.990491]` 越界更多。
依然没有范围约束，没有裁剪、重新归一化或改变显示来隐藏问题。误差降低不能抵消所有剩余缺陷。

### 5.2 布局选择并不是免费的

令 Wₓ(n)、Wᵧ(n) 为两个图的长度 n 弧路径数，即所有 Aⁿ 元素之和。
带上下文目录的 n×n 布局总数恰为 Wₓ(n)Wᵧ(n)；解除上下文时为 Wₓ(n)ⁿWᵧ(n)ⁿ。
本轮两图 W(6)=16。原二值端点目录则由 (n+1)² 个独立二值顶点唯一确定。

| 目录 | 每库合法有向邻接对（两方向合计） | 6×6 合法布局总数 |
| --- | ---: | ---: |
| 原端点 | 128 | 2⁴⁹ = 562,949,953,421,312 |
| 固定图分组 | 40 | 256 |
| 内容图分组 | 40 | 256 |
| 内容图解除绑定 | 160 | 2⁴⁸ = 281,474,976,710,656 |

带上下文构造的布局数对边长是指数增长，其对数除以面积趋于零。
解除上下文的内容图有两条长度 6 的不同闭合路径：重复两次三弧环与重复三次二弧环。
当 n 是 6 的倍数，每行每列都可独立串联这些路径，至少得到 2^(n²/3) 个布局，具有真正随面积增长的组合选择。
这些是精确计数/构造关系，不是随机图片重复率或视觉丰富度评分；严格非周期性仍未证明也非本轮目标。

解除上下文虽恢复了这类选择，场值误差却比旧目录增加 23.50%。
它同时将接口 12→3、角点类别 9→1，不能用此对照推出二维布局自由与保真之间的普遍不可能性。
只能说本次“全部保留上下文”与“全部抹掉上下文”两端都没有兼顾目标。

## 6. 本轮决定及下一步

保留“内容兼容关系参与目录构造”的方向；不将带上下文图直接替换主线，也不因解除绑定版不佳否定 Wang 方法。
两种图作为必要结构对照，使用同一研究入口；不扩展 UI、风格预设或为它们各自新增生产实现。

下一步需要研究 **局部上下文如何进入标签而不强制整行整列相同**，并联合检查角点闭包、延拓与源结构改动。
先给出这种目录的构造条件，再比较相近接口/类型预算下的效果；避免仅增加颜色数或放宽约束后宣布方法进步。
如果必须增加类型预算，应明确计算与存储代价，不将其隐藏成一次参数微调。
目前尚未证明这一构造一定存在或一定优于旧目录。

后续：[局部上下文目录](qrp-local-context-study.md)给出了可局部替换且可延拓的构造，
同时记录旧图部分合并仍缺乏局部自由的证据，以及新构造保留周期骨架、增加接口预算的代价。

## 7. 复现、验证与工程边界

先完成内容覆盖实验的零相位与相位迁移，然后运行：

```powershell
python -X utf8 tools/catalogue_study.py
```

支持 `--source`、`--phase-source`、`--output`、`--font`；默认输出 `output/qrp-content-catalogue-study/`。
源池写入 sources.json；目录、图证据、布局、源分配和指标写入 results.json。
每个目录/相位有 library.npz、16 张缓存和两张 6×6 铺砌。
生成物被 Git 忽略，不当作另一套实现来源；不改动以前各轮输出。

本轮必要验证：

- 8 套库全部完成；逐源 C++ 值/梯度核对误差小于 1.1×10⁻¹³，线性方程相对残差小于 1.8×10⁻¹⁵。
- 8 套库合计检查 736 个合法边对，场值与完整梯度采样差均为 0；全部演示布局标签合法。
- 每库 72 个实例纯缓存复用，合计 576 次逐像素检查；求解目标不读取演示布局。
- 带上下文目录的两次演示均合计使用 14 种类型，并非声称已展示全部 16 种；全库生成及图延拓证明覆盖全部类型。
- 每种目录至少有同一缓存类型出现在两个不同的四邻居上下文，记录在结果中。
- 所有源与拟合边的穿越计数在 8,193/16,385 点下稳定；不是严格根隔离证明。
- 原两相位基线系数、映射与 32 张缓存 PNG 和原覆盖库完全相同；共用测量与上一轮基线逐项相同。
- 检查数值图板、Python 语法、diff 和文档链接；生产 C++ 未改，不重复无关构建和测试。

按图形研究技能区分场相容、角点约束、目录延拓和显示；按简化技能共享测量与拼接，按审阅技能完成自审，不声称独立评审。
保留此前未提交研究改动；本轮未提交、未推送。
