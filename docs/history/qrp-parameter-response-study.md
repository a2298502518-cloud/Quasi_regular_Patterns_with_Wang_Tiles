# QRP 参数的形态作用与 Wang 保留程度

2026-09-27。用户已确认开始；最多三轮方法级迭代，不预设风格类别，不开发 UI，不提交或推送。

## 第一轮：分清参数作用（完成）

固定 q=5/8/12、频率 2、源跨度 16、相同源中心、同一 Wang 目录、上一阶段共同整数分支的相位图。
全部使用同一青金分层配色、相同高度阈值，并补充统一黑白等高线；不按结果改变取景和阈值。
源与候选在每一类型的相同局部坐标比较；完整重铺另展示，不把重排的像素差作为损失。

首先把有效相位分为三种作用。记有效频率矩阵 W=A V，A 为已有统一规则得到的整数关系表示：

- 平移：`delta=W t`；源场严格满足 `F_delta(x)=F_0(x+t)`。
- 保持关系的非平移相位：`delta in col(A) intersect ker(W^T)`。它不等价于一般的精确平移，但不改变整数频率关系的相位常数。
- 关系相位：取 `L=[-A[D:,:], I]`，则 `L A=0`。用 `delta=L^T(LL^T)^(-1) chi` 最小范数地改变 `L phi=chi`，不混入前两类。

后两者并不是先验的“风格旋钮”。各自能否改变可解释的宏观组织，或主要产生局部重排，要由推导和图片共同判断。
旧 SVD 第一非平移方向可能混合后两类，本轮报告其分量，不默认它已有明确的设计语义。

### 固定参数路径

1. 已有方向偏置 `beta=0,0.5,1,2`，`crossMix=0`，其余不变。记录实际有效主波幅度，不将跨 Q 相同 beta 说成同等方向性。
2. 保持关系的相位 `t=0,1,2,3 rad`；方向从上述正交投影的第一非零坐标列确定并归一化，不按好看程度挑选。
3. 第一独立关系相位 `chi_0=0,pi/3,2pi/3,pi`；其余关系相位为零。不存在的自由度明确缺席，不为 q8 添加第三种效果。

统一记录局部场响应、方向集中度和固定阈值的正/负区域比例；它们不是美观分数。
另外从源谱零和频率项计算无限区域平均的二、三、五阶矩，辨别“有限窗口重排”与确实改变统计组织；
Wang 库仅报告实际 16 类型有限窗口采样，不把其平均值当作相同无限域统计。

每个 Q 的零状态与各路径末端生成完整 16 类型库、两份 6×6 布局、局部替换和带标签库图。
中间状态保留真实 C++ 源、相位系数和同坐标图；不为重复基线另烘焙同一套库。
核对 C++ oracle、相位关系/导数传递、同标签实际接边、缓存像素复用和局部替换。
不重新求解相位图，因为本轮只改变已有幅度及共同相位；旋转/频率改变需要重建，不冒称已解决其连续控制。

## 第一轮已得到的判断

源中的三类相位维数 `(平移, 保持关系的非平移, 关系相位)` 分别为：q5 `(2,2,1)`、q8 `(2,2,0)`、q12 `(2,2,2)`。
旧 SVD 第一非平移方向落入关系相位正交子空间的长度占比依次为 0.496、0、0.652，因此旧的同名旋钮确实混合了不同作用。
本轮拆分是对已有逐模态相位的坐标解释，不新增波、不改变源公式、不针对 Q 写配方。

当相位增量在 col(A) 中时，任意整数零和频率组合的相位增量也为零。
把有限乘积 `product F(x+h_i)` 展开为有限指数和，对不断扩大的方形区域取平均，所有非零合成频率项趋于零；
只剩整数零和频率项，它们的相位不变。因此这些无限域平移平均的各阶相关矩不变。
这一推导以源频率关系 A 完整、V 在有理数上独立为条件；本轮整数 q 的圆分构造满足此条件。
它不是说有限画面逐点相同、仅有刚体平移或所有局部轮廓不变，而是不能把局部重排自动当成新统计组织。
计算二/三/五阶矩作为此结论的实例核对，不用这三个数代替所有形态。

关系相位的确能改变统计组织：q5 的归一化五阶矩随 chi 从 0 到 pi，由 0.75895 到 -0.75895；
q12 第一关系相位对应的归一化三阶矩由 0.57735 到 0。源、Wang 同坐标图保留了从嵌套高值区到更多低层局部单元的可见转变，
但高阶矩不是审美指标，也不把改变正负区域比例自动命名为一个新风格。

此外发现控制语义的边界：源中相位增量 Wt 严格等于平移；在当前非线性相位库中通常不等于把整张图刚性平移。
局部位移 `(0.03,0.02)` 的实际源误差小于 1.1e-14，Wang 内容与真实平移之间 RMS 为 q5 0.02784、q8 0.02388、q12 0.01247。
原因是空间梯度已从 W 改为 `B+grad(psi)`。纯平移/旋转/缩放应区分为成图的坐标变换，不能用源相位更新冒充整个铺砌的刚体编辑。
本轮不修改铺砌坐标变换，也不把这个差异隐藏在参数命名中。

## 第二轮：单场方向权重平衡（完成）

第一轮确认单向偏置与不同相位的作用后，检验模型已有的 `crossMix`：固定 beta=2，相位全零，
取 m=0、0.25、0.5、1，使用同一归一化幅度公式 `a=(1-m)a_x+m a_y`，而不是两个场相乘。
这一操作只是同一个 QRP 场内部的方向贡献平衡，仍使用同一已冻结相位库；两个强方向的乘积不进入本轮。
此路径的 m=0 就是第一轮 beta=2，完整库不重复烘焙；m=0.5 和 m=1 生成完整复用证据。
重点观察有无方向相消以外的组织变化，并记录 q8/12 的两端是否只是旋转等价，不将其重复计作风格。
源中权重平衡引入的变化与 Wang 引入的扭曲仍分别测量；以下第二轮结果已足以完成本阶段判断。

### 实际结论

在 q5/8/12 都观察到：从 m=0 到 m=0.5，单向拉长的区域逐渐出现两个方向共同作用的局部单元；继续到 m=1 则偏向另一方向。
这仍是原来同一组波的幅度变化。由于余弦和对幅度线性，也可写成 `(1-m)F_x+m F_y`，
但没有乘积带来的和差频率，不是先前被称为第三种风格的乘积实验。源与 Wang 场的这条线性恒等式连同一阶梯度，最大核验误差为 1.43×10⁻¹⁴。

整数 q 可被 4 整除时，90 度旋转置换方向星并交换两组权重；因此零相位源在 m=0 和 m=1 时旋转等价。
q8/12 的逐点核验最大误差小于 4.45×10⁻¹⁵。q5 的方向星不满足这一置换；其两端不能简单当成同一纹样旋转。
这按方向星的对称条件判断，不是给不同 Q 指派不同生成算法。

m=0.5 并不等于 beta=0：例如 q8 前者更强调两条正交轴，后者有效方向等权，虽然两者的二阶方向集中度都接近零。
因此一个方向统计量不足以判定纹样同质或风格数量。中间态的行列感也可能不符合用户审美，不将其包装成新的“成功风格”。

## 参数语义与保持范围

| 控制 | 对原 QRP 的实际作用 | 当前 Wang 中能说什么 |
| --- | --- | --- |
| 位置、整体旋转、频率缩放 | 固定波数/权重/相位定义下属于坐标变换；不是新的形态自由度 | 成图坐标变换与重建内容库是不同操作；仅给源相位加 Wt 不保持严格刚体平移语义 |
| beta：方向偏置 | 改变波的相对幅度；从较均衡组织逐步走向主方向拉长，而非只旋转 | 本轮三个 Q 的方向集中趋势保留，局部曲率、位置和连通仍可能不同 |
| m：方向权重平衡 | 在同一波谱内分配两组方向贡献；中间值不等于强度归零 | 源和候选对 m 都严格仿射，实际相位图不变；端点旋转等价不能重复算风格 |
| 关系保持的非平移相位 | 改变有限窗口中的排列和局部细节；在上述条件下不改变无限域平移平均的各阶相关矩 | 非零响应仍存在；有限库的统计和原无限源不同，不宣称该统计不变性也被全部继承 |
| 关系相位 chi | 改变整数频率关系的相位常数，可改变局部峰谷及统计组织 | 所有类型传递相同增量，关系常数严格对应；q5/12 的本轮趋势可见，局部结构不是逐点无损 |

原源的旋转/尺度语义来自 `F_{kappa,theta}(x)=F_{1,0}(kappa R_theta^T x)`（同一幅度和相位）。
它不表示当前固定相位库支持任意频率或旋转的无重建编辑：改变波矢会碰到载波/整数分支边界。
本轮没有实现成图交互，也没有修复全部控制的几何等变性；只是明确不把这些变化混称为风格自由度。

本轮路径在有限 beta、固定有效谱与秩下是平滑的：相位增量线性传递，幅度按 C++ 的平滑归一化公式改变，
Wang 相位图和整数分支不重新选择。阈值着色和临界高度仍可出现轮廓分裂/合并，场平滑不等于图像拓扑不变。
本研究坐标不覆盖相消点或跨 Q 改变模态数量的边界；q8 没有这里定义的关系相位，不代表 q8 不能产生其他有用的设计。
相位分解采用局部实坐标，不声称在模 2pi 的相位环面上得到全局唯一参数，也不把三个有限代表的视觉结论推广到所有 Q。

### 同条件的保持程度

所有响应比较均在同一 16 类型、96×96 采样上进行。定义 `Delta F=F_p-F_0`、`Delta G=G_p-G_0`，
报告增益 `||Delta G||/||Delta F||`、夹角余弦和相对响应误差 `||Delta G-Delta F||/||Delta F||`。
这是逐点控制响应，不是美观分数或“形态保留百分比”。两轮合计：

- 增益 0.9942～1.0048：没有把源的变化整体压没。
- 夹角余弦 0.8014～0.9675，相对响应误差 0.2551～0.6305：保留了相当一部分空间响应，但远非逐点等价；q5 的偏差更明显。
- beta 从 0 到 2 时，方向集中度的源/候选终点依次为 q5 `0.9204/0.9084`、q8 `0.9641/0.9556`、q12 `0.8868/0.8809`。
- q5 的等权源集中度约 0.0011，候选约 0.0518：Wang 自身带来的弱方向性仍存在，不能只展示终点的接近。
- q12 第一关系相位由 0 到 pi，有限区域归一化三阶矩的源/候选从 `0.5478/0.5817` 变到 `-0.0123/0.0068`。
  这是明确趋势证据；有限区域的数值本来就不必与无限源平均完全相同。

## 交付、验证与阶段判断

第一轮 27 个保存状态，第二轮 12 个；其中第二轮三个起点与第一轮 beta=2 重合，不把它们算成新的独立状态或风格。
全部状态保存真实 C++ 源、定义完整 16 类型内容的相位系数、同坐标彩色/中性图和实际接边检查。
17 个代表状态另保存完整 PNG 内容库；每库 16 张不同图像，共 1,836 个重铺实例块逐像素核验通过。
这些统计是证据规模，不是风格数量。

- 39 个状态合计 3,744 对合法有序边邻接，值及完整一阶梯度的最大采样误差小于 3.65×10⁻¹³；数学相容性仍来自共同相位与共享 jet。
- 实际 C++ oracle 最大误差小于 2.08×10⁻¹³，解析梯度有限差分误差小于 7.10×10⁻⁹。
- 所有保存模型的导数自由度与本轮基线逐位相同，值自由度增量与指定相位一致；每个 T5 从保存系数重绘，与展示图逐像素相同。
- 每套代表库的实际局部替换都改变内容，至少 102,410 个像素；替换区域外改变 0。
- 通过独立的无混叠环面积分核对组合展开的源二/三/五阶矩，最大差小于 8.22×10⁻¹⁵。
- 自审核对了新增文件及原调用者、保存清单、实际图片；Python 编译与差异/链接检查通过。本轮没有改 C++ 或重新求解相位，因此不重复无关的全量构建。

在第 2 轮结束本阶段：已建立方向幅度、排列相位和关系相位的作用与边界，不为用满三轮继续增加样例。
当前证据支持把幅度/关系相位视为值得继续评看的控制，把关系保持相位视为局部组织变化工具；不把它们自动对应到商业风格标签。
没有证明已经覆盖广泛审美风格、全部参数区域或所有 Q 的视觉优越；也没有据几个样例判定当前模型绝无其他表达潜力。
若下一阶段追求更大的风格跨度，应先指定想增加的结构特征，再判断是否需要扩展 QRP，而不是继续任意选相位、改配色或添加组合算子。

本轮仅增加一个参数研究编排入口和本文，更新 README；共享的源、Wang、相位与显示实现未复制或改写。
工程技能用于分清源/坐标/显示及一般结论，简化技能让两轮共用编排、复用基线与已有烘焙，审阅由实现者自审完成，不冒称独立评审。
既有未提交改动与双通道历史对照保留；没有提交、推送或增加 UI。
