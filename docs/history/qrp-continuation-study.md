## 2. 返回块的输入/输出状态

保持既有有限波 J、内部方向 b、ℓ=4π/3、β=π/3、根 (3,3)、c=0.38 不变。
沿整数瓦片格每隔三块划分一个 3×3 返回块；其 4×4 节点高度为：

```text
0 0 0 0
0 a a 0
0 a a 0
0 0 0 0
```

其中 a∈{−1,0,+1}。每个非零块仍包含一个平台瓦片和八个过渡瓦片，
不是缩窄支撑或降低强度的新微调。其局部瓦片来自同一个十九类型闭合目录。
四条外边 H=0、∇H=0，所以不同返回块之间无需拼接两种非零内部相位边界。

这里返回的是**内部高度状态**，不是重置 QRP 源相位。令 p=(3i,3j)，
当前位置的源相位为 ξₚ=ℓW(p−p*)+W(.5,.5)ᵀ+φ，进入相邻返回块时仍按

\[
\xi_{p+3e_x}=\xi_p+3\ell W e_x,\qquad
\xi_{p+3e_y}=\xi_p+3\ell W e_y
\]

传递。所有求值保留绝对位置与同一根，不能在每块重新绘制同一张“漂亮源图”。

定义 Gₐ(ξₚ) 为该返回块九个瓦片的完整 (u,v,τ) 路径通过旧包围条件。
同一机制在每个固定格点先检查 +1、再检查 −1，若均未证实则选 0；
QRP 参数决定 ξₚ、谱与方向，选择不读取图像，不依赖手工移动平台。
零选择的路径恒等，所以即使纯源某处 c 本来就是临界高度，也不在此处引入新的变化；
零选择不冒充非零分支或源场全局正则性证明。

在精确判定的数学前提下，每个非零返回块的形态对应流都在边界为零，
可以与相邻块及零区域拼成局部有限的 C¹ 场。任何既定有限前缀都可以补零继续，
扩展窗口时已选的格点与状态不变。这证明该**受限返回状态构造**不会因相邻选择而走入组合死路。
它不是任意十九类型边界状态的完成算法，不保证每步都有非零选择，也不自动给出无限域全部轮廓的拓扑结论。
实际允许检查仍采用普通浮点与裕量，不升级为定向舍入形式化认证。

## 3. Wang 作用的限制不能隐藏

该构造在细瓦片层确实遵守十九类型标签与累积状态，但每个 3×3 返回块的外边标签全为零。
因此在返回块尺度上，邻接匹配本身不区分 +/−/0；跨块选择只受各自源相位判定影响。
它可能退化为对局部调制补丁的组织，而非具有强跨区约束的 Wang 生成。

事实上设 η(t) 在 [0,1] 为 s(t)，在 [1,2] 为 1，在 [2,3] 为 1−s(t−2)，在外侧为 0，
则返回块的共享高度插值正是 aη(u)η(v)。整个构造也可写作

\[
H(z)=\sum_{p\in3\mathbb Z^2}a_p\,\eta(z_x-p_x)\eta(z_y-p_y).
\]

这是直接由节点双线性插值推出的同一函数，不是“视觉相似”的猜测。
所以哪怕本回合获得非零延拓，也不能将其包装为 Wang 的独特贡献；
后续必须面对这个等价表达及规则作用的局限。

## 6. 第 2 回合：带非零边界的条带状态链

### 6.1 三种真实边界剖面与相容转移

在高三块的条带中，取上一回合相同的 η(v)，边界状态 a∈{−1,0,+1} 的剖面为
ρₐ(v)=aη(v)，节点值 (0,a,a,0)。从左状态 a 到右状态 d 的一列（宽一块、高三块）使用

\[
H_{a,d}(u,v)=\big((1-s(u))a+s(u)d\big)\eta(v),\qquad 0\leq u\leq1,\ 0\leq v\leq3.
\]

要求 |d−a|≤1，得到七种几何转移：0→0、0→±1、±1→0、±1→±1（同号）。
每种都由原十九类型中的三个瓦片组成，不增加相位公式或另一个内容库。
边界上 H 与切向导数由状态决定，法向导数因 s'(0)=s'(1)=0 为零。
相邻列的出入状态相同就共享完整 H 的一阶 jet，再结合未重置的源相位传递，得到原 C¹ 相位/标量接边。
条带上下边仍为零状态，可与其他条带相接。

这次在列尺度上确实存在非零边匹配约束：上一列输出 +1，下一列不能独立改用 −1 或 0 作为输入。
对非退化 b 与既定 β，在剖面的平台部分，不同边界状态造成至少一个模态的实相位差非零，
且该模态相位差小于 2π，不是可忽略的整周相位；不能把不匹配的边当作同一内容边界。
Q6 的 b=0 仍退化，单独标识，不以“形式上非零的高度”冒充非零图案。

### 6.2 保留平台宽度的有限状态语法

为保留上一回合至少一列的非零平台，不允许 0→±1→0 这种更短脉冲。
调度状态用 0、+入、+稳、−入、−稳五个符号，实际高度仍只有 0、±1；
“入/稳”只记录是否已经完成一列平台，不是高度 ±2，也不是新的用户参数。

```text
0 → 0 / +入 / −入
+入 → +稳
+稳 → +稳 / 0
−入 → −稳
−稳 → −稳 / 0
```

因此上一回合的 0,+1,+1,0 和 0,−1,−1,0 均为合法路径，也允许保持更长的平台。
该最短停留语法是本实验用于固定变化尺度的附加约束，并非 Wang 铺砌或 QRP 的必然要求。

### 6.3 “当前允许”和“有可用后继”分开

令 Γᵢ(a,d) 表示第 i 列、给定源相位下的三个瓦片通过旧完整相位路径条件；
0→0 直接标为恒等允许，而不声称源场该处一定正则。
固定六列为一段，要求入口和出口状态为 0，但段内可以跨过原来第三列的零边界。
以 κ 将调度状态映射成真实高度，末端 B₆={0}，反向计算

\[
B_i=\{s:\ \exists t\in\operatorname{Next}(s),\quad
\Gamma_i(\kappa(s),\kappa(t)),\quad t\in B_{i+1}\}.
\]

只有出状态在 Bᵢ₊₁ 中的转移才被选择。这里的“可用”针对实际通过包围检查的图，
未决过渡不进入图；它不证明所有被排除的转移在数学上都不可行。
反向可达性和有限有向图的动态规划不是新的通用数学原理，本回合新增的是它们与当前 QRP 状态条件的连接。

在可达图上，选择作用列数量最多的路径：每个非 0→0 转移记一列，
同分按既定符号/保持顺序选择，不读图像或计算美感分数。
由递推可得此目标在本六列接受图中的最优值；不称为真正可行集合上的最优或审美最优。
旧两个三列返回块的组合也是该图内路径，所以新结果的非零作用域不少于旧结果，
这比仅报告“更多候选通过”更明确地排除了靠缩小整体作用域得到结果的解释。

每六列仍回零，条带上下也回零，因此任何已提交的六列段仍可以继续补零或接下一段，
扩大画幅不会重新求解旧段。它没有解决任意非零前沿的无限可继续性，也尚未去除固定分区返回要求。

两个具体见证说明失败类型不同：

- Q5、条带底行 0、起列 0：0→+入 的第一列通过，但下一列 +1→+1 未决，

这既支持加入后继条件，也限制结论：搜索预算导致的未决可能偏保守，

### 7.1 递归可行性的条件与证明

在已提交 k 列之后，实际调度状态为 σₖ。保留一条长度 L=6 的可行备用计划
Pₖ=(σₖ,p₁,…,p₆=0)，其每条转移都符合语法及对应绝对位置的 Γ。
初始 σ₀=0，六列全零就是备用计划。每次在这一窗口中调用原反向规划，
从真实 σₖ 出发，选出结束于零且作用列最多的可行计划 Qₖ=(σₖ,q₁,…,q₆=0)。
**只提交第一条转移**，而不是把整个窗口画进已完成内容。

下一步令 σₖ₊₁=q₁，新备用计划为

\[
P_{k+1}=(q_1,q_2,\ldots,q_6,0).
\]

它的前五条转移是已检查旧计划的后缀，最后是允许的恒等 0→0。
只要源参数与绝对位置的 Γ 不变，后缀仍有效；故下个窗口至少有这一候选。
有限图上的归纳证明了：从零或已有可行备用计划的入口出发，不会走入已接受图中的组合死路。
这不是任意非零入口都有出路的结论，也不要求未来六列始终沿旧备用计划执行。
程序先核验备用计划，再重选；新计划的窗口作用列数不小于备用计划。

出口会随窗口向右滚动，所以第六、十二列及可见右边界可以非零。
不同请求画幅使用相同绝对源状态、相同六步窗口与确定性同分顺序，
因此同一条带的前缀决定不依赖最终画幅；追加条带也不影响旧条带。
这是沿 +x 的条带生成，沿 +y 增加独立的三行条带，不是任意二维前沿完成器。

必须保留的限制：

- 备用计划保证能继续，但可能最后只能一直选零；未证明无限非零密度或有界零间隔。
- 每个窗口最大化作用列，不等于整个已提交长序列全局最优；没有一般性地证明其总覆盖不少于固定出口策略。
- 固定源参数是上述证明的前提；改变 Q、权重或相位会使旧 Γ 和备用计划失效，本回合不解决即时改参。
- 非零可见右边界可能让等值线穿过裁剪框；不能声称这个裁剪框内部的拓扑与纯源相同。
  另检查右侧六列备用尾部组成的零边界完成，但不将该尾部冒充已经提交的像素。
- 对精确正则条件的有限紧支撑形态推论，不直接推广为无限平面全局同胚：
  未给出无限域上的统一梯度下界或流完备性；实际仍是普通浮点包围，只限 c=0.38。

### 8.2 有限规则不等于完整状态只有五个符号

条带的完整生成状态至少包含 **源相位 ξ、当前调度符号 σ，以及可行备用计划 P**。
五种 σ 只描述 0/正入/正稳/负入/负稳；ξ 按绝对位置继续变化，Γ 也随之变化。
因此这是连续源状态驱动的有限规则系统，不是与位置无关、只凭五个符号工作的齐次有限自动机。
不能在固定语法图中找到一个非零环，就推出实际所有未来位置均允许沿该环生成。

接边依赖有限边标签、闭合积分得到的高度及一致的源相位传递。
十九类型的颜色相等不会单独决定一条可缓存复用的像素边；同类型在不同位置仍有不同 QRP 内容。
这里的 Wang 扩展复用的是相容生成规则，不满足旧固定内容库的强复用定义。
这符合用户后来允许的研究方向，但论文必须明说，不能与旧缓存实验混用。

在本构造中，Wang 的价值不需要被证明为“其他数学表示绝不可能实现”。
可以写成平滑调制并不否定方法；其可核验作用是：有限接口表示实际内容边界、约束相邻生成，
并与源状态相关的允许条件共同组织可延续的选择。
不过目前上下条带独立，五状态路径也可直接看作受约束的一维序列，
还不足以把二维 Wang 组织能力或审美优势写成已验证贡献。
JSON 中历史 `certified` 字样仅指通过现有包围检查的接受图，不表示定向舍入认证。

### 8.3 可保留的核心与论文表述

建议保留一条研究机制，而不是把三个实验当成三套主方法：

1. **内容表达**：以原 QRP 的有限波表达直接计算内容，叠加保持已认证整数关系的内部相位状态；
   不量化原载波或拟合图片，但空间变化后不能声称原全局频谱不变。
2. **局部相容**：闭合边增量与高度插值保证共享相位/场的一阶边迹；三种条带边剖面是受限实例。
3. **条件性选择**：完整相位路径的指定等值线检查给出源状态相关的接受关系；
   滚动备用返回计划保证在该接受图中的递归可行与已提交前缀不变。

可供后续论文讨论、但**尚未定稿或认定新颖性**的核心问题是：

> 如何将 QRP 的连续相位状态与有限局部铺砌规则结合，在不拟合预生成图像的情况下，
> 实现内容边界相容，并在声明的形态条件下增量延续？

可写成条件命题的是上述接口相容与备用路径归纳；实际包围通过和非零样例属于数值证据。
当前实现限于导出器的非相消基础有限波源，尚未覆盖文献中的全部 QRP 函数族或相消退化点。
归纳法、动态规划、平滑插值本身不是新的通用原理，当前也没有完成新颖性文献审查。
旧固定库的“任意位置复用相同瓦片图像”、全空间拟合最优性不能借给本方法。

### 8.4 未解决项不是措辞问题

| 缺口 | 当前实际情况 | 为什么不能省略 |
| --- | --- | --- |
| 所有合法 Q 的非零作用 | 机制无逐 Q 配方，但内部空间为零时退回纯源，Q6 是明确见证 | 能统一求值不等于每个 Q 都有同类非零 Wang 作用 |
| 持续且丰富的非零生成 | 可永远保有返回路径；只测到有限非零前缀，长平台可能占主导 | 不推出无限非零密度、风格数或布局熵 |
| 一般二维组织 | 沿条带向右规划，上下零剖面独立 | 非任意边界、孔洞或二维前沿算法 |
| 完整 QRP 形态与审美 | 只检验 c=0.38；颜色其他界面、曲率、厚度和视觉节奏未保护 | 新环块未必难看，守住一个轮廓也未必好看 |
| 交互工程价值 | 已免去图片拟合库，但源状态允许判定仍有成本，改参需重算 | “直接公式”不自动等于实时编辑；未接入操作台 |
| 连续参数语义 | 当前固定参数研究，未验证跨秩/谱分支的平滑选择 | 选择图变化可能引起离散跳变 |

本轮多数 QRP 设计参数有意固定，以隔离状态组织作用。
因此没有展示丰富风格不能反过来证明整个 QRP 函数族没有表达能力；
同样也不能从几组不同 Q 的图直接宣布已经解决风格多样性。
“内部空间为零仍必须有非零结果”若成为硬要求，就涉及是否放宽相位关系/源族或引入其他机制，
需要另行决定，不能由实现擅自改掉假设。

### 8.5 取舍与下一步建议

**本 Goal 完成；保留研究构件，不将当前条带规划器宣布为成熟最终算法，也不接入操作台。**
返回块与固定出口只保留为因果对照，滚动方案是当前可继续性见证；不以扩大画幅或覆盖率继续刷成绩。
旧最小锥保留其组合延拓含义和失败证据，不再当作形态保持延拓使用。

建议下一次任务回到用户的设计目标，先明确一个具体的**形态组织目标与 QRP 参数作用**，
再判断现有相容状态是否提供了需要的组织自由度，而不是先增加状态或更换评分权重。
例如区分“参数改变母题本身”与“规则改变母题间的排布/尺度节奏”，选择其中确实要解决的问题。
届时应以同源同尺度的纯 QRP、无组织约束调制、当前相容规则作必要对照；
判断的是可解释控制、跨区域组织及用户认可的效果，不是必须证明 Wang 是唯一表示。

这是下一阶段建议，不在本 Goal 内自动实施。
若仍无法说清当前规则带来的设计收益，应重新审查内容状态与组织自由度，而不是再进行小幅参数修补。
总项目的风格多样性、通用非零效果及最终论文主张仍待用户与后续研究确认。
