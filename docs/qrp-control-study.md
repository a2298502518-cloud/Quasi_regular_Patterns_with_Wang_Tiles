# 保留现有效果：从参数变化到可解释的造型控制

日期：2026-09-21。用户已认为当前 A 路线效果可以接受。
因此撤回“形状混合本身就是必须修复的缺陷”这一判断：圆环、圆角三角、花瓣和连接体
可以共同构成准规则纹样。是否需要更一致的单元，应由具体设计目标决定。

当前重点是保留这个有效起点，检查有目的的控制与可拓展性，不为改方法而推翻它。
方法论修改仍应针对明确的能力缺口。Wang 仍是内部铺砌机制；调试台暂停；每轮直接展示纹样。

## 1. 这一轮的问题与结论

复用已有 QRP 方向权重、载波旋转、共同相位与方向混合，不新增内容生成参数。
保持 q=5、频率 3.15、相位差 A=B=0、C<0 的深色区域、无收缩、无独立细节、同一双色。
除明确的线描对照外，所有图使用相同面状填充。

观察结果：

- 增强方向权重 η，出现从环瓣、纵向串联到贯通波带的清楚变化。
- 共同相位 φ 从 0° 改到 60° 时，这个趋势仍保留，但局部轮廓和连接会改变。
  这支持把 φ 暂时解释为同族变体，而不是“更规整”“更多花瓣”等尚未证实的控制。
- 载波旋转 α=30° 时，纵向结构转向斜向；它不是最终图片的严格刚性旋转，Wang 网格不旋转。
- 在 q=5、η=1.5 下，t 从 0 增至 0.5 主要削弱单向性，回到更均衡的环瓣组合。
  不宜把它宣传为独立的“交叉风格”。它仍改变场，不是数学上完全无效或冗余的参数。
- 线描只改变表达，不能单独计作新增结构类型。

这轮支持的是几个控制维度的作用，不是已经证明多种商业风格或任意组合都稳定。

## 3. 方向性的数值检查

在输出域 [0,20)²、每单位 64×64 的固定采样点上累加解析梯度的二阶矩：

```text
Jxx = sum(Cx²), Jxy = sum(Cx Cy), Jyy = sum(Cy²)
R = hypot(Jxx-Jyy, 2 Jxy) / (Jxx+Jyy)
```

R 是两个特征值的差除以和，接近 0 表示总体梯度方向较均衡，接近 1 表示高度集中。
它不是连接数、规则性或美感指标，也不是整个有限图案的非周期性证明。
不使用外扩几何区或颜色梯度计算这个指标。

| η | φ=0° 的 R | φ=60° 的 R |
| ---: | ---: | ---: |
| 0 | 0.016884 | 0.007243 |
| 0.5 | 0.436080 | 0.449339 |
| 1.0 | 0.707447 | 0.712688 |
| 1.5 | 0.845356 | 0.847497 |

两组共同相位下的方向性趋势一致，但只有这两组比较，不能据此声称所有相位都等效。
η=1 的主梯度法向所对应的纹样切向轴约为 90.00°；载波转 30° 后约为 120.06°。
坐标采用 x 向右、y 向上，轴向按模 180° 解释；R 很小时该轴不稳定，不应拿来标注主方向。

η=1.5 的混合 t=0、0.25、0.5 时，R 约为 0.845、0.61、0.042，支持本轮图中
“削弱单向性”的解释，不能据此推导任意参数下 t 都只承担这一种作用。

## 4. 贯通波带的一个充分条件

这里区分参数现象与可解释的控制规则。结论只针对本轮 q=5、t=0、κ=3.15、A=B=0、
level=0、不收缩的解析场；不是所有提取轮廓的拓扑认证。

第 0 个方向的幅度为

```text
a0 = 1 / sum_r exp[η(cos(4πr/5)-1)]
```

把场写为 `C=a0 cos(κ d0·x + φ + 0.11 U(x)) + E(x)`。
由内部 Wang 场的范围证书 `|U|≤1`，且其余正幅度和为 `1-a0`，有 `|E|≤1-a0`。
在未调制主波的极值相位线 `κ d0·x+φ=nπ` 上，只要

```text
a0 cos(0.11) > 1-a0
```

则整条线上的 C 符号严格按 n 的奇偶交替。负值相位线提供穿过窗口的深色通道，
相邻正值相位线将它们分隔。因此这里的贯通趋势不只是挑图得到的偶然现象。
这个条件对本轮任意共同相位 φ 都成立；变化的是相位线的位置。

η=1.5 时，a0≈0.542885，符号余量约为 0.082489，满足上述条件。
对应 η 的充分门槛数值约为 1.312201。该条件只是充分条件，不是必要条件或精确分岔位置。
它不保证带的两侧没有分叉、孔洞或局部粗细变化，也不保证离散轮廓已经获得严格拓扑认证。
频率、层级、收缩、混合或内部耦合改变时，不能直接复用这个数值门槛。

这是把设计意图与参数条件相联系的起点，不需要先把现有环瓣型当成错误。

## 5. 实现与验证

- 核心 QRP 公式本轮未改；`DirectQrpDesign` 将已有权重与混合传入同一个权威场对象。
- 在原几何采样遍历中统计解析梯度，不另复制 QRP 或 Wang 实现。
- 新增一个研究命令与两张排版，不改 UI，不新增测试目标或依赖。
- Release 构建及六个 CTest 目标通过。
- 36 张案例 PNG 解码、尺寸和非空检查通过。
- N01 与上一轮 M01、N05 与 M06 在三种视图上分别字节一致，保留旧参考。
- N12 的粗灰度与 N01 一致，确认线描没有悄悄改场。
- 独立使用 8 位粗灰度差分近似核对方向统计：R 最大差约 0.003203；
  对 R>0.1 的样例，轴向最大差约 0.02048°。这只是统计实现的数量级核对，
  不是把量化图像当作解析梯度的权威来源。

尚未验证：用户能否不看公式就通过这些控制复现给定设计意图；超出本轮范围的组合；
丰富风格的覆盖能力；印花生产条件。未重新执行全部历史七图或本轮 UI 测试。

## 6. 下一步

优先以环瓣、方向性串联、贯通波带作为三种结构意图的工作描述，而非认证的商业风格分类。
旋转负责走向，φ 负责观察到的同族变体。若需要超出这个结构跨度的目标，
再定位谱结构、相位组织或几何表达的具体能力缺口，并据此修改方法。
不要重新把“形状混合”本身当成缺陷，也不要仅靠换色或描边宣称新增结构风格。
