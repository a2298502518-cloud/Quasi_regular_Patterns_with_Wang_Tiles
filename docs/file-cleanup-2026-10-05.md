## 判断依据

对 tools 下全部 Python 做静态导入检查，并搜索 C++、测试、VSCode、CMake 和保留入口中的字符串调用；当前入口的传递依赖中不包含这 16 个脚本。
它们在删除区保留原内容，不再作为同时维护的生成入口。

仍保留母题/图册类前序模块以及 common_coordinate_study.py：当前母题连接/选区、整数格、显示和文献探针依然使用其中的共享构件。
没有仅凭文件名、年代或“旧路线”标签删除仍有调用关系的代码。

保留当前 relational、新参数、跨 Q 图库、关键机制对照及全部高清交付。
`build/`、VSCode 配置、C++/原生窗口与现有 Python 环境保留；只有 `build-cleanup/`、`build-legacy/` 等已无调用的目录隔离。
