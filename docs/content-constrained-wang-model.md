# QRP–Wang 数学模型

本文档是当前 `20 × 20` 实验的数学定义。实现以单位正方形 Wang 瓦片为基本域，
用边标签构造全局 `C¹` 连续权重场，再以该权重场调制 QRP 的方向相位。

## 1. 研究目标与适用范围

当前模型满足以下约束：

1. 所有瓦片使用同一套解析公式；
2. 离散 Wang 网格只决定合法边标签的空间排列；
3. 相同边标签在共享物理边上给出相同的场值和完整一阶导数；
4. QRP 共振方向负责纹理内容，Wang 场负责连续地调制方向相位；
5. 参数组比较使用相同网格、层级残差、色带和分辨率；
6. 不使用预生成图片瓦片、逐瓦片随机量、随机旋转、硬截断或逐图归一化。

本文只讨论轴对齐、单位大小、不旋转且不镜像的正方形瓦片。有限窗口内的复杂图样不能
作为无限铺砌严格非周期的证明。

## 2. 坐标与边标签

全局坐标记为

\[
x=(x_1,x_2)\in[0,N]^2.
\]

位于整数格点 `g=(i,j)` 的瓦片使用局部坐标

\[
q=(u,v)=x-g\in[0,1]^2.
\]

瓦片的有序边标签签名为

\[
\tau=(c_S,c_N,c_W,c_E),\qquad c_d\in\{0,\ldots,K-1\}.
\]

南、北边的参数均从左向右，西、东边的参数均从下向上。合法 Wang 邻接要求相邻瓦片在
同一物理边上使用相同标签。网格随机种子只用于生成可复现的合法标签排列，不进入连续场
的数值公式。

## 3. Canonical QRP 参考场

对整数方向数 `q >= 5`，令

\[
\theta_r=\frac{2\pi r}{q},\qquad
e_r=(\cos\theta_r,\sin\theta_r)^T,
\qquad r=0,\ldots,q-1.
\]

Canonical QRP 参考和为

\[
H_{q,\kappa}(x)=\sum_{r=0}^{q-1}
\cos\!\left(\kappa e_r^Tx\right).
\]

其归一化形式

\[
Q_{q,\kappa}(x)=\frac{1}{q}H_{q,\kappa}(x)
\]

满足 `|Q| <= 1`。参考和的解析梯度为

\[
\nabla H_{q,\kappa}(x)=
-\kappa\sum_{r=0}^{q-1}
\sin\!\left(\kappa e_r^Tx\right)e_r.
\]

`CanonicalQrpField` 实现未归一化的 `H`，测试参数化场的零相位退化时再除以
`q`。该参考实现用于检查已知值、旋转对称性和解析梯度。一般 canonical QRP 不应被
解释为单位环面周期函数。

## 4. Wang 标签的全局 C¹ 权重场

### 4.1 标签边界数据

标签 `c` 对应角度

\[
\vartheta_c=\frac{2\pi c}{K}.
\]

定义端点平坦的气泡函数

\[
b(r)=16r^2(1-r)^2,\qquad r\in[0,1].
\]

标签共享的边值与固定全局坐标方向导数为

\[
a_c(r)=w_*+\rho\cos\vartheta_c\,b(r),
\qquad
d_c(r)=\sigma\sin\vartheta_c\,b(r).
\]

`d_c` 表示固定坐标正方向的横向导数，不是随瓦片改变符号的外法向导数。由于

\[
b(0)=b(1)=b'(0)=b'(1)=0,
\]

所有标签在瓦片角点都给出

\[
W=w_*,\qquad \nabla W=0.
\]

### 4.2 三次 Hermite 延拓

三次 Hermite 基函数为

\[
\begin{aligned}
h_{00}(r)&=2r^3-3r^2+1,
&h_{10}(r)&=r^3-2r^2+r,\\
h_{01}(r)&=-2r^3+3r^2,
&h_{11}(r)&=r^3-r^2.
\end{aligned}
\]

记 `\widehat a_c(r)=a_c(r)-w_*`。南北边和东西边的延拓分别为

\[
\begin{aligned}
P_y(u,v)={}&
h_{00}(v)\widehat a_{c_S}(u)
+h_{10}(v)d_{c_S}(u)\\
&+h_{01}(v)\widehat a_{c_N}(u)
+h_{11}(v)d_{c_N}(u),
\end{aligned}
\]

\[
\begin{aligned}
P_x(u,v)={}&
h_{00}(u)\widehat a_{c_W}(v)
+h_{10}(u)d_{c_W}(v)\\
&+h_{01}(u)\widehat a_{c_E}(v)
+h_{11}(u)d_{c_E}(v).
\end{aligned}
\]

局部权重为

\[
w_\tau(u,v)=w_*+P_x(u,v)+P_y(u,v).
\]

合法相邻瓦片在共享边上使用同一标签、同一边参数方向和同一横向导数约定，因此两侧的
`W`、切向导数和横向导数逐点一致。分片权重场由此在整个有限网格上组成全局
`C¹` 场。

### 4.3 范围证书

在 `r in [0,1]` 上，

\[
h_{00},h_{01}\ge0,\qquad h_{00}+h_{01}=1,
\qquad |h_{10}|+|h_{11}|\le\frac14.
\]

于是

\[
|w_\tau-w_*|\le
R_W=2|\rho|+\frac{|\sigma|}{2}.
\]

只要

\[
R_W\le\min(w_*,1-w_*),
\]

全部 `K^4` 个标签签名都满足 `0 <= W <= 1`，不需要会破坏一阶光滑性的运行时
`clamp`。

## 5. 二阶角谐波参数化 QRP

对每个方向定义

\[
c_r=\cos(2\theta_r),\qquad s_r=\sin(2\theta_r).
\]

将中心化 Wang 场写为

\[
U(x)=\frac{W(x)-w_*}{R_W},\qquad |U(x)|\le1.
\]

若 `R_W=0`，规定 `U=0`。两个方向相位系数为

\[
A(x)=A_0+\lambda_AU(x),\qquad
B(x)=B_0+\lambda_BU(x).
\]

参数化粗尺度场为

\[
C(x)=\frac1q\sum_{r=0}^{q-1}
\cos\!\left[
\kappa e_r^Tx+A(x)c_r+B(x)s_r
\right].
\]

`(A_0,B_0)` 改变同一完整共振星内部的相对相位，
`(\lambda_A,\lambda_B)` 控制 Wang 标签对这些相位的局部调制。所有瓦片仍共享
同一个公式，不存在逐标签或逐签名参数表。

记

\[
\chi_r=\kappa e_r^Tx+A(x)c_r+B(x)s_r.
\]

解析梯度为

\[
\nabla C(x)=
-\frac1q\sum_{r=0}^{q-1}
\sin\chi_r
\left[
\kappa e_r+c_r\nabla A+s_r\nabla B
\right],
\]

其中

\[
\nabla A=\frac{\lambda_A}{R_W}\nabla W,
\qquad
\nabla B=\frac{\lambda_B}{R_W}\nabla W.
\]

由于 `W` 是全局 `C¹` 场，`A`、`B` 和 `C` 也为全局 `C¹`。余弦平均直接
给出 `|C| <= 1`。当 `A_0=B_0=lambda_A=lambda_B=0` 时，该场退化为归一化
canonical QRP。

## 6. 多尺度层级

粗、中、细三个场在同一全局坐标中求值。最终标量场定义为

\[
F=C+\beta_m(1-C^2)D_m
+\beta_f(1-C^2)^2D_f.
\]

门控项使中、细尺度主要进入粗场的过渡区域。它们只增加统一细节，不负责制造参数组之间
的粗骨架差异。若

\[
|C|\le1,\qquad |D_m|,|D_f|\le\sqrt2,
\qquad 2\sqrt2(\beta_m+\beta_f)\le1,
\]

则 `F` 保持在 `[-1,1]` 内。

## 7. 固定实验配置

| 项目 | 当前值 |
| --- | --- |
| 网格 | `20 × 20`，共 400 个瓦片 |
| 分辨率 | 每瓦片 `80 × 80` 像素，总图 `1600 × 1600` |
| 标签数 | `K=5` |
| 网格种子 | `0x4d595df4d0f33173` |
| 权重参数 | `w*=0.5, rho=0.10, sigma=0.40, R_W=0.40` |
| 粗尺度 | `q=7, kappa=3.15, (lambda_A,lambda_B)=(1.15,-0.80)` |
| 中尺度 | `q=9, kappa=7.4, (A0,B0)=(0.55,-0.30)` |
| 细尺度 | `q=11, kappa=12.8, (A0,B0)=(-0.25,0.45)` |
| 层级强度 | `(beta_m,beta_f)=(0.19,0.055)` |
| 色带 | `MidnightGold` |

四组粗尺度全局相位为：

| 组别 | `(A0,B0)` |
| --- | --- |
| P0 | `(0.00,0.00)` |
| P1 | `(1.65,0.00)` |
| P2 | `(3.00,0.85)` |
| P3 | `(2.10,-2.45)` |

P0 只把全局相位设为零，仍保留 Wang 调制。独立的 uniform 对照固定 `W=w*=0.5`，
因而 `U=0`；它与真实 Wang 结果使用相同的 P2 参数、层级、网格范围、分辨率和色带。

## 8. 当前证据与结论边界

五组单元测试分别验证 Wang 网格、canonical QRP、C¹ 权重场、层级公式和参数化 QRP。
当前实验另外输出四组粗场、四组分层结果以及 uniform–Wang 因果对照。

粗场成对差异为：

| 参数对 | RMSD | 符号分歧率 |
| --- | ---: | ---: |
| P0–P1 | 0.291436 | 36.69% |
| P0–P2 | 0.436893 | 59.82% |
| P0–P3 | 0.438151 | 60.49% |
| P1–P2 | 0.276631 | 34.20% |
| P1–P3 | 0.389104 | 51.56% |
| P2–P3 | 0.447371 | 61.16% |

这些指标证明固定实验窗口中的参数组存在显著数值差异，但不证明严格拓扑变化或无限铺砌
的非周期性。当前模型也尚未实现 GPU 等价路径、实时 UI、交互编辑或通用项目导出。
