# 验证方案

## 1. 验证原则

项目同时验证数学正确性、渲染一致性、交互稳定性和视觉质量。编译成功或单张截图都
不能单独作为完成依据。

测试使用固定种子和可序列化参数。失败信息必须指出参数、瓦片坐标、采样位置、残差
或颜色误差，避免只能人工重现。

## 2. 数学单元测试

### 边函数

- `f(0) == 0` 与 `f(1) == 1`。
- 合法参数在全区间严格递增。
- 导数解析式与有限差分一致。
- 临界和非法参数被拒绝。

### Coons 映射

- 四条边分别精确还原对应边函数。
- 恒等边函数产生恒等映射。
- Jacobian 解析式与有限差分一致。
- 所有边颜色组合满足规定的 Jacobian 安全裕量。
- 极端合法参数和接近非法边界的参数不会产生折叠。

### 逆映射

- 随机和结构化采样点满足 `Phi(Phi^-1(p))` 的误差限。
- 覆盖四条边、四个角、中心和 Jacobian 最小区域。
- 记录迭代次数分布、最大残差和失败数。
- CPU 失败时返回明确状态，不输出未初始化或静默夹紧的结果。

## 3. Wang 铺砌测试

- 每对水平邻居满足 `left.east == right.west`。
- 每对垂直邻居满足 `bottom.north == top.south`。
- 相同种子生成相同网格和单元种子。
- 不同种子能够产生不同但合法的网格。
- 1 x 1、1 x N、N x 1 和普通二维网格均有效。

### 3.1 经典图像 Wang tile 对照

独立目标 `qrp_atlas_tests` 验证有限图像 tile 的经典路径：

- 独立枚举的 8 个签名均满足偶校验规则；
- 每个已约束的南/西边对有且仅有 2 个合法候选；
- 扫描线生成结果对 seed 可复现，并满足全部水平和垂直邻接；
- `1 x 1`、单行、单列和普通矩形网格方向正确；
- 缺失或重复签名、越界标签和尺寸不一致的 atlas 会明确失败；
- 匹配边的 RGB 像素完全相等，成图接缝最大通道误差为 0；
- 改变全局选片 seed 只改变合法 tile 的选择，不在 tile 内注入随机内容。

诊断程序 `qrp_classic_wang_reference` 输出 8 张 tile、固定 10 x 10 铺砌和 JSON 指标。
它是相关方法基线，不调用主论文的 Coons warp、QRP/环面生成器或表现层噪声。详见
[经典图像 Wang Tile 对照基线](./classic-wang-reference.md)。

### 3.2 四样本纹理 atlas 构造

独立目标 `qrp_quilting_tests` 验证从四张受控样本构造经典纹理 tile 的路径：

- `3 x 4` 全部二值代价矩阵上的最小误差 DP 结果与暴力枚举 oracle 一致；
- 等价路径的直行、中线和下标 tie-break 可复现，非法尺寸与代价溢出明确失败；
- 旋转裁剪使用唯一坐标定义，并对多组奇偶尺寸验证范围、边界对角线和方向；
- builder 的 S8 入口固定生成 8 个唯一偶校验签名和 32 条独立 cut；S16 入口覆盖全部
  16 个二值四边签名并生成 64 条独立 cut；
- 非对称测试样本下，S16 的 16 个签名产生 16 张不同图像，coverage 为 `16/16`；
- 32 个东西向和 32 个南北向有序兼容边对全部比较，像素通道误差严格为 0；
- S16 的 128 个东西向和 128 个南北向有序兼容边对同样逐像素完全一致；
- 使用非对称坐标编码样本检出边方向、转置和反向错误；
- 修改一张源样本不会改变 tile 签名、铺砌布局或不引用该标签的 tile；
- 多个铺砌 seed 只改变合法选片，不改变 atlas 内容，最终栅格接缝误差仍为 0；
- 记录权威边界覆盖的像素数、mean/max 通道修正以及边界向内跳变，不能只用覆盖后的
  零接缝证明 quilting 正确；
- quilt 与 cut 路径调试图默认不构造，只在显式选项开启时保留。

诊断程序 `qrp_wang_texture_atlas` 输出四张源样本、8-tile atlas、cut 路径、
固定 10 x 10 合法铺砌和 JSON 指标。该程序不调用主论文的 Coons warp，不在 tile 内
加入随机噪声，也不把诊断纹理注册成正式预设。详见
[Wang 纹理 Atlas 构造基线](./wang-texture-atlas-construction.md)。

## 4. 生成器测试

对每个正式生成器验证：

- `G(u, 0) == G(u, 1)`。
- `G(0, v) == G(1, v)`。
- 四角值一致。
- 周期噪声的所有 octave 均满足边界条件。
- 每瓦片扰动在边界精确为零。
- 使用高阶窗口时，边界附近导数满足对应设计目标。

## 5. 接缝测试

接缝两侧必须独立求逆和采样，不能复用同一侧结果后再比较。记录：

- 最大标量误差。
- 最大线性 RGB 误差。
- 量化到 8-bit 输出后的最大通道差。
- 误差位置、相邻瓦片编号及共享边颜色。

默认目标在实现误差分析后固化。初始设计目标为 CPU 标量边界误差不超过 `1e-10`，
GPU 标量误差不超过 `1e-5`，最终 8-bit 颜色接缝不超过 1 LSB，且连续大片接缝不得
依赖颜色量化掩盖。

阶段 B 固化的 CPU 门槛为：标量与线性 RGB 最大误差均不超过 `1e-12`，8-bit 最大
通道差必须为 0，且接缝采样中不允许逆映射失败。固定 10 x 10 基线的实际线性 RGB
最大误差低于 `2e-14`。

阶段 C 根据 OpenGL 单精度实现固化 GPU/CPU 对照门槛：参数坐标不超过 `1e-5`、标量
不超过 `2e-4`、线性 RGB 不超过 `1e-3`、Jacobian 行列式不超过 `2e-4`，GPU Newton
最终残差不超过 `2e-5`。最终 8-bit 图像最大通道差不超过 12、平均通道差不超过
`0.75`，并且不允许失败像素。最终图像的门槛较宽是为了捕获异常而不是代替各阶段
浮点比较；固定基线当前实际最大通道差为 1。

屏幕导数驱动的轮廓与浮雕属于最终显示合成：它们必须在 Wang 边界安全窗口内衰减，
且不得写入基础线性颜色验证附件。GPU/CPU 数值校验显式关闭这些效果；视觉矩阵则分别
检查开启材质后的低倍抗锯齿与高倍接缝。

必须提供接缝误差热图。热图使用独立调试合成，不能改变被测渲染路径。

## 6. CPU/GPU 一致性

使用固定参数和固定样本比较：

- `Phi`。
- Jacobian 与 `detJ`。
- `Phi^-1` 坐标。
- 生成器标量值。
- 线性颜色。

误差阈值按运算阶段分别设置，不只比较最终 8-bit 图片。Shader 编译和链接失败必须
作为测试失败报告，而不是退回空白或旧 Shader。

## 7. 视觉验证矩阵

每次影响渲染的改动至少覆盖：

| 维度 | 代表状态 |
| --- | --- |
| 形变 | 恒等、小幅、默认、接近合法上限 |
| 铺砌 | 单瓦片、2 x 2、10 x 10、窄长网格 |
| 生成器 | Fourier/QRP、周期噪声、混合 |
| 颜色 | 连续渐变、抗锯齿色带、材质效果 |
| 视口 | 宽屏、竖屏、窗口缩放、平移与高倍缩放 |
| 调试 | 边颜色、Jacobian、Newton 残差、接缝误差 |
| 输出 | 屏幕预览、标准 PNG、高分辨率 PNG |

对声称体现主论文 Wang/Coons 机制的候选，第一轮必须关闭全部可选内部扰动，并固定母纹、
调色、相机、分辨率与随机种子，至少比较：

1. 恒等边函数；
2. 非恒等边函数，但所有边标签都映射到同一个函数；
3. 相同边函数与真实随机 Wang 标签网格；
4. 第 3 项叠加实际标签覆盖图。

还应验证同一有序边签名的 tile 在相同局部采样位置得到相同结果，并验证改变未参与主
公式的 tile seed 不会改变图像。若恢复边界消失扰动，应从幅度零开始逐级增加，并保持
频率、相位和结构类型等其他因素固定。单格及多格位移相关、频谱峰和方向一致性可作为
视觉诊断，但不能单独证明数学意义上的非周期性，也不能替代上述因果对照。

### 7.1 论文核心因果审计

独立程序 `qrp_paper_core_audit` 固定使用

\[
I_T(x)=C\!\left(G\!\left(\Phi_T^{-1}(x)\right)\right),
\]

并将周期噪声、tile 内变化、tile domain warp、世界调制和世界 domain warp 全部置零。
它生成以下四张 `10 x 10` 对照图，而不把任何一张提前注册为正式预设：

| 文件 | 唯一变量 | 预期用途 |
| --- | --- | --- |
| `A_identity.png` | 五种边标签都映射到恒等函数 | 严格单 tile 周期基线 |
| `B_uniform_deformation.png` | 五种边标签都映射到同一个非恒等函数 | 排除“只有形变就能消除重复”的解释 |
| `C_wang_edge_deformation.png` | 五种真实 Wang 边标选择边函数 | 检查主论文机制本身产生的变化 |
| `D_wang_edge_labels.png` | 在 C 上叠加真实边标签 | 核对可见变化与边码位置的关系 |

运行方式：

```powershell
cmake --build build --config Release --target qrp_paper_core_audit
build/Release/qrp_paper_core_audit.exe output/paper-core-audit
```

三组主图使用同一个 Wang 网格，因此边标签和 tile seed 完全相同，只改变标签到边函数的
映射。固定 `rho = 0.08` 的首轮结果中，A、B 的水平和垂直单 tile 位移平均 RGB 差均为
`0`；C 分别为 `0.07955295` 与 `0.07935127`。100 个实例中有 93 个不同原始边标签
签名，625 种标签组合全部通过安全检查，采样最小 Jacobian 为 `0.5606011`，无逆映射
失败，8-bit 接缝差为 `0`。关闭可选扰动后，更换 tile seed 的生成器标量最大差严格
为 `0`；独立的 pipeline 测试还验证了恒等边函数控制下的端到端图像完全相同。

这些数据说明 C 相对单 tile 重复的变化来自 Wang 边标控制的 Coons 形变，而不是 tile
随机噪声；但首轮图像仍保留清晰的公共母纹拓扑和周期骨架。因此，这套结果是用于定位
论文模型表达力边界的审计证据，不是已经验收的新风格。完整数值写入生成目录中的
`metrics.json`。

人工视觉检查关注：

- 无黑块、NaN、未初始化纹理或意外背景洞。
- 没有可见接缝、单像素亮线或颜色跳变。
- 图案没有明显方格感和短周期重复。
- 轮廓无严重锯齿、摩尔纹和缩放闪烁。
- 调试覆盖层与真实实例边界一致。
- 屏幕预览与导出在相同参数下语义一致。

阶段 E 固化的导出检查使用相同 committed 场景、相机和材质，分别读取 PPM 预览与
1 倍率 PNG。两张 720 x 720 图像要求尺寸相同且逐通道差为 0；高分辨率样张还必须
包含 `sRGB` 与匹配的 `gAMA` chunk，其 JSON 必须能够由标准解析器读取并与图像尺寸、
相机和固定种子一致。

## 8. 视觉预设验收

首个里程碑至少包含三套风格差异明显的预设。每套预设必须：

- 保存完整参数和随机种子。
- 在 10 x 10 以上铺砌中没有明显接缝。
- 在缩略图和高分辨率下均有清楚的层次。
- 不依赖调试线隐藏边界问题。
- 能够重新加载并生成相同结果。

## 9. 性能与计算时机

记录但不在设计阶段虚构硬件无关的绝对帧率。性能验证至少包括：

- 稳定视图中的平均和高分位帧时间。
- 参数提交时的重建时间。
- Newton 平均/最大迭代次数和失败数。
- GPU 资源大小与缓存命中情况。
- 窗口重绘、悬停和平移时没有无关的模型重建。

性能优化不得引入第二套不可验证的几何或采样定义。

## 10. 每阶段交付检查

每个阶段结束前执行：

1. 针对性测试与必要的完整构建。
2. `git diff --check`。
3. 检查未跟踪文件和生成产物。
4. 复查屏幕、调试视图和导出是否共享权威数据。
5. 记录未通过、未实现或仅在单一设备验证的项目。

在视觉结果尚未经过实际截图检查前，不把“效果良好”写成已完成事实。
