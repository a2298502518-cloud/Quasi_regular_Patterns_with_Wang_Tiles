# 主方法 v2 候选方案：Wang 条件内容与 Coons 形变

## 1. 文档状态

本文档描述下一轮 CPU 实验要检验的候选方法，不是当前权威数学规范，也不是已经写入
论文的结论。在消融实验通过以前，`docs/math-spec.md`、现有 CPU/GPU 渲染路径和正式
预设保持不变。

这次修改针对一个已经由实验暴露的问题：当前所有 tile 共享同一个周期母纹，Wang
边标签主要改变坐标形变。因此画面虽然不再严格满足单 tile 平移重复，公共母纹的周期
骨架仍然明显。继续加入 tile seed、随机相位或额外噪声只能掩盖问题，不能加强 Wang
标签与可见内容之间的因果关系。

## 2. 候选数据流

```text
程序化 QRP 源场 H
  -> 四个边标签样本
  -> minimum-error quilting
  -> 有限的 Wang 条件内容 A_sigma

Wang 网格 sigma(T)
  -> 边函数与 Coons 映射 Phi_sigma
  -> A_sigma(Phi_sigma^-1(x))
  -> 连续调色 C
```

这里的经典 Wang atlas 构造只负责建立“边标签选择内容”的机制；QRP 源场、Coons
重参数化及二者的组合才是需要由主论文定义和验证的对象。外部图像 quilting 方法应在
相关工作中明确归因，不能直接当作本项目的新贡献。

## 3. 候选公式

令 tile 的有序边签名为

\[
\sigma(T)=(s_T,n_T,w_T,e_T).
\]

对每个允许的签名，预先构造一个标量内容函数

\[
A_{\sigma}:[0,1]^2\rightarrow\mathbb R.
\]

相同边标签必须对应同一条有向边界信号。例如，东西相邻的两个 tile 满足

\[
e_L=w_R=c
\]

时，要求

\[
A_{\sigma_L}(1,t)=A_{\sigma_R}(0,t)=B_c^{EW}(t).
\]

南北边同理：

\[
A_{\sigma_B}(t,1)=A_{\sigma_T}(t,0)=B_c^{NS}(t).
\]

每个签名仍使用当前主方法的 Coons 映射 \(\Phi_\sigma\)。候选渲染式为

\[
I_T(x)=C\!\left(
 A_{\sigma(T)}\!\left(\Phi_{\sigma(T)}^{-1}(x)\right)
\right).
\]

与当前公式相比，关键变化不是增加随机项，而是把所有 tile 共用的 \(G\) 替换为由
Wang 边签名选择的 \(A_\sigma\)。因此 tile 的内部结构变化可以追溯到边标签，而不是
追溯到独立的 tile seed。

## 4. QRP 在新方法中的位置

内容 atlas 不应以当前绿色诊断纹理作为论文素材。首轮实验从一个较大的程序化 QRP
标量场中截取样本：

\[
H(q)=\sum_k a_k\cos\!\left(2\pi\langle \omega_k,q\rangle+\varphi_k\right).
\]

在旧方法中，生成器必须在单位环面上周期，才能让所有 tile 共用同一个 \(G\)。新方法
的边界兼容性改由 Wang 内容构造保证，因此源场 \(H\) 不必强制使用整数波矢，也不必先
压缩成单个周期单元。这使实验能够保留更自然的 quasi-regular 方向组合，同时仍由
有限 tile atlas 控制跨边内容。

首轮只使用一组固定的 \(a_k\)、\(\omega_k\) 和 \(\varphi_k\)，并记录样本搜索 seed。
不加入 octave 噪声、tile 内随机相位、世界坐标调制或边界消失扰动。

## 5. 连续性依据

以东西共享边为例。若相邻 tile 使用同一个边函数 \(f_c\)，则共享物理边上的坐标
\(y\) 在两侧都会被逆映射为

\[
t=f_c^{-1}(y).
\]

atlas 构造又保证两侧内容在相同参数 \(t\) 上都等于 \(B_c^{EW}(t)\)，因此

\[
A_{\sigma_L}(1,t)=A_{\sigma_R}(0,t).
\]

只要调色函数 \(C\) 连续，最终颜色就在共享边上满足离散与连续意义下的 \(C^0\)
一致。南北边证明相同。该结论只保证边界值连续，不自动保证导数、纹理过滤足迹或
四 tile 角点邻域连续；这些问题在候选方法通过首轮实验后再决定是否扩展。

## 6. 最小 CPU 消融实验

首轮只生成三组固定 `10 x 10` 图像：

| 组别 | 内容 | Coons 映射 | 目的 |
| --- | --- | --- | --- |
| A | 当前公共 torus-safe QRP | 开启 | 现有主方法基线 |
| B | Wang 条件 QRP 内容 \(A_\sigma\) | 恒等 | 单独观察内容 atlas 的作用 |
| C | Wang 条件 QRP 内容 \(A_\sigma\) | 开启 | 检验候选组合方法 |

三组共用 Wang 网格、边签名、调色、相机、分辨率和铺砌 seed。只检查四项：

1. 所有匹配边的 8-bit 最大通道差为 0；
2. 固定输入重复运行得到相同图像；
3. B 相对 A 的单 tile 平移重复显著下降；
4. C 的结构变化能够从边签名和 Coons 映射解释，且没有明显方格接缝。

如果 B 仍只表现为有限图片的机械重复，或 C 只增加扭曲而没有改善整体结构，则停止
集成，不修改主论文方法。只有这组三图给出清楚的正面证据后，才讨论 18-tile、角点
编码、GPU atlas、交互参数和正式视觉预设。

### 6.1 首轮 CPU 结果

独立程序 `qrp_wang_qrp_ablation` 已按上述三组对照实现。程序从固定的五方向 QRP
标量场中选择四个样本，经 minimum-error quilting 构造 8 张二边色 Wang tile；三组
图像不使用 tile seed、噪声、世界场或额外随机相位。复现命令为：

```powershell
cmake --build build --config Release --target qrp_wang_qrp_ablation
.\build\Release\qrp_wang_qrp_ablation.exe output\wang-qrp-ablation
```

2026-09-11 的固定 `10 x 10`、每 tile 96 像素结果如下。平移差是相隔一个 tile 后的
归一化平均 RGB 差，只作为重复性诊断，不作为非周期性的数学证明。

| 组别 | 水平单 tile 平移差 | 垂直单 tile 平移差 | 最大 8-bit 接缝差 |
| --- | ---: | ---: | ---: |
| A：公共 QRP + Coons | `0.0940181` | `0.0782012` | `0` |
| B：Wang 条件内容 + 恒等映射 | `0.156773` | `0.141694` | `0` |
| C：Wang 条件内容 + Coons | `0.183745` | `0.167028` | `0` |

三组固定输入均逐像素可复现，所有接缝求值均无逆映射失败。B/C 相对 A 的单 tile
平移差明显增加，说明 Wang 条件内容确实削弱了公共母纹的直接重复；但视觉上仍能辨认
出有限 8-tile 字典中的重复构件。该结果支持继续研究内容 atlas，但尚不足以把候选方法
并入正式预设或写成主论文结论。

## 7. 候选贡献的表述边界

现阶段可以讨论的研究问题是：由 QRP 场生成的 Wang 条件内容与边函数驱动的 Coons
重参数化结合后，能否在保持无缝的同时削弱公共周期骨架。是否具有足够的新颖性需要
继续核对相关工作，实验通过以前不能把它写成已经成立的论文贡献。
