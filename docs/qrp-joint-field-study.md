# 总场共享边界联合拟合：最小方法探针

日期：2026-09-23。状态：已运行并目视检查；保留为研究证据，不替换 C++ 相位闭合路径。

## 1. 本轮问题与边界

目的不是再添加风格预设，而是检验：**不要求每个模态独立整数闭合，改为约束最终标量场，是否能少改变 QRP 目标的形态，同时保留真正的 Wang 内容复用？**

本轮保留原来的 16 类端点编码类型、两种顶点状态和三种已有配方，隔离内容构造的改变。
没有实现内容驱动的类型筛选，也没有扩大瓦片库。保留全类型集合使合法布局仍可由任意二值顶点网格生成；不因删除类型而另引入铺砌可延拓问题。

这只是“内容—边界—类型联合设计”中的第一个受控实验，不是整条研究路线已经完成。

## 2. 先修正一个容易过度乐观的推断

### 2.1 从模态约束改成总场约束，并不自动保住原始 QRP

以下是本轮推导，不是文献原结论。设单通道基本 QRP 的全部波向量满足同一个模长 \(k\)，则

\[
F(x,y)=\sum_r a_r\cos(k_r\cdot(x,y)+\phi_r),\qquad
\Delta F+k^2F=0.
\]

若相邻两块瓦片内部仍**精确**使用这类有限平面波和，把它们写到同一个世界坐标系，二者之差 \(D\) 仍是解析的 Helmholtz 解。
若一条开边上同时满足 \(D=0\) 和 \(\partial_nD=0\)，则所有切向导数为零；由
\(\partial_n^2D=-\partial_t^2D-k^2D\) 逐次递推，所有法向阶数的导数也为零。
解析性于是使两侧成为同一个解的延拓。

因此，**对同频单通道基本场，精确 C¹ 总场匹配仍不能任意拼接独立相位的原始 QRP。**
再要求有限内容库在平面中重复使用：同一块内容若出现在相差 \(p\) 的两处，解析延拓会推出 \(F(x+p)=F(x)\)；对没有非零平移周期的原始场，这不可能成立。

适用范围必须保留：这不是针对二值像素、近似场、非解析变形场或所有多频组合的普遍禁止定理。
乘积通道包含不同频率，不能直接套用上面的单一 Helmholtz 方程。
当前逐模态闭合本来就引入空间变相位，已经越出了精确基本波和；它不因此“错误”，但其代价需要衡量。

### 2.2 固定标签也存在不可消除的目标冲突

对于同一个有向边标签，把所有待共享的目标边迹写成 \(g_1(s),\ldots,g_m(s)\)。任何共同边迹 \(b(s)\) 必须满足

\[
\max_i|b(s)-g_i(s)|\geq
\tfrac12\big(\max_i g_i(s)-\min_i g_i(s)\big).
\]

这是标量区间的半径下界，不依赖求解器。如果同一点的目标迹有正有负，一个共享值不可能同时保住它们的正负分区。
本轮数值只采样此下界；不是连续全边上最大值的严格数值认证。

因此应问“在哪里、以何种结构代价做了改变”，不能只问“是否有无缝解”。

## 3. 允许怎样的改变

### 3.1 输入目标不是另造一套 QRP 定义

从 C++ 相位实验的 manifest 读取每个模态的波向量、幅值、相位、顶点状态差，以及类型和布局。
局部坐标 \(u,v\in[0,1]\)，模型跨度 \(L=4\)，\(q=5,\kappa=3.15\)，所以波模长 \(k=\kappa L=12.6\)。

令 \(h(t)=t^2(3-2t)\)，\(S_t(u,v)\) 是四个二值角状态经 \(h\) 的张量插值。未闭合目标为

\[
G_t(u,v)=\sum_r a_r\cos(w_r\cdot(u,v)+\phi_r+d_rS_t(u,v)).
\]

这是**去掉整数闭合项、但保留现有顶点状态变相位的 QRP 派生目标**，不应称为精确原始 QRP 裁切。
旧闭合场则在每个相位中加
\(c_{r,x}h(u)+c_{r,y}h(v)\)，其中 \(c_r=2\pi\operatorname{round}(w_r/2\pi)-w_r\)。
乘积风格先组成最终目标 \(G_{t,1}G_{t,2}\)，再拟合最终场，而不是分别拟合两个通道后相乘。

图板另外显示没有 \(S_t\)、没有闭合项的全局原始 QRP 参考；其起点是 manifest 的第一源偏移。
它与局部目标不逐点对齐，不用它计算误差，更不把“更接近未闭合目标”偷换成“无损保留原始 QRP”。

### 3.2 联合表示与精确共享

每块单位瓦片划分为 \(n\times n\) 个方格，用分片双三次 Hermite 场表示 \(T_t\)。
每个节点存储 \((f,h_cf_u,h_cf_v,h_c^2f_{uv})\)，其中 \(h_c=1/n\)；缩放仅用于数值条件，不改变物理导数。

- 内部节点：归当前瓦片拥有。
- 竖边节点：按竖边标签共享；切向坐标自下向上。
- 横边节点：按横边标签共享；切向坐标自左向右。
- 角点：按二值角状态共享同一组自由度。

竖边的 \(f,f_v\) 确定共同三次值迹，\(f_u,f_{uv}\) 确定共同三次法向导数迹；横边同理。
因此相等标签给出**整段** C¹ 匹配，不只是几个采样点相等。梯度使用同一局部正轴，不使用两侧相反的外法线。

内部方格也共享节点，故瓦片内部为 C¹。该结论来自基函数构造；边采样只检查实现是否偏离构造。
这不保证零等值线不会断开、合并或产生小岛，也不表示所有风格都必须使用 C¹。

双三次 Hermite / BFS 是已有数值表示，不作为项目的新贡献。参考 Burman、Hansbo、Larson 的 [2020 年原论文 §有限元空间](https://link.springer.com/article/10.1186/s40323-020-00164-3)，这里只使用其张量 Hermite 空间定义，不复现薄板方程、切割单元或误差定理。

### 3.3 目标函数与求解

联合求解所有共享边界和内部自由度：

\[
\min_{\{T_t\}\in V_{\rm shared}}
\sum_{t=0}^{15}\int_{[0,1]^2}
\left[(T_t-G_t)^2+
\frac{\|\nabla T_t-\nabla G_t\|^2}{(\kappa L)^2}\right]du\,dv.
\]

固定梯度权重为 1，不搜索“最好看的”权重。每个方格使用 4×4 Gauss 积分。
双三次表示的 Gram 矩阵积分是精确的；含三角函数的右端积分仍是数值近似。
线性自由度无冗余、值项为正，离散目标有唯一解。使用 SciPy 稀疏线性求解；具体 API 见 [官方 spsolve 文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.sparse.linalg.spsolve.html)。

这是平均值/梯度误差最小化，**没有设置逐点变形上限，也没有证明形态保持**。实验必须另看符号分歧和实际图像。
固定网格与类型时，没有整数 round 选支；系数随平滑的目标参数连续变化，但零等值线仍可能在临界事件处改变拓扑。

相比历史“九块来源的预定分区权重混合”，这里边界和内部系数由同一个目标联合决定，不预先选择独立边条再加混合带。
它仍然可能产生边界层或模糊折衷，不能因为换了求解方法就认为老问题消失。

## 4. 验证协议

固定三类已有配方：rings、ribbons、product。16 类瓦片各生成一次，使用旧 manifest 两个合法布局的左下 4×4 子窗口。

必要对照：

1. **旧 C++ 一致性**：独立解释序列化模态所得的所有旧瓦片 PNG，逐像素与 C++ 缓存核对。
2. **无共享约束拟合**：同样的基函数、目标函数和积分；区分表示误差与铺砌代价。

4. **相容性**：全部 64 个横向、64 个纵向合法有序对，沿边 257 点比较值与梯度。
5. **复用**：A/B 共 32 个实例只复制缓存，并逐块核对像素。
6. **视觉**：查看三类同条件图板；统计变好不自动视为视觉变好。

生产 C++ 算法、CLI、构建目标和测试套件均不因本探针改变。

## 6. 第一轮结果：数值更接近目标，不代表形态问题已经解决

主结果为每瓦片 12×12 方格。共享表示共 8,104 个标量自由度；无约束表示 10,816 个。
同样的 16 张缓存预算**不代表**与旧解析模型具有相同的自由度、求解成本或参数复杂度。
此轮没有性能基准，不宣称更快或更紧凑。

## 7. 根据结果继续：保留 QRP 生成关系的对照

### 7.1 为什么直接拟合会有这个风险

这是局部解析推导：若两个通道 \(G_1,G_2\) 的零线横截相交，局部可把它们作为坐标 \((\xi,\eta)\)。
乘积场为 \(G=\xi\eta\)，零集是两条相交的轴；任意小的常数扰动 \(G+\varepsilon\) 的零集变成 \(\xi\eta=-\varepsilon\)，交叉就被绕开的分支代替。
因而场值乃至一阶误差很小，也不足以保护位于零水平的临界交叉。

这不是说每一次数值拟合都会失去所有交点，而是该误差目标根本没有保护它们。

### 7.2 对照方法及结果

不调拟合权重、不加风格预设；改为分别对两个**通道总场**求共享边界解 \(T_1,T_2\)，再输出 \(T=T_1T_2\)。
仍未要求各平面波单独整数闭合。乘积保持 C¹；零集在代数上仍满足

\[
\{T=0\}=\{T_1=0\}\cup\{T_2=0\}.
\]

如果两个拟合通道仍有横截零线交点，其交叉不会因为最终场被独立近似而消失。
但这**不证明**所有目标交点的数目、位置或横截性都保持；每个通道自身仍会变形。

| 格纹方法 | 值 RMSE | 归一化梯度 RMSE | 符号分歧 |
| --- | ---: | ---: | ---: |
| 直接拟合最终乘积 | 0.017605 | 0.035572 | 3.221% |
| 分别拟合通道再相乘 | 0.020885 | 0.040863 | 3.360% |

后者的平均误差稍大，但实际图像明显恢复了格纹的交叉组织。它说明**结构约束不能由误差指标代替**，不是宣称后者对所有审美目标都更好。
20×20 加密后后者值 RMSE 为 0.020871、符号分歧为 3.402%，观察结论一致。
其全部 128 个合法边对的采样误差为 0，A/B 共 32 个实例像素复用一致。

图像：`composition.png`；两个布局、16 张缓存和两通道系数库单独以 `factorized_*` 保存。
它使连续表示的系数预算翻倍，但最终烘焙后的瓦片数量仍为 16；未隐藏这项成本差异。

## 8. 本轮决定与下一步

本轮支持的结论：

- 逐模态整数闭合不是构造可复用相容内容的唯一办法。共享通道总场是一个可运行的替代候选。
- 原方法的连续拼接和复用结论没有被推翻；不足在于不能把这些性质当成 QRP 形态控制已经实现。
- “允许适应性改变”必须具体到保留什么：乘积关系、零线组织、相位族覆盖等，而不只是允许任意小均方误差。

当前不把任意总场拟合作为生产替代；三类基础拟合和乘积对照均保留为证据，不新增 C++ 类或永久 CLI 分支。
值得继续的是**保留 QRP 生成结构的共享边界构造**，而不是对最终纹理进行不区分结构的拟合。

下一步在这个框架下检查 QRP 相位与方向控制的传递：

1. 固定类型预算与渲染，扩大目标的相位覆盖，明确希望保留的局部母题/通道关系。
2. 记录不同设计参数下的边迹冲突及形态改变；若固定标签将不同组织硬并在一起，再决定怎样调整标签或允许类型。
3. 类型筛选只有在保留可延拓的非平凡布局之后才进入候选；不以少量成功拼图代替可铺砌依据。

尚未完成：内容驱动类型选择、参数族全域验证、拓扑保持保证、主观审美评价、商业价值与创新性论证。
已有拓扑控制与内容感知制砖工作仍需进一步对照，不能把有限元拟合或边界条件生成本身当作新颖贡献。

新增内容只有一个独立研究脚本、本记录及 README 的研究入口修订；既有工作区改动未还原、删除、暂存、提交或推送。
复用现有配色/字体和纯像素铺砌辅助函数；探针中的模态求值不成为生产公式的第二个维护入口。
没有改动生产 C++，因此没有运行无关的全量构建/测试；验证范围为上述实际运行、加密对照、PNG 核对和图像目视检查。

## 10. 按用户反馈更换默认测试纹样

同日后续：用户指出旧三组不好看，不应继续代表 QRP 的表现能力。本次改动是**测试样例与显示设计的替换**，不是又换一套拼接算法。

旧样例的局限有明确来源：只观察零高度正负分区；三组都是 q=5，其中两组依赖强方向权重；L=4 的局部窗口包含的结构很少。
这些选择适合观察边界和乘积交叉，却把大量其他高度的嵌套形状藏掉了，也不适合代表设计目标。
并非所有团块或波带本身都“不美”，而是不能长期只用这一种简化表达来评价整个 QRP 方法。

## 11. 相位控制重审与传递实验（2026-09-25）

用户认可第 10 节三组纹样后，回到主线：固定这些显示配方，检验 QRP 设计控制是否真正传递到可复用 Wang 内容中。
本节修正一个上游参数化问题，不宣称更换了 QRP 的定义或证明了最终论文方法。

### 11.1 旧二阶相位在偶数方向数上的退化

忽略本轮固定为零的共同相位，原始场为

\[
F(x)=\sum_{i=0}^{q-1} a_i\cos(\kappa d_i\cdot x+\phi_i),\qquad
\phi_i=A\cos2\theta_i+B\sin2\theta_i.
\]

当 q 为偶数，`dᵢ₊q/₂=−dᵢ`，当前二阶方向权重满足 `aᵢ₊q/₂=aᵢ`，而旧相位满足 `φᵢ₊q/₂=φᵢ`。于是

\[
a_i\cos(t+\phi_i)+a_i\cos(-t+\phi_i)
=2a_i\cos t\cos\phi_i.
\]

这其实是改变合并驻波的振幅。A/B 在零相位的一阶场响应为零，且同时取反 A/B 得到同一场。
尤其 q=8 的四组无向波相位为 `A、B、−A、−B`；令 A=B=π/2，**任意位置的整个场为零**。
平移、固定旋转和相同的空间形变不消除此恒等式；问题在 Wang 处理之前已经存在。

这不是浮点精度或代码漏项，也不是“QRP 不适合多样风格”。旧函数仍可作为幅度重分配的设计扩展；
但把这些参数统一解释为保幅度的非平移相位控制是错误的。基础理解文档中“更高 q 只是部分自由度”的说法已补充这一限制。

### 11.2 候选：反向波采用相反相位，权重定义保持不动

对本轮 q=8、q=12 使用

\[
\phi_i=A\cos3\theta_i+B\sin3\theta_i,
\qquad \phi_{i+q/2}=-\phi_i.
\]

于是同一对模态合并为 `2aᵢ cos(t+φᵢ)`，不会再用 `cos(φᵢ)` 衰减其幅度。
在这两个方向数上，三阶角谐波的两列与表示二维平移的一阶列正交；它们是非平移的相位变化。
这不等同于所有准晶语境下的 phason。q=12 还存在本轮未覆盖的相位方向，q=6 的三阶正弦列则退化；不能推广为所有 q 的完整两维控制。

q=5 仍使用原二阶构造。`commonPhase` 在偶数 q 的新配对下成为整体 `cos(commonPhase)` 因子，本轮固定为零，
不把它宣传为第三个独立形态控制。方向权重仍由二阶角谐波计算，绝不随相位基一起改成三阶。

实现只在 `ParametricWangQrpParameters` 末尾增加显式 `phaseHarmonicOrder`，缺省为 2；历史配方和已批准零相位图像不变。
`QrpMode` 明确区分 `weightHarmonic` 与 `phaseHarmonic`，实际源场及相位兼容瓦片都消费同一相位基；
全局相位、历史调制相位、内部顶点相位使用相同约定。导出清单补记 `phase_harmonic_order`，缺字段的旧快照对应二阶。
本轮没有增加 Wang 用户参数或新生产 CLI。

### 11.3 同条件实验定义

- 固定第 10 节的 q、κ=2、L=16、两种源偏移、16 类目录、布局 A/B、384px、2×2 超采样和全部显示阈值/颜色。
- 每个 q 比较 `(A,B)=(0,0)、(0.8,0)、(0,0.8)、(0.8,0.4)`；q=5 用二阶，q=8/12 用三阶。
- 每组参数各自离线联合求解一次完整的 16 类内容库，再用同一库铺出 A/B。改设计参数需要新库，不声称不同设计参数共享旧像素。
- QRP 模态及 C++ 核对值来自实际 C++ 重新导出，Python 仅复用现有 `Projection`、序列化模态求值、显示映射与像素拼装。
- 仍为 28×28 双三次共享边界投影；误差在每类独立 96×96 点上测量，边界检查使用原来的 128 个合法边对。

相位传递不只看绝对拟合误差：记某个参数变化造成未闭合目标变化 `ΔG`，拟合内容变化 `ΔT`，
分别报告 `||ΔT||/||ΔG||`、两者的余弦相似度和 `||ΔT−ΔG||/||ΔG||`。这些是本窗口中的场值响应指标，
不是审美评分，也不是等值线拓扑、连续参数全域或最终图像感知保真的证明。

另外从 C++ 重导出的 ±0.001 相位对照计算中心差分，检查零参数附近的两个原始场响应是否退化；
这项检查不经过 Wang 或投影。零相位三组的模态快照及 48 张瓦片像素均与已批准基线直接比较。

不能把 A/B 两轴响应都非零解释成两个新风格：等权各向同性的 q=8/12 原始场中，
`(0.8,0)` 与 `(0,0.8)` 可由方向星的离散旋转关联。这不与它们在局部未卷绕相位空间中独立于平移矛盾。
因此画廊第三列使用 `(0.8,0.4)` 混合相位；两条单轴仍保留作为参数传递诊断。
该补充不能替代对旋转、平移等视觉等价关系的完整分类，也不能把每个不同参数点都计为一种风格。

### 11.4 实测结果与限度

原始场零参数附近的两个中心差分响应，以采样 Jacobian 奇异值除以采样数平方根计：

| q / 相位基 | 两个归一化奇异值 |
| --- | --- |
| 5 / 二阶 | 0.22582、0.22337 |
| 8 / 旧二阶 | 9.21×10⁻¹⁴、2.14×10⁻¹⁴ |
| 8 / 三阶 | 0.24519、0.24519 |
| 12 / 旧二阶 | 1.03×10⁻¹³、2.35×10⁻¹⁴ |
| 12 / 三阶 | 0.20457、0.20457 |

旧偶数 q 的数值零与上面的解析退化相符。q=8 反例在 1536×1536 全局参考窗口中的最大绝对场值为 3.97×10⁻¹⁵。

混合相位 `(0.8,0.4)` 相对零相位的传递结果：

| q | 目标变化 RMS | 拟合变化 RMS | 响应范数比 | 响应余弦相似度 | 响应相对 L² 误差 |
| --- | --- | --- | --- | --- | --- |
| 5 | 0.19554 | 0.19066 | 0.97508 | 0.99079 | 0.13630 |
| 8 | 0.21599 | 0.21121 | 0.97789 | 0.98869 | 0.15035 |
| 12 | 0.18005 | 0.17321 | 0.96199 | 0.98377 | 0.18074 |

全部九个非零参数样本（两条单轴及混合相位）的响应范数比为 0.9620–0.9940，余弦相似度为 0.9797–0.9970；
**不能将这些数值翻译为“保留了 96% 的风格”**。响应相对误差仍有 7.69%–20.11%，局部等值线偏移不由总能量指标排除。
同一显示映射的颜色分歧最高为 9.178%（q=12 的 B 单轴），且该统计仍受背景比例影响。

必要验证：

- 12 个设计状态均与 C++ 源场/闭合场值及梯度核对，最大差 3.38×10⁻¹⁴。
- 每状态 128 个合法边对，合计 1536 组采样值/梯度差均为 0；共享自由度的 C¹ 构造依据仍见前文。
- 12 套完整 16 类库，A/B 合计 96 个铺砌实例均逐块像素复用；铺砌不重新求值或补缝。
- 三套零相位的谱快照及原有 48 张 PNG 与第 10 节基线完全一致。
- 默认构建成功；两个相关 CTest target 通过。新增一个相位语义测试组，复用已有顶点恢复、梯度和合法边检查覆盖 q=8/12，不新增独立测试框架。

视觉上，局部大环、偏心环和邻接区域随相位改变，并没有都被共享边界拟合压回零相位图案。
但同一库内依然反复出现相似的中心母题。当前未闭合目标本来就是同一源区域的小幅平滑平移：
`Gₜ(u)=Fψ(Lu+a+(b−a)Sₜ(u))`，其中 `b−a=(0.7,0.1)`。仅改变全库共同的 ψ，并不会让 16 类自动覆盖不同的局部组织。
因此本轮确认的是**设计参数跨库变化可以传递**，不是**单个固定库已经具有充分的内容多样性**。

### 11.5 当前决定与下一步

1. 后续 q=5 相位族仍用二阶，q=8/12 的保幅度相位实验采用三阶；旧二阶仅保留其明确的历史/幅度调制语义，不自动重写旧数据。
2. 接下来研究同一 QRP 设计内的内容库构造：让有限类型覆盖不同的局部相位/组织，区分全局设计控制与内部类型状态。
   先固定类型预算、显示和布局，对比“相同局部源的小平移”与“覆盖不同局部组织的目标库”，再测共享边界带来的改动。
3. 如果内容覆盖扩大后边迹冲突显著增加，再依据证据决定调整边标签、允许类型或共享边界策略，不先靠加类型、模糊接缝或缩窄参数范围掩盖问题。
4. 有限内容库的边界可共享、布局可重排仍须成立；类型像素不能依赖它所在的全局位置。联合求库允许离线耦合，实例铺砌只依赖预先生成的类型。

本轮没有证明任意相位的拓扑保持、严格非周期性、主观审美优越或商业价值。
三阶相位、有限元拟合和自由度共享本身也不是本项目已确立的论文创新点。
