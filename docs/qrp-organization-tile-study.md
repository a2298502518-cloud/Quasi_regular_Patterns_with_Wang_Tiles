# 相位兼容瓦片的父子组织（2026-09-22）

## 1. 本轮结论

接续 [相位兼容研究](qrp-phase-compatible-tile-study.md)。用户已接受边界约束下的 QRP
扩展，本轮目标是增加纹样组织方式，同时保住有限内容库的真正 Wang 复用，不推进界面。

将既有 `QrpChannelComposition::Nested` 用于两个相位兼容通道：低频父场组织区域，
高频子场生成区域内部的细节。完成三种配置：分簇细环形、分簇条纹、带内横向短条。
这是同一种组织关系的三种 QRP 配置，不是三套独立算法。

第一轮揭示了此前未充分处理的问题：低频父场的平均波矢在整数闭合后发生方向合并，
等权五方向 QRP 也会变成偏纵列的组织。不是所有“降低频率”都等价于“把原纹样放大”。
据此增加由实际闭合误差选择内部瓦片跨度的规则；第二轮在相同源视野、QRP 参数与总像素
数下恢复了二维大环和团块式的父场组织，新增候选不再主要依附纵列。

这次新增的能力是**用较大结构组织留白和局部细节**，不是仅对全幅纹样加密或换色。
仍有周期骨架，门控会截短子结构；不能声称完整图元无损摆放或商业质量已经验证。

## 2. 门控为何仍能独立复用

对同一类型 τ，在单位瓦片局部坐标 u 上分别求父场 aτ(u) 和子场 bτ(u)。
两者各自使用同一套 16 类型及边标签编码，但频率、方向权重和旋转可以不同。
本轮沿用原门控公式，父场中心 h=0，过渡宽度 w=0.35：

\[
t=\operatorname{clamp}\left(\frac12+\frac{h-a}{w},0,1\right),\quad
g=t^2(3-2t),\quad F=1-g(a)(1-b),
\]

\[
\nabla F=-(1-b)g'(a)\nabla a+g(a)\nabla b,\qquad
g'(a)=-6t(1-t)/w.
\]

三次门控在两端导数为零，因此是 C¹ 函数。合法邻接上两个输入的值与完整梯度分别相同，
链式法则直接给出 F 的值与完整梯度也相同。不是只保证颜色或沿边切向导数相同。
组合式不读取实例的全局坐标；先烘焙每类 16 张图片，再按 ID 复制到 A/B 两种合法布局。

当 a,b∈[−1,1] 时，F 是背景 +1 与 b 的凸组合，仍在 [−1,1]，不需逐图归一化。
父场 a≤h−w/2 时恢复子场；a≥h+w/2 时为常值背景。特别地，本轮 h=0 时，
a≥0 意味着 g≤1/2，从而 F≥0：以 F<0 填色的区域一定包含在父场负值区域内。

在过渡区，F<0 等价于 `b < 1−1/g`（g>0），所以子场负值区会收缩，甚至被截成短段。
因此不能把原子场的贯通核心带证明直接套给门控后的结果。
manifest 中的 `band_certificate` 仍只描述各个输入通道，不是复合场证书。

## 3. 发现的问题：低频与相位闭合的分辨率

已有相位模型的目标波矢、整数圈数与修正为

\[
\omega_r=L\kappa d_r,\quad n_r=\operatorname{round}(\omega_r/(2\pi)),\quad
\Delta_r=2\pi n_r-\omega_r.
\]

其长期平均载波是 `2π n_r`，不是 `ω_r`。当父场 κ=1.15、L=4、q=5、旋转为零时，
五个整数波矢依次为 `(1,0)、(0,1)、(−1,0)、(−1,0)、(0,−1)`。
原本不同的方向被合并成两组轴向方向。局部相位仍有闭合插值和角点状态项，不能据此说
整个场“严格只剩两个 Fourier 模态”；问题是平均载波方向的退化。

因此，“保持 QRP 振幅”不等于“保持原方向结构”。这是新增低频父场后暴露的模型适用
约束，不是边标签接边证明错误，也不是用更多门控强弱微调就能解决的问题。

## 4. 内部跨度选择规则与边界

从实际 `PhaseCompatibleQrpTiles::modes()` 读取波矢与修正，定义所有研究通道及模态上的
最大相对闭合误差：

\[
\varepsilon(L)=\max_{\text{channel},r}
\frac{\|2\pi n_r-L\kappa d_r\|}{L\kappa}.
\]

在本轮候选 L∈{4,8,16,32} 中取第一个满足 ε≤0.25 的跨度。所有通道共用该跨度，
不让父子通道形成不同空间尺度的瓦片目录。阈值是本轮 q=5 研究的内部准则，不是用户的
Wang 控件，也未成为所有实验入口的通用参数认证。

这个阈值有方向分辨率依据：ε<1 时，闭合波矢非零，与目标波矢的夹角不超过 arcsin ε。
q=5 的五个无向轴最小间隔为 36°，而 `2 arcsin(0.25)≈28.96°<36°`，因而各方向
不会因闭合而意外平行或反平行。该准则不保证精确五重对称、各向同性或纹样拓扑不变；
更多方向的 QRP 若轴间隔更小，需要重新评估误差预算，不能直接照用 25%。

| 项目 | 第一轮 | 规则选中的第二轮 |
| --- | ---: | ---: |
| 源跨度 L | 4 | 16 |
| 布局网格 | 8×8 | 2×2 |
| 每瓦片像素 | 96×96 | 384×384 |
| ε | 0.809704 | 0.157952 |
| 源视野 / 输出尺寸 | [0,32]² / 768×768 | [0,32]² / 768×768 |

ε 是平均闭合波矢误差，**不是完整局部梯度误差或图像误差**。局部梯度还包含
`Δ h′` 及角点状态项；误差不保证随 L 逐次单调。这只是离散候选里的首个合格值，
不是全局最优求解。整数圈数与跨度选择仍可能随频率/旋转发生跳变。

固定视野下，增大 L 同时减少可见瓦片数量并改变合法布局，不能称作只改变一个变量的
相同布局对照。未铺砌的八张全局 QRP 参考在两轮间全部字节一致，确认没有改变源纹样或
像素密度。16 张原始 RGB 瓦片的缓存占用由约 0.422 MiB 增至 6.75 MiB，尚无性能基准。
第二轮仅有 2×2 可见布局，不含全部 16 类型；不能据此认证大面积视觉变化。

与上一轮“增大瓦片没有消除周期骨架”的结论不矛盾：本轮针对新增低频父场的方向退化，
不是再次尝试用更大瓦片消除重复。相位闭合的周期骨架仍然存在。

角点源偏移仍为 `(0.2,0.3)、(0.9,0.4)`。父子门控参数不随案例变化。

| 组织 | 父场 κ / η / 方向 | 子场 κ / η / 方向 |
| --- | --- | --- |
| 分簇细环形 | 1.15 / 0 / 0° | 6.9 / 0 / 0° |
| 分簇条纹 | 1.15 / 0 / 0° | 6.9 / 1.5 / 0° |
| 带内横向短条 | 1.15 / 1.5 / 0° | 6.9 / 1.5 / 90° |

另外输出五种独立父/子输入，共八例。每例均保存 16 张源瓦片、A/B 布局、同库类型 0
的合法周期重复与一张未铺砌全局参考。固定深蓝/米色、F<0 填色、2×2 覆盖采样，
不描边、不收缩、不后处理接缝。总计两轮 320 张原图，图板另计。

- 根目录 `board_style_span.png` 保留第一轮纵列组织，不删除负面结果。
- `board_resolution.png` 比较第一轮、第二轮父场与第二轮组合结果。
- `resolved-scale/board_style_span.png` 比较已有环形、波带、格纹与新增三种组织。
  上排来自上一轮 L=4、κ=3.15，下排为本轮 L=16 父子组合；这是风格展示，不是单因素消融。
- `resolved-scale/board_organization.png` 同时显示父场、未门控子场、组合结果及同库重铺。
- `resolved-scale/board_wang_value.png` 比较同库单一类型重复与合法 A/B 多类型布局。
- `resolved-scale/board_reuse.png` 展示实际 16 张瓦片和编号，红框标出两个位置的同一类型 6。

视觉上，第二轮细环形和条纹在大环与团块内聚集，与全幅波带/格纹有可辨认的组织差异；
短条案例则保留方向性节奏。Wang 布局带来局部差异与内容重组，但类型之间仍较相似，
没有消除底层重复；新增组织也没有解决门控边缘的全部碎片。这些是观察，不是美感评分。

## 6. 复现与必要验证

先保留或重跑上一轮相位研究，供风格跨度图板引用：

```powershell
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
.\build\Release\qrp_wang_qrp_experiment.exe --phase-tile-study
.\build\Release\qrp_wang_qrp_experiment.exe --organization-tile-study
python tools\build_tile_board.py output\qrp-organization-tile-study --previous output\qrp-phase-tile-study
```

入口仍为同一个 C++ 实验程序；相位公式、门控公式均复用既有模型，Python 只核验图片和
排版。`manifest.json` 记录组合关系、h/w、全部通道模态、闭合误差、布局与共享边抽样。
未改动 UI，也未新增 Wang 用户参数。

Release 编译、七组 CTest 通过。在既有可复用瓦片测试中补充一个父子组合用例：
全部合法类型对的值与完整梯度接边、值域、负值支撑域包含关系、过渡中心的解析梯度差分。
两轮 320 张原图全部解码；1,088 个 Wang 实例及 544 个周期对照实例与源瓦片 RGB 完全一致。
实际布局的值/完整梯度边采样最大误差不超过 `1.009×10⁻¹²`。
旧相位研究 120 张、旧来源研究 111 张 PNG 重跑后全部字节一致；manifest 新增了组合元数据，
不声称 manifest 字节一致。已目视检查两轮风格图、来源图、跨度比较和第二轮实际复用图。

下一阶段仍应围绕风格跨度与实际铺砌价值：区分有用的“细节分区”与用户不希望的碎片，
并检验固定库在更大视野下带来的可见重组。不要因连续性通过就认定视觉价值完成，
也不要默认回到界面或把所有局部混合都当作缺陷。

后续已完成 [大范围重铺研究](qrp-retiling-study.md)：原库扩为 8×8 后仍显公共骨架；
仅扩展父场的 QRP 相对相位状态，可产生更松散的簇群和起伏列。本文原候选与数据保持不变，
它的完整大环作为规整装饰风格保留，不自动以新结果覆盖。
